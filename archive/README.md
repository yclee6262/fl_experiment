# 非論文主線的歷史研究

`legacy/` 是112支非主要腳本的實體位置。它們包含早期探索、重複pipeline與主文外擴充。主區域保留的技術依賴仍可透過自動產生的 `.local_scripts/` 相容連結引用這些檔案。

`contribution_packages/` 是移出主要索引的貢獻研究相對連結，實體資料及套件仍在原 `contribution_analysis/` 路徑。研究版本與資料共用路徑尚未完全解耦，因此沒有永久刪除整個歷史目錄。

目前位置、舊位置與分類見 `docs/reorganization_20261116/layout.json`。新工作請從 `python run.py list` 選擇主要入口；此區用於回查與歷史重現。封存不代表結果錯誤，也不代表方法從未被引用。
