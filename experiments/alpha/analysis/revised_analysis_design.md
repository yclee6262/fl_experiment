# 修訂十法分析設計

此設計在讀取修訂2700筆結果前固定。研究是既有90 seeds、三情境的數值修訂重分析，非獨立確認。求解規約float32_slsqp_v1，方法仍為U/Q/E/S及六種等比例兩兩混合。

- 主指標為保存決策重新計算的合成真值絕對目標誤差；pooled為輔助，兩者不回饋搜尋。
- 統計單位是seed：先平均同seed的三情境，再於90 seeds間分析。情境內結果另列，不將270案例當獨立seed。
- 200000次paired bootstrap，固定rng=20261123，所有方法共同重抽seed；普通95%區間，以及Bonferroni family區間。
- 12原六法與17 SE/QU比較由原registration讀取，分開校正。另45個十法全配對是新的探索family。真值與pooled各自清楚標示，不宣稱跨指標共同校正或獨立確認。
- 報每法均值、seed標準差、95%區間、初始化與Stage3查詢、交付/solver success/fallback/失敗；保留失敗列，配對只能用完整有效seed，報排除數。
- 所有45對報逐案例、seed平均後的pooled／truth方向一致率，ties另列；並報兩指標Spearman。沒有差異不證明等效，不事後挑等效界限。
- 核對來源hash、方法覆蓋、政策、原模型與盲測來源、alpha完全相同、X與truth一致；報歷史與修訂的決策和成本差異。舊區間不能移植。
- 圖以真值差值對U九項，顯示普通95%與45對探索family區間。無硬查詢預算，結果不稱同成本優勢。
