# 代理路徑幾何訊號：開發登錄

2026-10-20。前5族140個global-free品質代理候選均未兩情境通過0.5；offline_E顯示代理路徑有訊號，配分品質仍不確定。本族只使用端點幾何及已接受的正常路徑，不以模型MSE、pooled、truth或支持度直接配貢獻。

代理位置仍用已鎖定四設定；三種預先固定分數：

1. displacement：||z_i-X||，只反映影響幅度，不能判正負；若排名驗收通過仍不能稱signed品質差或辨識負貢獻。
2. rollback：-(z_i-X)·u，其中u=(X-X0)/||X-X0||，評估移除是否使解退回原搜尋起點方向。若總位移<=1e-8棄權，不能補0。
3. normal_distance：abs((z_i-X)·u)，衡量相對原搜尋前進方向的偏離幅度，同樣不能判正負。

3×4=12候選，方向與正負定義先固定，不按開發結果反轉。這些只是幾何代理，未驗證前不能把位移當成品質貢獻；其中unsigned方法縱使排序高仍只支持排序用途。
