# 單次倒推的 A／B 交叉驗證切換：探索性診斷

## 問題與事前可用資訊

目前五候選方法 pooled 品質通常較好，但需約五次 Stage 3；三候選正式比較雖節省 39.55% 方法模型請求，未建立更好的 pooled 品質。本診斷問：**只做一次倒推時，能否用 Stage 0 資料決定採 Uniform A 或品質權重 B，兼顧品質與查詢成本？**這是初始 α 的選擇，不改參與者招募、付款或最終候選選解。

`explore_cv_ab_switch.py` 使用 Stage 0 已有的 20 筆盲測標記與各 local model 對它們的預測。對每筆 j，從其餘 19 筆重算各人的 MSE 反比 B 權重，計算在 j 的 B 集成平方誤差；與同一筆的 Uniform A 集成平方誤差比較，取兩者的 20 筆逐筆留一平均。若 B 的交叉驗證 MSE 嚴格較低，選 B，否則選 A；**實際執行時用完整 20 筆得到的 B 權重，只做一次 Stage 3**。若 Stage 0 預測可沿用資格檢查時的快取，不需新增預測；此處保守列入每位 local model 一次、每次 20 筆輸入的批次 API 呼叫。pooled evaluator 與合成 truth 均未進入切換規則。

以先前已使用的乾淨、4 倍樣本量不平衡、25% 低品質三批各 120 seeds 保存的 A／B 候選 X 作離線反事實；候選 X 沒有重新求解。所有資料已用於其他研究，**下表及信賴區間完全屬於方法開發描述，不能作獨立優勢**。每 seed 的 Stage 0 MSE、B α、有效 box 解、交付分數和保存模型均核對；逐 seed 記錄在 `alpha_weight_outputs/alpha_cv_ab_switch_development_v2_1900_120/`。

| 情境 | 120 seeds 中選 B | A 平均 pooled | B 平均 pooled | 切換法平均 pooled | 五候選平均 pooled | 切換法平均模型請求 |
|---|---:|---:|---:|---:|---:|---:|
| 乾淨基本 | 83 | 0.016967 | 0.014558 | 0.014735 | 0.013266 | 365.8 |
| 4 倍樣本量不平衡 | 62 | 0.019741 | 0.017900 | 0.018293 | 0.015877 | 357.3 |
| 25% 低品質 | 103 | 0.020974 | 0.018569 | 0.018068 | 0.015735 | 368.4 |

切換法相對 B 的平均 pooled 差依序為 `+0.000178`、`+0.000393`、`-0.000501`；三個描述性 95% 配對區間皆跨零。相對五候選平均 pooled 差分別為 `+0.001469`、`+0.002416`、`+0.002332`，方向均較差。它在三情境都接近單次倒推的成本，但目前沒有跨情境優於直接選 B 的訊號，也沒有足夠理由為它新增正式實驗或提升為主要方法。這不排除其他更有資訊的事前診斷；只否定本規則已呈現有力開發訊號的說法。

**研究決策：**暫不把 A／B 交叉驗證切換加入正式 runner。若應用情境能取得候選 X 附近、與原 20 筆盲測獨立的可信資訊，可以另立有成本計價的選解研究；在這類資訊及實際誤差價值／查詢價格尚未確定前，不依舊 pooled 結果繼續微調同一批資料的切換門檻。
