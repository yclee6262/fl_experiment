# 模型池第一階段：固定端點的尺度換算驗證 v1

日期：2026-10-28。使用者授權「先驗證換算後的貢獻是否維持一致」。本文件於新探測評分與換算前凍結。

## 1. 範圍與假說

只驗證固定端點下，把某模型全部loss乘a>0，同時用同一批探測點重算其尺度，標準化C是否維持一致。這是正比例換算的代數／數值與工程驗證，不證明評分品質、公平、抗任意操弄、低成本或完整搜尋不變。不重跑搜尋、不改alpha、錨點或歷史演算法。

使用T3已讀60個解析設定的固定full/minus端點與共同評分loss，其中59可定義、1個無剩餘正權重維持null。全部是已讀機制開發資料，不冒稱新的保留或正式確認。只有target owner=0的單輪模型消融，不具同一團隊所有owner的C，因此本輪不產生付款比例或金額。

## 2. 固定探測與公式

共同探測點為[-1,-1/2,0,1/2,1]²的25點，與原box一致，規則不依端點或C挑點。用原解析模型取得loss，Q10/Q90採排序後(n−1)p線性插值；s_m=Q90−Q10。固定原完整模型權重v。每個評分panel都以全部模型同一把共同尺比較，不因移除owner重算權重或尺度。

標準化C=Σ_m v_m[(loss_m(minus)−loss_m(full))/s_m]；另存own與others及Σ二者。採先作單模型差再加權，避免大offset共同loss相減的消去誤差。所有正權重模型尺度必須>1e−12；不足則undefined_scale，不以epsilon分母硬補；零權重模型可無尺度但不參與評分。無minus端點保持原undefined_no_remaining_weight，不填0。

原端點在舊搜尋中已產生，本輪25探測是現在離線建立的固定評分尺度，不回溯宣稱搜尋前已校準。假如未來用於新搜尋，應在該搜尋前鎖版本與探測尺度。本輪一致放大時重估尺度代表一致的單位換算／完整換算panel，不授權模型在鎖定版本後任意換回覆。

## 3. 固定操作

每個設定做baseline；再對每個模型單獨施加a=0.1、10、100，探測loss和兩端點loss一起乘a，其他模型、權重與原端點固定。共60 baseline＋360變體（354可比較、6預期原未定義）。每個panel只算既有loss的確定性變換，不新增搜尋或神經網路推論；新解析模型探測60×2×25=3000次函數評分。

反例控制：每個可定義設定對target模型只放大兩端點loss×10、故意不換探測尺度；保存造成的差異。這是違反一致單位換算／鎖定版本的故意控制，不冒稱可通過准入的真實作弊。預先指定useful_information_0控制必須揭露改變，其餘零作用／零權重案例可以不變，不要求每案都變。

解析補充：T3 individual_scale各設定端點是否相同，以及標準化後分數的跨設定差異；保留有用少數與過度樂觀案例的相同內部數值、相反原解析D，不把尺度通過當品質通過。D只引用鎖定原值，不進公式。

技術邊界測試：零尺度、近零尺度、NaN／負loss、缺probe／長度錯誤、無minus、零權重、nonzero target下「loss倍增」與「預測倍增」不同、baseline有號與own+others。近零s跨單位可能跨絕對可靠性門檻；正比例不變主張只限各panel尺度均可靠，不掩蓋這個邊界。

## 4. 獨立驗收與成本

生產用float64 quantile與差值；獨立reference不匯入生產計分器，以Fraction從raw probe／endpoint loss重算分位數、s、C、分解。原探測回覆另以有理數多項式重核。原保存score.losses_full/minus必須與common階段原始回覆及鎖定座標連結。

技術硬gate：354個可比較變體的C／own／others各與baseline一致（|Δ|≤1e−10+1e−9|baseline|），且與獨立reference一致；6個無端點變體維持null；沒有可靠尺度時明確未定義。真實非零C符號不得翻，|C|≤1e−10只列近零。useful_information_0故意不換尺度的控制必須不同。故意C+1、scale錯誤及null改0須被獨立核對發現。失敗保存原貌，不重挑點或改門檻。
