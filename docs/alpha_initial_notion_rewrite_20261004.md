> **閱讀重點｜更新至 2026-10-04**　先分清初始 α 公式、候選組合與最終 X 的選解規則。新「邊際資訊 α 取代 Target-local 候選」在乾淨基本情境的獨立 180-seed 比較中，pooled 誤差穩定低於原五候選，平均模型請求僅多 0.34%，沒有額外可信標記。依預定順序測的兩個複雜情境均**未建立穩定優勢**，因此改善主張限於已測基本情境；尚無真實貨幣淨收益證據。
## 1｜先分清楚：改 α、改候選組合、改選解
- **初始 α 公式**：倒推前為每個 local model 設定資訊權重；每組 α 可執行一次 Stage 3，得到一個候選 X。
- **候選組合**：選擇要為哪些 α 付出 Stage 3 求解成本，例如五候選、加一組專家 α 的六候選，或只跑四組。
- **選解規則**：已有數個候選 X 後，僅用內部盲測資料決定交付哪個 X。最終 α 是該 X 對應的 α，**不是多組 α 的平均**。
- **外部評分**：交付後用凍結的 pooled evaluator 計算 `E_pool(X)=|f_pool(X)-target|`，越小越好；合成真實函數的 `E_true(X)` 只作診斷。兩者均不得進入 α、候選組合或正式交付 X 的選擇。
本頁的「經濟意義」是用有限的模型查詢與可信標記，決定向哪些參與者的資訊配置權重、是否值得多買一個候選解。α **不是**報價、貢獻 q、付款比例或公平分潤。沒有實際標記價格、請求價格與誤差改善價值時，不能宣稱淨貨幣效益或誘因相容。
## 2｜共同設定與符號
- **確認用基本情境**：乾淨合成資料、二維、target 0、固定參與者 IDs 1／2／20，X 各座標在 `[-1,1]`，可行性容差 `1e-8`；不更新 α、不 pruning、不結算。同 seed 的方法共用資料、local models、Stage 2 proposals 與凍結 pooled evaluator。
- **事前資料**：通常有 20 筆 Stage 0 盲測 `(x_j,y_j)`，`f_i(x)` 是參與者 i 的 local model 預測，`MSE_i=平均_j(f_i(x_j)-y_j)^2`。`norm(s)` 表示將非負分數除以總和；公式的 `eps=1e-5`。若數值或求解不合法，依程式 fallback 並記原因，不把 fallback 說成原公式成功。
- **配對差**：`Δ=E_pool(新法)-E_pool(基準)`；負值表示新法較好。以 seed 為單位重抽樣 10,000 次求信賴區間；同 seed 的多個候選 X 不當成獨立樣本。有效解品質、失敗率、可行性、請求量與耗時分開看。
- **pooled／truth 衝突**：同一 seed 上，兩種評估來源對「新法比基準好或壞」給出相反方向。這是評估排序衝突，不要求兩者預測值相等；主要判準仍是 pooled。
## 3｜已實作的初始 α 公式
以下皆依固定 agent ID 順序保存，權重非負且總和為 1。單次方法只做一次 Stage 3；多起點方法可選用其中數組。
### 3.1 基準與收縮
- **A／Uniform**：`α_i=1/n`；三人各 1/3。平均使用資訊，作低成本基準。
- **B／Stage 0 品質權重**：`α=norm(1/(MSE_i+eps))`。盲測誤差低者有較高資訊權重；不代表其應得較高付款。
- **Quality shrink**：`α=0.5A+0.5B`。在平均使用與盲測品質間折衷，降低 20 筆資料造成的過度集中。
- **Ensemble shrink**：先在 20 筆盲測上求非負、總和為 1、使集成 MSE 最小的 `w`，再設 `α=0.5A+0.5w`。測模型互補；可能對小盲測集過擬合。
### 3.2 目標區域與誤差結構
- **Target-peer shrink**：對參與者 i 的有效 proposal，取其他 local models 的 `|預測-target|` 中位數 `m_i`；令 `t=所有 peer 誤差的中位數+eps`、`s_i=B_i exp(-m_i/t)`、`α=0.5A+0.5norm(s)`。用同儕對 proposal 的支持調整權重；共同偏差可誤導。
- **Target-local precision**：`K_j=exp(-|y_j-target|/0.5)`；`L_i=[Σ_j K_j(f_i(x_j)-y_j)^2+5 MSE_i]/[Σ_j K_j+5]`；`α=norm(1/(L_i+eps))`。加重目標附近盲測誤差，以 5 筆等效全域 MSE 避免局部樣本過少。
- **MSE power 1.5**：`α=norm((MSE_i+eps)^(-1.5))`。比 B 更相信盲測最佳模型；資訊集中風險也較高。
- **Corr precision 0.5**：有號殘差 `R[j,i]=f_i(x_j)-y_j`；令 `M=0.5 diag(MSE_i+eps)+0.5 RᵀR/20`，在 `α_i≥0、Σα_i=1` 下最小化 `αᵀMα`。意圖減少重複誤差；`RᵀR` 是**未中心化殘差二階矩**，並非相關係數矩陣。
### 3.3 專家與局部風險
- **Best-agent**：盲測 `MSE_i` 最低者權重 1，其餘 0；平手取固定 agent 順序第一位。代表「把資訊權重全集中於盲測最佳專家」這個極端方案；可能忽略模型互補。
- **Local-bias-risk／20 標記**：對每人的有號殘差 `f_i(x_j)-y_j` 以 `[1,x_j]` 做 ridge 回歸，截距／座標懲罰分別 0.01／1；在 proposals 平均位置 `c` 得預測偏差 `b_i`，回歸後殘差平方均值為 `v_i`；`α=norm(1/(b_i²+v_i+eps))`。把預期使用區域的偏差平方與剩餘風險一起計入；依賴局部線性和 proposal 中心的代表性。
- **Local-bias-risk／100 標記（已完成基本正式比較）**：公式同上，但 ridge 使用 100 筆可信盲測；前 20 筆與原方案相同，另需取得 80 筆標記。`MSE_i` 仍沿用原 20 筆 Stage 0 值；新增資料只用於局部偏差／殘差風險。此版會新增一個 Stage 3 候選，選解仍用原 20 筆的 B 校正規則。合成環境可由真實函數產生新增標記，實際部署必須另行取得並計入價格，不能當成免費資訊。
- **Marginal information 50／邊際資訊 α**：先用原 20 筆 Stage 0 盲測的 B 權重集成求 `MSE_full`。逐人將 B 權重設零、其餘重新正規化，求 `gain_i=MSE_without_i-MSE_full`；令 `g_i=max(gain_i,0)`，若 `Σg_i>0`，則 `α=0.5 B+0.5 norm(g)`；若沒有正增益，退回 B 並記原因。經濟意義是**當前 B 集成在盲測上的邊際預測資訊價值**；不是完整移除參與者後的倒推貢獻、Shapley、報價或分潤。
## 4｜候選組合與選解規則
**原五候選（目前主方案）**：A、B、MSE power 1.5、Corr precision 0.5、Target-local precision 各做一次 Stage 3。以原 20 筆標記，先算 B 權重集成的有號殘差 `r_j=Σ_i B_i f_i(x_j)-y_j`，再將 `r_j` 對 `[1,x_j]` 做 ridge 回歸（截距／座標懲罰 0.01／1）。每個有限且 box 可行的候選 X 的內部分數為 `|Σ_i B_i f_i(X)-ridge_bias(X)-target|`；交付分數最小的 X。pooled 和 truth 只在交付後評分。
- **六候選／專家選擇權**：原五候選再加 Best-agent；選解規則不變。多付一次求解成本，測是否值得保留專家解的選擇權。
- **七候選／局部風險**：上述六候選再加 20 標記 Local-bias-risk；選解規則不變。多測一種按局部誤差配置資訊的 α。
- **局部選解**：原五組 α 和五個 Stage 3 候選不變；對每個候選 X，以盲測點距離設 `K_j(X)=exp(-||x_j-X||²/(2×0.25²))`，各自做加權 ridge 偏差校正，再選校正後內部分數最低者。這**不是新 α 公式**，只改交付哪個 X；不增加 Stage 3，但增加本地校正工作。
- **固定四候選**：省略 Target-local precision，只求解 A、B、MSE power 1.5、Corr precision 0.5；用原全域校正選解。目的是少付一次求解成本。
- **動態多樣化四候選**：先算出原五組 α，固定保留 A、B，再從其餘三組選兩組，使四組 α 的六個兩兩 L1 距離總和最大；平手依固定候選順序。只為所選四組求解，仍用原全域校正選解。成本含**全部五組 α 的初始化**及四次 Stage 3；α 距離是資訊分散代理，不能保證 X 品質。
- **六候選／100 標記（正式比較未通過）**：在原五候選外加 Local-bias-risk／100 標記的 X；選解仍用原 20 標記 B ridge。它同時增加 80 筆可信標記、初始化預測及一次 Stage 3，與前述「Best-agent 六候選」是**不同方法**。
- **邊際資訊替換五候選／本輪新法**：保留 A、B、MSE power 1.5、Corr precision 0.5，將原 Target-local precision 的 Stage 3 候選替換為 Marginal information 50。仍只做五次倒推；用完全相同的 B20 全域 ridge 內部分數選一個可行 X。新增 α 只用原 20 筆標記及 local models，pooled／truth 不參與候選計算或選解。
配對實驗為產生基準會在同一批次跑多個方法；報告的「方法獨立執行成本」只計該方法自身候選，共用模型訓練、資格檢查、proposal 和 evaluator 另記，不能重複加總。
## 5｜實驗結果：每批的目的、規則與結論
### 5.1 單次 α 是否比低成本基準好
- **舊正式比較**：五情境 × A／B／三種 shrink × 30 seeds，750／750 有效。乾淨情境平均 pooled 誤差：A 0.020415、B 0.017640、Quality shrink 0.018755、Ensemble shrink 0.019098、Target-peer shrink 0.018956。三種 shrink 未建立對 A 的穩定優勢；均值不能代替配對區間。
- **Target-local precision 獨立比較**：seeds 400–429，90／90 有效。A／B／Target-local 均值 0.013299／0.013845／0.015298；Target-local 減 B = +0.001453，95% 區間 \[-0.001739,+0.004473\]，不支持其優於 B。
### 5.2 五候選能否改善交付 X
- **5-seed pilot**：A／B／五候選均值 0.025947／0.030903／0.014757；15／15 條摘要與 25／25 候選有效。只驗流程。

- **獨立複驗，seeds 600–659**：A／B／五候選均值 0.016663／0.016652／0.013275；180／180 有效、60／60 選解可重算。五候選減 A = -0.003388、97.5% 同時區間 \[-0.006443,-0.000491\]；減 B = -0.003377、區間 \[-0.006405,-0.000930\]；**此批通過事前門檻**。均值請求 A 341.75、B 341.60、五候選 1782.45，五候選約為 B 的 5.22 倍。兩批是不同證據，不能挑有利的一批當普遍結論。
### 5.3 增加專家或局部風險候選是否值得
- **開發**：在已用 seeds 500–529／600–659 篩選候選，六候選相對五候選描述性 pooled 差 -0.001768／-0.001054；七候選 -0.001468／-0.001636。方法由這些資料選出，不能當確認證據。
- **pilot**：25／25 摘要、35／35 候選及 15／15 選解重算通過；五／六／七候選 pooled 均值 0.014757／0.014757／0.013966。
- **獨立正式，seeds 700–759**：300／300 摘要有效，三法各 60／60 有效解、180／180 選解重算、14／14 來源雜湊相符。事前主要比較是 Best-agent 六候選減五候選：均值 0.015081 對 0.015218，配對差 -0.000137，95% 區間 \[-0.001258,+0.001010\]；較好／相同／較差 = 8／49／3，**未建立穩定改善**。方法請求 2141.00 對 1857.55，平均多 283.45。
- **七候選次要探索**：均值 pooled 0.016300，減五候選 +0.001082，95% 區間 \[-0.000653,+0.002940\]；請求 2506.00，比五候選多 648.45。雖然 truth 均值 0.012862 小於五候選 0.013511，不能取代 pooled 主要判準。pooled／truth 方向衝突六候選 3／60、七候選 7／60。
### 5.4 改選解或少做一次倒推能否更划算

### 5.5 100 筆可信標記的第六候選：pilot 與獨立正式
**目的與方法**：原五組 α、五次 Stage 3 和 20 筆 B 全域 ridge 選解不變；新增 `local_bias_risk_100`，用與原 20 筆前綴相同的 100 筆可信盲測估計各模型在 proposal 區域的偏差平方加剩餘風險，形成第六組 α 並多倒推一次。Stage 0 的 `MSE_i` 仍用原 20 筆。新增 80 筆可信標記在合成環境由真實函數提供；實際取得價格未知，且與模型請求分開計帳。
- **開發（非確認證據）**：已用於多次挑法的 510 seeds 上，新六候選減原五候選的描述性 pooled 均差約 -0.000637，各批方向不一致。這些資料不能當正式優勢。
- **5-seed pilot**：20／20 摘要條件、10／10 選解重算通過；原 A、B、五候選的 X、α、pooled 分數與舊 pilot 完全相同。新候選在五次都未被選中，兩法 pooled 均值同為 0.014757；新法平均多 406.2 次模型請求和 80 筆標記。pilot 只驗資料流與成本。
- **事前登錄的獨立正式，seeds 1300–1479**：在開跑前固定 180 個全新 seed、14 個來源雜湊及主門檻：180 個有效可行配對、`E_new-E_five` 的 10,000 次 seed-bootstrap 95% 區間上限小於 0、無較高失敗率。720／720 摘要條件完整，兩法各 180／180 有效可行，360／360 次選解可重算，14／14 來源雜湊一致。
- **主要結果**：五候選／新六候選平均 pooled 誤差 **0.014168694／0.013765638**；新減舊的配對平均差 **-0.000403056**，95% 區間 **\[-0.001273042,+0.000408086\]**，跨零。新法較好／相同／較差 **25／135／20**；新增候選被選中 45／180。pooled／truth 排序方向衝突 18／180；truth 仍只作診斷。
- **成本與判定**：平均模型請求五候選 1891.517、新法 2279.217，多 **387.7 次（20.50%）**，並需額外 80 筆標記；平均本地方法時間 0.122217／0.157312 秒。**事前的穩定 pooled 改善門檻未通過。** 平均較好只是訊號，不足以宣稱優勢或淨貨幣收益，依規則不擴到複雜情境。若請求價 `c`、標記價 `l`、每單位誤差改善價值 `v`，只按觀察均值的損益平衡為 `v×0.000403056 > c×387.7 + l×80`；價格未實測。

### 5.6 邊際資訊 α 取代一組候選：基本通過，複雜驗證有限
**問題與成本邏輯**：原五候選中的 Target-local precision 需要一次 Stage 3。本法以盲測上的正邊際集成損失，形成另一組初始 α 來替換它；五次倒推與標記數不變。這是在固定候選求解預算下，測試邊際資訊價值是否比目標附近誤差更能找到高品質 X，並非分潤規則。
- **開發與 pilot**：已使用 seeds 500–759 的離線替換試算，描述性 pooled 均差約 -0.000429，方法由這些資料挑出，不能當正式證據。seeds 0–4 的 pilot 20／20 條件、10／10 選解重算通過；原 A、B、五候選 X／α／pooled 與舊 pilot 完全相同。新法／原法 pooled 均值 0.011420／0.014757，請求 2081.4／2031.0；五個 seed 只驗流程。
- **基本情境獨立正式，seeds 1500–1679**：事前固定 180 個新 seed；720／720 摘要、1080／1080 候選、180／180 有效可行配對、360／360 選解重算，16／16 來源雜湊一致。原法／新法平均 pooled 誤差 **0.012410591／0.011724811**；新減舊平均 **-0.000685780**，10,000 次 seed-bootstrap 95% 區間 `[-0.001267517,-0.000135724]`，完全小於零。較好／相同／較差 **42／116／22**，pooled／truth 方向衝突 25／180。新法平均多 **6.517 次模型請求（0.344%）**，無新增標記或失敗；**基本品質與事前 5% 成本門檻均通過**。
- **依門檻才測複雜情境**：樣本量 4 倍不平衡與 25% 低品質 local labels 先各做 5-seed pilot，再以未用過的 seeds 1700–1819 各跑 120 個配對。兩批各 120／120 有效可行、480／480 摘要、720／720 候選、240／240 選解重算，17／17 來源雜湊一致；兩項確認比較各報 seed-bootstrap 97.5% Bonferroni 同時區間，不把 240 條跨情境資料視為獨立 seed。
- **樣本量不平衡正式**：原法／新法平均 pooled **0.016061360／0.015050509**；新減舊 **-0.001010851**，97.5% 同時區間 `[-0.002295360,+0.000127655]`；較好／相同／較差 27／76／17，模型請求平均少 0.425%。有平均改善訊號，但區間跨零，**未建立穩定優勢**。
- **低品質正式**：原法／新法平均 pooled **0.014877164／0.015034744**；新減舊 **+0.000157580**，97.5% 同時區間 `[-0.000633872,+0.001102274]`；較好／相同／較差 20／90／10，模型請求平均多 0.721%。均值稍差、區間跨零，**不能宣稱改善或確定惡化**。低品質 seed 1817 的較大退步（約 +0.029113）提醒平均勝場數不能代替平均品質。
**判定與限制**：兩個複雜情境的請求成本門檻都過，但 pooled 同時區間都未完全小於零，跨情境穩定優勢未建立。新法可作為乾淨基本情境中有證據支持的候選；若面對低品質或資料不平衡，現有證據不足以全面取代原五候選。若每次模型請求成本為 `c`、每降低一單位 pooled 誤差的價值為 `v`，基本情境只按觀察均值的損益平衡約需 `v>9502.56c`；實際價格未知，不能宣稱貨幣淨收益。

## 6｜成本該如何解讀
- `initialization_requests`、`stage3_requests`：分別是算 α 與求解的 local-model API 呼叫數；對應 `input_samples` 是批次呼叫中輸入點數，不等於呼叫次數。`seconds` 是本地計時，不是實際網路服務延遲。
- 外部 pooled 評分與建置 evaluator 屬研究成本，另列；不得混入 Stage 3 或選解成本。共用訓練、資格測試、proposal 每 seed 只記一次，方法成本與整批成本分開報。
- 可信標記是另一種資源。100 標記試法除原 20 筆外需取得 80 筆；本地模型請求計數器不能代表其取得費用。
- 五候選獨立複驗相對 B 平均多 1440.85 次請求、pooled 誤差少 0.003377。若每次請求成本為 `c`、每降低 0.001 誤差的價值為 `v`，只算這兩項的均值損益平衡約為 `v>426.65c`；實際 `c`、`v` 未知。四候選雖省請求，仍未達事前品質容忍度；不得用假設價格把失敗改稱研究門檻通過。
## 7｜輸出欄位讀法與重評
- `summary.csv`：一列是一個 scenario × seed × method 的交付條件。`status`、`failure_stage`、`failure_reason` 說明執行／失敗；`delivery_status` 說明是否有有效交付 X；`final_solution` 是交付 X，空值不是零向量。
- `candidate_rows.csv`：各初始 α 單獨求出的 X 與成本；多起點摘要只交付其中一個 X。`agent_ids` 與 `initial_alpha` 依位置對應；`stage0_mse`、`alpha_audit` 記原始分數、公式中間值、fallback、選中初始化和內部選解分數。
- `actual_solver`、`solver_status` 是求解路徑和數值結果；`final_box_feasible`、`max_box_violation` 是從交付 X 重算的限制檢查。求解器回報成功不等於 X 可行。
- `external_global_prediction` 是 pooled 對 X 的預測，`external_global_error` 是本頁主指標；`final_target_error` 是 truth 診斷。沒有交付 X 時品質值不適用。
- `shared_costs.jsonl` 每 seed 保存一次共用準備、盲測點、proposal、coalition 和 `artifact_path`；後者指可重載的資料與模型。正式批次還保存 manifest、分析規則、來源快照雜湊與 `selection_verification.json`／決策檔。
原五候選 60-seed 複驗的 180／180 解可重評，seed 600 隔離重播通過。pooled／truth 相對 A、B 的逐 seed 排序方向各衝突 13／60。複驗 target 附近測試點中位數 258.5、範圍 232–291；target-near truth MSE 中位數約 0.000101。這些只描述合成評估覆蓋，不能保證真實應用可靠。
