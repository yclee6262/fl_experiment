# 既有驗證可靠度作評分者：開發登錄

2026-10-20。固定均勻面板32方法未在兩情境達到0.5後，另測「評分模型的既有驗證可靠度」是否改善品質代理。不是把個人MSE、alpha_pre、選取次數直接當個人貢獻，也不更新任何求解alpha。

資料限定部署原已有的Stage1 phase1_report之agent_id與mse。MSE是本次資格檢查已保存的驗證紀錄，不另查truth、clean_y、pooled預測或原資料標籤。不讀alpha_pre、bid或is_poisoned。不改求解／coalition／候選，評分者只評已鎖定的代理端點。

沿用32面板實驗保存的20個原local模型端點回覆，零新增查詢。按原pool或noncoalition兩面板，預先固定四個signed預測評分者：MSE最小單一模型、MSE最小3模型平均、MSE最小5模型平均、1/(MSE+1e-8)正規化加權平均。所有Q=abs(估計預測-target)，score=Q(proxy endpoint)-Q(baseline)。排序同MSE時agent_id小者先，不能按LOO調整。

共2面板×4評分者×4已鎖定代理設定=32候選，全報告。此權重只屬端點品質代理，與求解alpha隔離，不能把通過者當alpha選擇結果。原Stage1驗證MSE少量測試點可能不可靠，這正是待驗證限制。

同20舊開發團隊、同seed bootstrap及點估計>0.5兩情境、覆蓋>=90%門檻。按最小情境相關、5格優先、linear優先、非coalition優先、方法名稱的固定順序選單一候選；若沒有通過保留失敗，不反轉分數或增加seed。

若通過，該方法在任何新資料的LOO或pooled品質揭露前鎖定，才可加入尚未揭露效果的2026102200–2219確認；新資料生成已啟動不代表可看其效果調參。若該資料已讀過效果，必須另保留新seed。獨立驗收仍為兩情境點估計>0.5、95%下界>0、覆蓋>=90%；樣本／端到端成本另作完整配對驗收。

這是本次任務已有可靠度資訊與反事實端點的組合，不是歷史資料擬合。沒有alpha研究、付款、pruning、Shapley或Notion操作。
