# 自適應共享回應庫：開發登錄

2026-10-20。固定格點代理在獨立40團隊Clean排名0.418、污染0.730；不調整或重命名該失敗版本。前10族236個global-free開發候選未同時通過。下一假說是固定格點忽略角色移除後會走到的細部位置；以兩個本次插值器的分歧選共同探測點，而非用LOO或pooled選點。

## 固定探測與模擬

正常custom30被動記錄signed模型回覆。初始共同5×5格點使用原查詢包圍盒外擴20%（同先前）。接著3輪共享精煉：每輪在當前分片線性代理上模擬所有完整角色移除，記錄全部代理查詢點；以同一回覆庫的linear與thin-plate RBF（degree1、neighbors32、smoothing1e-10）在這些點的逐模型預測平均絕對分歧排序，查詢最多12個新位置的全部原團隊模型。

候選先float32去重、排除已實查位置；分歧相同依位置字典序，batch內最近距離需>1e-3×初始共同格點包圍盒對角線。確定選點前不查原模型或pooled；候選不足12則如實少查，不補無關點。每輪所有成員共用新回覆，沒有在真實模型上逐人從頭跑。總共同新增位置<=25+36=61。所有代理仍是逐人反事實模擬，非嚴格非LOO。

3輪後以同一精煉庫分別用linear、RBF跑固定custom30，得到兩個已鎖定端點設定。固定原X0、box、target、剩餘alpha正規化、退火與mode語義，原歷史solver不改。保存分歧、查詢座標、原模型回覆與每輪模擬，不憑結果改輪數／query budget。

## 固定配分與比較

global-free分數共12種：原團隊mean_abs、median_abs、abs_mean_signed、abs_median_signed四種；以及已登錄的本次client局部degree1／2、各四種Q八種（128點、3個既有最低MSE提供者、ridge1e-6，X/observed_y/agent_ids限定，與alpha隔離）。兩端點設定共24候選，全報告。client資料回饋是額外可得性假設，不能混稱只使用原過程statistics。

另離線讀pooled評估鎖定端點，共2個offline_E診斷；不能混為global-free分數。truth不作任何方法輸入。score仍Q(z_i)-Q(X_full)，不翻號，不按情境換公式；同分留未定義、覆蓋不填0。

開發只原20團隊；已揭露的40新團隊不拿來當本方法確認或調參。分數先鎖再讀LOO，團隊內Spearman平均、seed bootstrap10000/RNG20261020，兩情境>0.5且覆蓋>=90%可選。按最小情境平均最大、其次linear最終代理、無client資料需求、degree1、方法名排序。offline_E若過而global-free未過，只支持離線代理路徑。

若有global-free候選通過，另在未見seeds2026102300–2319×兩情境40團隊確認；方法先鎖才生成新資料。確認兩情境平均>0.5、95%下界>0、覆蓋>=90%；不能用同一確認集換配置追門檻。

成本上限：20正常重放、原模型額外10000samples、代理全部模擬500次、CPU300秒、client觀測8000筆。原模型calls/samples、proxy CPU、client資料處理及傳輸分列，<=70%樣本門檻及端到端時間都需另核對；若CPU更高不能只說便宜。停止超預算、幾何／數值失敗保留，不能棄除不利案例。
