# 錨點池：多輪端到端、數值穩定與輸入複製驗證 v1

日期：2026-10-28。使用者授權：針對錨點池執行上一輪所提驗證。本文件於新模型推論前凍結。模型池、基本保障與原搜尋規則不變；僅影子比例，沒有付款。

## 1. 本輪主張與契約調整

只研究固定內部目標、原路徑累積當輪錨點作用。每輪從g扣同owner的H，不重配其他方向權重，保留所有模型，依原最多10次縮步／接受。S_i=Σ_t C^A_i,t，w_i=S_i（S_i>τ_i），否則0；q_i=w_i/Σw。固定預算500測試單位按最大餘數取整，餘數同分固定owner字典順序。

依使用者已明確選擇固定預算相對分配，本輪移除上一輪測試的Σw≥0.001釋出gate；它不再是經濟驗收條件。只保留數值可靠性死區。全無可靠正值則reserved／q=null／金額0；缺任何應計owner×輪次則held／q和金額null。模型資格為凍結的原owner名冊，本輪不由C反推服務品質；基本費另按T1。

τ_i=max(1e−8,Σ_t ρ_i,t)，ρ_i,t=max(1e−12,32*eps64*(1+|L_full|+|L_minus|))。此容差只覆蓋保存回覆之後的float64聚合／相減誤差，不是float32模型準確率、不同硬體、輸入擾動或隨機推論保證。

## 2. 固定資料與新增操作

只用既有兩個已讀CPU模型團隊：`budget_clean_2026101600`、`budget_controlled_poison_2026101600`，來源為10/27 pilot cases.json與其原模型hash。這是舊資料工程／機制驗證，不是新獨立品質確認；不開pooled、不讀真實truth、不訓練。

每團隊7次主搜尋：最小counter/digest控制2次（30輪上限）、完整觀察base／repeat各1次、輸入拆分adjacent／separated各1次、輪預算延長60各1次。所有原起點、a、v、模型、target、eta初始化、box與solver接受規則固定。錨點拆分是每個原錨點複製兩份，各權重減半，同owner、同總權重；adjacent將兩份相鄰，separated將所有第一份放前再放第二份，測浮點加總順序。K與M可不同，模型清單與v不得複製。錨點版本源於模型hash，identity不新增。

每個觀察run對所有實際輪、所有owner形成一個消融分支，包括拒絕、零方向、模式切換及最後停止輪。不只計原本接受的輪；端點用各自接受位置，不用最後拒絕trial。完整分支直接重用原run結果，避免另做完整分支推論；另用保存原始回覆獨立重播原solver核對。排除分支不回到主搜尋。

完整觀察raw API／evaluation／iteration與分支query/reply逐筆保存。所有分數在獨立核對後才稱通過。輸入拆分必須從真實模型重新查詢與跑完整搜尋，不能只把已形成H拆半。

## 3. 驗收

1. 完整鏈：原主搜尋counter/digest控制與base一致；base與repeat之結果、query digest、每輪C與q重現。base另與原pilot保存結果比對。應計槽位=實際輪數×固定owner數，無漏輪、重複或錯歸戶；原69組保存C只用作回歸核對。獨立scalar核對主搜尋raw回覆、狀態鏈及未插樁solver重播。
2. 分支：獨立Fraction／scalar從raw主回覆重建每anchor及每owner H，核對g、分支幾何、box、最多10縮步、接受、保留位置、mode／eta、原始所有模型回覆及C。共同尺全程固定。
3. 輸入複製：幾何與權重先證明同owner每來源總權重守恆；主搜尋結果x/loss絕對誤差≤1e−10、所有S差≤1e−8、連續q最大差≤1e−6（0.0001百分點）、整數金額完全相同。query數因新增duplicate查詢可以增加，不要求digest相同。原方向與mode／接受若分歧須完整列出，不刪資料或宣稱等價；失敗不改原solver，本輪完成診斷後停止候選升級。
4. 數值：保存API回覆以Fraction精確重算共同比較，報實際float64差與接受比較符號是否翻轉。對每C的±ρ作owner級最不利／最有利端點組合（2^owner，最多32），要求主可靠性壓力下資格不翻、max|Δq|≤1e−6且影子金額相同。另用固定每C±1e−8／±1e−6作壓力診斷，不把較大擾動稱實際已測誤差，不依結果選容差。逐輪正負近零不直接決定資格，只有累積後套τ。
5. 輪長：保存base每個prefix的累積S／q／總正淨值，報最後25%實際輪的變化及新增近零事件。60上限run與30上限run比對；若皆在30前停止，誠實列「無新增輪，未測得更長持續路徑」。不要求真實新增有效輪的q不變，也不把複製事件冒充拖長路徑。
6. 缺失／重播／順序及預算：人工移除槽位→held；改同槽為null→held；相同事件重播／逆序q和金額不變；偽造owner／衝突槽位拒絕；各人非負、Σq=1（可分配時）、Σ付款=500。全零／全負／零輪保留。獨立reference從原C槽位重新計算，不沿用生產net或q。

資料／程序完整性失敗立即保存failure並停止；方法效度或等價驗收失敗則繼續保存其他已凍結診斷，但標失敗，不自行修公式、補種子或啟動新模型。

## 4. 成本與交付

原先一般小試上限50外層輪不足以涵蓋重現／拆分／延長。本輪在執行前明列調整：總主搜尋實際外層輪≤250、新模型API≤100,000、主流程≤600秒、輸出≤250MB；單搜尋仍沿用原trace≤20,000samples及≤60秒。CPU單執行緒。原2團隊不增加。

成本拆：模型載入、兩次counter/digest控制、觀察搜尋、所有owner消融、計分／敏感度、寫檔；報api_calls/samples/unique、主要時間、最終bytes與Python/native/RSS可取得的範圍。cache不新增，unique僅統計，不冒稱已省呼叫。原主搜尋及baseline都含計數與digest，不稱裸搜尋；新工程目標不套用原低成本候選≤15%門檻，本輪是完整反事實離線基準。報代表base完整處理/最小控制時間比，明列CPU小樣本限制。
