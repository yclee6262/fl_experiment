# A、B、EU、EB、SU、SB：六方法聚焦比較

## 研究問題
以最終交付 X 的凍結 pooled evaluator 絕對目標誤差比較六方法；成本另外報告，不以權重符合直覺取代品質證據。

|方法|定義|
|---|---|
|A|每人 1/N|
|B|原 20 筆盲測個人 MSE 加 1e-5 後取倒數正規化|
|EU|0.5 最佳組合 w + 0.5 均勻 U|
|EB|0.5 最佳組合 w + 0.5 品質 B|
|SU|0.5 候選點支持度 s + 0.5 均勻 U|
|SB|0.5 候選點支持度 s + 0.5 品質 B|

w 是原 20 筆盲測混合預測 MSE 最小的非負 simplex 權重。s 使用其他模型對提出者候選點的絕對目標差距中位數，exp(-e/tau) 正規化；tau 是全部非自身差距中位數加 1e-5。三人時每個候選點有兩個評估者，中位數等於平均數。這裡的 SB 不相乘、不向均勻收縮，舊 QS 品質乘支持方案不列入。

## 固定流程
- 三種情境：乾淨、低品質 25%（噪聲只影響 local labels）、樣本量不平衡 4 倍。參與者固定 IDs 1、2、20，三人、2D、target 0。
- 同一案例共用原盲測、模型、proposal、凍結 pooled evaluator；box [-1,1]、可行容差 1e-8、best_of/custom30。
- 初始化後只倒推一次；不動態更新、不剪枝、不結算、不新增標記。
- pooled 在解交付之後才評分，不可作初始化、選人、選輪次依據；truth 僅作診斷。
- 原模型最佳組合的 SLSQP 數值失敗沿用既有 fallback 並記錄原因，不偷偷丟棄。

## 順序與樣本
1. 舊五案例來源做 pilot：三情境、六方法共 90 條件；測公式對齊、保存與重評。
2. 舊三批共 363 案例來源做探索：三情境、六方法共 6,534 條件；原結果不覆蓋，六方法重新求解於獨立目錄。
3. 未使用過的新資料：三批各 30 個案例，共 90 個 seed 抽樣單位、1,620 條件。重新產生 local 資料、模型、proposal 與 pooled evaluator，與探索和 pilot 分開；開始前查核既有 manifest/registration 的 seeds。

獨立確認固定 90 案例，沒有保證檢定力；小效果可能區間較寬。不能因不顯著宣稱等效。全部方法均保留，不依探索排名刪除。

## 分析
主要終點是每個 seed 的三情境 pooled 誤差等權平均。12 組事前比較：四候選各對 A/B 共八組；EB-EU、SB-SU、SU-EU、SB-EB 四組設計比較。差值為前者減後者，負值較好。

主要使用 200,000 次配對 bootstrap、分析 RNG 20261014，十二比較 Bonferroni 同時區間（每項約 99.5833%）及一般 95% CI。三批一般 95% 區間用 10,000 次抽樣；場景結果為探索性。

穩定優勢：同時區間全負、三批平均差全負、至少兩批一般 95% CI 全負、全部共同合格案例有有效配對，且觀察方法失敗不增加。要稱候選優於基準，須分別通過 A 和 B；不是平均名次第一就稱總體最佳。十二比較不包含所有候選的全部兩兩比較。

共同資格失敗在倒推前保存並保留，不補抽；品質結論以共同資格通過人口為條件，不能冒充完整招募流程表現。方法求解失敗、不可行解、共同準備失敗分開報告。失敗成本保留，未知不寫零。

## 驗收與產出
完整條件、無重複鍵；有效 X 全部 box 可行；來源及 artifacts hash 核對；重載矩陣、alpha 與 pooled 分數最大差 <=1e-7。來源模型與 evaluator 的 verifier 必須通過。保存逐列 X、alpha、原因、solver、初始化/Stage3成本、shared 成本與實驗來源；不把外部評分混入 Stage3。

交付來源封存、登錄、pilot、探索、獨立確認、重評、對照統計、成本、pooled/truth 衝突及本地/Notion同頁摘要。開頭執行曾遇到沙箱 OpenMP 共享記憶體限制，原錯誤保留；改於正常本機執行，數值設定不變。
