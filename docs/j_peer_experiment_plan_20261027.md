# J_peer 候選實作與固定資料比較規約

2026-10-27，執行前保存。使用者要求將J改為不採本人事後評分的做法並試效果。新增獨立候選J_peer，保留原J與完整LOO，不覆寫舊結果。

## 算法

對每個原完整團隊的實際輪前狀態，同時移除i的錨點及模型，依原規則執行一外層輪。端點沿用已凍結資料，不改方向、縮步、停止或原路徑。

評分面板只包含k≠i，剩餘原權重正規化為w_k/(1−w_i)。j_peer=dot(剩餘正規化權重,各模型在x_minus的絕對誤差)−dot(相同權重,在x_full的絕對誤差)。以這個先算兩個loss再相減的確切運算順序定義實作；J_peer按原輪序累加。正值表示其他模型認為i缺席較差，負值表示較好。沒有其餘有效模型、非有限或負權重、剩餘權重零時回報未定義，不作零分。原J直接沿用歷史原值。

J_peer不等於去掉i模型後重新跑原完整路徑；也不是i的模型角色因果貢獻。不同i使用不同評分面板，跨人的分數比較因此含評分者差異，必須揭露。單一同端點算法與前輪other_mean代數等價；既有診斷已揭露，不包裝成全新獨立成功。浮點運算可能改變少數並列，以本次固定實作為準，核對與前輪other_mean在1e-10內吻合。

## 固定資料與比較

20舊隊、5起點、5450分支、400參與者×起點。資料來源：j_loo_start_stability_experiment_v1_20261027、j_self_other_diagnosis_v2_20261027。全部來源receipt、報告、模型輸入與程式hash核對。不新增模型、搜尋、pooled推論或訓練。

1. 累積主要比較：原J與J_peer各對同起點完整內部LOO D_L的rho、參考非零符號一致率、NMAE。分母與epsilon=1e-4保持相同，不裁負分或翻號。報相同隊／起點的配對差。
2. 離線品質：各對同端點累積J_E及全程D_E的rho、符號一致率；單輪用固定|j_E|>epsilon分母比較方向，近零算未命中。pooled不參與任何計分或選擇。
3. 跨起點：每隊10起點對的排名相關、兩端皆明確非零的翻轉率及有效對覆蓋。起點敏感不等於條件貢獻計算錯誤。
4. 成本：基於保存請求序列精確重建單次部署模型呼叫次數；baseline不省略原重複，只有本次baseline及本方法自己的精確float64模型／輸入可快取。原J決策請求保留；只將事後共同計分面板改為peer面板。逐筆重建cache命中，含baseline。先以原完整評分面板重建並精確重現原J成本，再算peer。這是確切查詢帳重建，不是新增實測時間或總RAM，不宣稱API加速。

## 聚合及判讀

先每隊每起點計算，再隊內有效起點平均，再情境10隊等權；bootstrap10000次、seed20261027、95%探索區間，團隊為重抽單位。原J各對照需重現前輪同口徑結果。完整LOO替代探索篩選：兩情境各>=8隊，rho>=.8下界>.5、方向>=.85下界>.7、NMAE<=.25上界<.5，查詢總成本<=完整LOO70%。局部外部品質篩選：單輪方向>=.85下界>.7，當輪rho>=.8下界>.5，排名輪覆蓋>=80%。跨起點穩定：rho>=.8下界>.5，翻轉<=.1上界<.2，有效排名對>=80%，各項>=8隊。
