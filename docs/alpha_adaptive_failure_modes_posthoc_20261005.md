# 自適應 α 正式結果的失效機制：事後診斷

這份分析只用於產生下一版假說。seed 3567 因資格失敗沒有候選；以下分母是其餘 179 個有效 seed。正式方法、0.01 門檻與正式失敗結論均不更動。逐 seed B／Uniform pooled 分數只在方法決策結束後讀取；這份事後分析不能視作部署時可取得的訊號。

目前的觸發規則是「B 的 B20 校正內部 target 誤差 > 0.01」。它觸發 **88/179** 次，但觸發時 Uniform 的 pooled 品質真正優於 B 的只有 **29/88（33.0%）**；未觸發的 91 筆中，Uniform 事後反而也有 **31/91（34.1%）** 較好。也就是說，這個 B 絕對誤差門檻**沒有在本批資料中富集「Uniform 值得求解」的案例**。

88 次額外求解中有 **55 次**最後仍交付 B，這些 Stage 3 請求沒有改變交付 X；55 次裡有 7 次 Uniform 事後 pooled 品質較好，但 B20 內部選解未選它。另有 **33 次**改交付 Uniform，其中 22 次 pooled 改善、11 次變差。觸發案例中，`Uniform−B` 內部分數差與 pooled 誤差差的 Spearman 相關約 **0.738**：內部排序有訊號，但不足以避免錯選或漏選。相關性是在已看過的資料上計算，不能推論新 seed 的選解保證。

作為純事後參考，若 179 個有效 seed **每次都求 B 和 Uniform**，並沿用 B20 內部選解，平均 pooled 差 `兩候選−B` 為 **−0.000844**，描述性 95% 區間 [−0.001698, −0.000023]；相對已登錄自適應法平均再改善 **−0.000149**，描述性區間 [−0.000527, +0.000197]，但平均請求會由 **531.02** 增至 **702.67**。這個「總是兩候選」是看過正式資料後才計算的反事實，**不是正式通過結果**；它多花約 171.65 次請求的品質收益尚無穩定證據。

下一版應優先研究**是否值得做第二次求解**的事前訊號，而非只調整 B 的絕對 target 誤差門檻。可用資料須限制為 Stage 0 labels、B α、proposals、B 的 X、local-model predictions 和內部校正不確定性；pooled 分數不可用於當次觸發。先在舊資料上固定一個簡單規則及呼叫成本，再以全新 seeds 同時檢驗 pooled 品質、觸發率、錯選／漏選、失敗率與尾端退步。若沒有可重現的品質或成本收益，保留單次 B 基準。
