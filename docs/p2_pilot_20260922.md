# P2 五種子 pilot 結果（2026-09-22）

## 實驗定位

本次是 seeds 0–4 的功能與方向 pilot，不是 30-seed 正式研究結論。比較固定 coalition 下四種方法：

- A：Uniform，不更新 α。
- B：Stage 0，不更新 α。
- C：Uniform 起始，固定步長 0.5。
- D：Uniform 起始，Guarded、初始步長 0.5。

Clean 使用 Stage 1 coalition 與 uniform 內部 evaluator；Poison 使用 5 人受控 coalition（固定含 1 名污染者）與 trimmed evaluator。兩者皆為 2D、target 0、最多 20 rounds，未啟用 pruning。每個 seed 的四種方法共用 local models、候選點、coalition 與凍結 pooled global evaluator。

原始輸出：

- `alpha_weight_outputs/p2_pilot_clean_20260922`
- `alpha_weight_outputs/p2_pilot_poison_20260922`
- `alpha_weight_outputs/p2_pilot_analysis_20260922`

兩個實驗 manifest 都為 `complete`；各有 20 個條件。40 個 accepted X 全部通過 box check，重載 evaluator 後重評皆為 `mismatches=0`。Clean 20/20 有有效 q；Poison 17/20 有有效 q。

## 對 A 的配對結果

- Clean D：外部誤差平均差 `+0.000109`，真實誤差平均差 `-0.000346`。兩種評估方向不完全一致。
- Poison D：外部誤差平均差 `-0.004363`，真實誤差平均差 `+0.000763`。兩種評估方向相反。
- Poison C：外部誤差平均差 `-0.000260`，真實誤差平均差 `-0.002909`，但只有 5 個 seeds，區間仍跨零。
- 動態方法的平均查詢量約為相同情境靜態基準的 12–20 倍。

所有 bootstrap 結果均標記 `pilot_only`，不得使用 5-seed 信賴區間宣稱穩定改善。

## Evaluator 稽核與判讀

凍結 pooled neural evaluator 在五個 seeds 上，對帶噪音 test labels 的 MSE 約 0.0025–0.0028。進一步對無噪音合成真實函數稽核：

- test truth RMSE 的五-seed 平均為 0.01175，最大為 0.01457。
- accepted X 上，Clean 的 evaluator／truth 分歧中位數為 0.00336、最大 0.01666。
- accepted X 上，Poison 的分歧中位數為 0.00512、最大 0.01854。

這個 evaluator 誤差與方法間差異處於相近量級，因此足以改變方法排序。此問題必須在正式報告中揭露。

2026-09-22 研究口徑已確認：**正式實驗以 frozen pooled evaluator 為主要品質判準，合成真實函數為次要診斷。**兩者衝突不阻擋正式實驗；主要結論依 pooled evaluator，並同步報告真實函數與 evaluator／truth 分歧。

## 本次結論與下一步

目前只能形成以下 pilot 結論：

1. A–D 配對流程、artifact 保存、重評及分析工具可以完整運作。
2. 動態 α 更新成本顯著高於靜態基準。
3. 5 seeds 不支持「α–q 收斂即可代表 X 改善」；Poison D 甚至呈現外部 evaluator 與 truth 相反的判讀。
4. 正式判準已固定為 pooled evaluator；真實函數不取代主要判準，但用來呈現 evaluator 代理品質的限制。

下一步可執行 seeds 100–129 的 P2 正式比較；P3 的完整參與者移除反事實工具則可在正式比較後依序進行。兩者報告都必須並列 pooled evaluator 與 truth，且只以前者作主要品質判準。
