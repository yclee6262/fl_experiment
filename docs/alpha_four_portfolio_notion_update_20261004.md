## 10｜四候選初始 α 組合：少一次倒推的成本／品質測試
**目的與定義**：原五候選會用 A（Uniform）、B（Stage 0 品質）、MSE power 1.5、Corr precision 0.5、Target-local precision 各做一次 Stage 3。四候選事前省略 **Target-local precision**，保留其餘四組 α；仍用相同的 B 權重全域 ridge 殘差校正分數，在四個可行 X 中選交付。最終 α 就是被選中的那組，不是四組平均。pooled／truth 都不參與省略決策或選解。

經濟問題是：少買一次候選倒推，能否用較少模型請求保留接近原五候選的 X 品質？這是資訊取得成本與品質的取捨，不是付款或公平分潤。配對研究為比較仍執行第五次求解，但四候選的「方法單獨執行成本」只計自身四次 Stage 3；共用準備成本另計。

### 開發與 pilot（不能當正式優勢）
- 在已用過的 210 seeds 上從固定及依 α 差異度挑候選的方案中選出固定四候選；描述性 pooled 差（四減五）平均 +0.000168、約少 370 次請求。這些資料曾用於選法，區間不能當獨立驗證。另試的平滑偏差校正（多項式、局部平均、RBF）在四批舊資料中沒有跨批次一致的品質改善，不進正式實驗。
- 5-seed pilot：20／20 條摘要條件有效、10／10 次選擇可重算；A、B、原五候選的解與舊 pilot 完全一致。四候選／五候選平均 pooled 誤差 0.013377／0.014757，方法請求 1636.8／2031.0。這只確認流程和計數。

### 事前登錄的正式比較（seeds 900–1019）
事前固定 **120 個新 seed**、同一乾淨二維三人情境。成本／品質門檻：全部 120 個有效配對，四減五的 pooled 配對平均差之 10,000 次 bootstrap 95% 區間上限小於 **+0.0005**、平均模型請求至少少 15%，且無較高失敗率。`0.0005` 約為開發基準平均誤差的 3%，只是研究容忍度，並非已驗證的業務門檻；若區間上限小於零，才另稱嚴格品質改善。

正式資料 **480／480 條件完整**、兩方法各 120／120 有效、240／240 次選解重算通過，15／15 個來源雜湊相符。原五候選／四候選平均 pooled 誤差 **0.014956／0.015169**；四減五配對平均差 **+0.000212**，95% 區間 **-0.000210 到 +0.000721**。四候選較好 11、相同 102、較差 7；pooled／truth 的逐 seed 排序方向衝突 6／120。

四候選平均模型請求 **1450.575**，原五候選 **1814.975**，每條件少 **364.4 次（20.08%）**；本機方法內平均耗時 0.103818 對 0.127202 秒。若每次請求成本 `c`、每降低一單位 pooled 誤差的價值 `v`，只以這批平均差計，四候選損益平衡需約 `c/v > 5.82×10^-7`；尚無實際價格可證明淨收益。

**判定：未通過。**品質差的區間上限 +0.000721 超出事前的 +0.0005，嚴格品質改善也未建立。查詢節省成立，但無法說品質損失已被限制在預設範圍；原五候選維持主方案，依規則不擴到複雜情境。不得事後放寬門檻後重新宣稱本批通過。
