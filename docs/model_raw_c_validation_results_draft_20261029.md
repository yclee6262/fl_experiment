# Raw C 多輪、補充作用與尺度診斷結果草稿

日期2026-10-29。設計：`docs/model_raw_c_validation_design_20261029.md`。正式封存：`contribution_analysis/model_raw_c_validation_20261029_attempt_03/`。attempt_01/02保留；03增加來源快照、測試報告及原事件方向單位檢查，沒有換案例或改定義。

## 已完成

全程只使用原事件及歷史score；未讀diagnostics或使用fixture內reference，0新solver/model/reference查詢。原來源373個receipt檔案及歷史198檔均核對SHA256。78案、157輪、441 owner-round；所有資料都曾探索，原new_heldout只是來源標籤。7個單元測試通過；來源及設計封存，執行約1.1秒，低於120秒及200MB上限。

實作邊界：帳務矩陣缺owner-round、重複或必要分數非有限時held，amount/reserve=null；原事件缺少endpoint loss或回覆互相矛盾時，目前拒絕整批而非產生個案held。本來源全端點完整，因此未影響上述結果。這一點與設計所列「缺漏held」尚有實作差異，不宣稱endpoint缺漏held已完成。

C是同一完整原始目標的F(minus)-F(full)，包含受評模型、沿用正規化原權重，未除模型尺度。以原loss的Fraction逐模型差加權為production，並用直接float F差核對。先有號跨輪累積，再用tau=max(1e-8,T*1e-10)及最大餘數整數分配，子額度不互轉。

## Raw C多輪結果

78案67分配、11全保留。204個case-owner累積128正、2負、74近零。62單輪中52分配；16多輪中15分配、1保留，多輪48個owner中35正、13零、0負。

有6個owner同時出現正輪及負輪，皆抵銷後仍累積正。74個近零owner全部每輪full/minus端點相同，屬本路徑冗餘；沒有不同端點但等F，也沒有抵銷後近零或微量死區案例。這不能說明永久無價值。2負都位於new_seeded_noise_0_1的owner_a、owner_b（各約-0.00894656）。舊46案raw分數、整數分配及reserve均重現歷史40分配/6保留。

128正分中126獲整數獎金；另2個原本已被辨識為正，因相對比例很小得到0整數額度，不能稱漏辨識。

## 固定端點尺度診斷

全體同乘單位234控制、單模型單位搭配v補償612控制，都保持原相對分配與累積符號，未見tau資格例外。單模型乘尺度而不補償612控制中412變分配、406變符號；這是改了F的相對重要性，屬目標敏感度，不判為算錯。所有控制保留變換endpoint losses、v、Z及C；補償只是離線單位換算測試，不更新原alpha或搜尋。

另外由原events重建方向的1323個單模型單位控制，最大g誤差2.22e-16、最大去重U誤差2.22e-16；固定endpoint下I不變。

原始資料未遇tau例外，不代表完全單位不變：人工C=5e-9在原單位被保留，同乘10變5e-8後可領500。絕對門檻對極小量有單位敏感性，例子存threshold_examples.json。

## 判讀邊界

這次支持raw C與已指定的原完整內部F方向一致，以及這批多輪資料的有號結算可執行；它不是外部品質、實務泛化、完整participant-removal或full-LOO的有效性證明。C-only可保留為此內部目標的主候選；U/I/N應作作用描述，不能由本次結果主張N穩定改善品質。未研究自評操弄，未改主算法、原輸出或Notion。
