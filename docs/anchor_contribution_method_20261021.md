# 錨點貢獻計算方法：目前採用版本

日期：2026-10-21。依使用者確認維持既有設計，本文整理方法與解讀，不修改公式、程式或實驗結果。

## 1. 目的與名稱

方法名稱：**固定原搜尋軌跡的當輪錨點 LOO，累計單步局部增益**。

每次問：在目前位置、目前方向估計模式與原實際接受距離下，如果這一步少了錨點 i 的方向作用，內部 loss 會高或低多少？

研究輸出包含各步分數與跨步總和。目前總和是「累積單步錨點增益」的描述性指標；後續作用反轉不會抹去當步紀錄，但總和未經驗證為最終品質貢獻。模型貢獻、基礎保障與分潤留待其他研究。

## 2. 原搜尋與離線計分的關係

原 custom 使用全部錨點產生方向、試走、縮步與接受更新。原路徑固定後，離線計分器逐步建立排除錨點的影子分支。它只試走一次，額外模型回覆不回寫原搜尋。下一步仍從原完整團隊走到的位置開始計算。

目前只計原搜尋**已接受更新的迭代**。原搜尋可能在同一迭代拒絕數個試步後接受較短的一步；計分取最終接受的那一步。整個迭代未接受更新則跳過，不能宣稱已涵蓋拒絕／停止資訊的價值。

## 3. 符號與評分尺

| 符號 | 意義 |
|---|---|
| I_i | 錨點 i 的位置 |
| f_j | 原完整團隊的評分模型 j |
| y_target | 問題的目標值；既有實作與實驗為0 |
| α_j | 模型評分權重，兩分支固定相同，合計為1 |
| a_i | 原方向組合中的錨點權重，合計為1 |
| x_t | 原搜尋該步之前的位置 |
| x_(t+1) | 原完整團隊實際接受的位置 |
| s_t | 原實際接受距離 ||x_(t+1)-x_t|| |
| v_it | 原錨點 i 對合成方向的向量分量 |
| g_t | 全部錨點分量總和 Σ_i v_it |
| c_it | 錨點 i 在該步的內部局部增益 |

內部評分尺：

L(x)=Σ_j α_j |f_j(x)-y_target|。

L越低越好。兩個分支都保留原完整模型集合及α。排除的是錨點方向，該錨點提供者的模型仍參與評分。

pooled不進L或分數，只在試走結果鎖定後作離線品質診斷。truth不作計分。α與a概念上是不同角色；原custom這批設定使用相同權重，不能一般化為兩者必須相同。

## 4. 錨點如何參與原方向

若 ||I_i-x_t|| 足夠大，原程式形成單位方向 u_it=(I_i-x_t)/||I_i-x_t||，再以原模式算斜率 b_it：

- secant：b_it=[L(I_i)-L(x_t)]/||I_i-x_t||。
- dynamic：從x_t沿u_it作小幅、盒內可行探測，距離h_it；b_it=[L(x_t+h_it u_it)-L(x_t)]/h_it。

該錨點的原方向分量為 v_it=a_i b_it u_it；合成 g_t=Σ_i v_it。custom沿 -g_t/||g_t|| 試走，再依內部loss判斷是否接受及是否縮步。原方法的eta會調整，因此不是整段固定步長。

貢獻計分重用已保存的 v_it、g_t及模式，不另外估新梯度或訓練替身模型。

## 5. 單步排除與計分

對每個原已接受步、每個錨點i，依序執行：

1. 固定x_t、原模式、全部評分模型、α、其他錨點既有分量與原接受距離s_t。
2. 移除v_it並將剩餘方向權重正規化：g_(-i,t)=(g_t-v_it)/(1-a_i)。
3. 若剩餘方向有效，產生z_(-i,t)=x_t-s_t g_(-i,t)/||g_(-i,t)||。兩邊使用相同實際移動距離。沒有為替代分支重跑退火。
4. 用原完整模型面板計算L(z_(-i,t))。
5. 若L(z)<L(x_t)，替代有效結果是z；否則拒絕試走，替代有效結果是x_t。
6. 單步分數：c_it=min{L(x_t),L(z_(-i,t))}-L(x_(t+1))。

也可用「改善量」理解。原步改善G_t=L(x_t)-L(x_(t+1))；排除後改善G_(-i,t)=max{0,L(x_t)-L(z_(-i,t))}，因此c_it=G_t-G_(-i,t)。

正規化後方向只比較角度，原方向向量大小不直接決定試走距離。固定s_t使本方法聚焦同距離方向作用，不完整衡量錨點改變退火步長或停止決策的效果。

## 6. 正負值怎麼解讀

- c_it>0：有該錨點時，當輪內部改善較多。
- c_it<0：排除其方向後，當輪內部改善較多。
- c_it=0：在這個局部比較下，兩個有效結果的內部loss相同；可能是方向重複等情形，不能推論沒有所有形式的價值。

負c與舊「方向投影為負」不同。投影為負只說方向相反，可能有煞車作用；當輪LOO則比較實際loss。若煞車確實使同距離的完整步優於排除步，這裡會得到正分。若保護效果出現在後續、外部品質或不同退火選擇，這個分數可能尚未涵蓋。

原始計算保留完整signed數值，不用deadzone把它改為0。先前分析的±1e-4只用於正／負／近零分類與穩定性診斷，與solver的嚴格改善接受條件不同。

## 7. 數字例子

假設原位置L=10，完整團隊接受後L=7，原步改善為3。每次單獨排除一個錨點，互不累積排除：

| 當輪排除 | 試走L | 有效L | c | 解讀 |
|---|---:|---:|---:|---|
| A | 9 | 9 | +2 | A讓當輪多改善2 |
| B | 6 | 6 | -1 | 排除B能再多改善1 |
| C | 11 | 10 | +3 | 排除C後無法改善，留原位 |

C的分數是10-7=3，不是11-7=4；被拒絕的壞點沒有真的交付。

這三個分數合計4，雖然原步只改善3。各錨點LOO是不同反事實，彼此可能互補或重複，因此不是總改善的不重複分配。

## 8. 跨步累計與輸出

令T_acc為原搜尋已接受步集合：

- A_i=Σ_(t∈T_acc)c_it：淨累積。
- A_i^+=Σ max(c_it,0)：正向累積。
- A_i^-=Σ min(c_it,0)：負向累積，保留負號。
- A_i=A_i^++A_i^-。

例：某錨點三步為+2、-0.4、+0.1，則正向累積2.1、負向累積-0.4、淨值1.7。

不再乘步長、loss改善量或時間權重，不取絕對值、不截除負分，也不正規化成付款比例。c已經是實際試走後的loss差，再乘步長會額外偏重長步。

建議閱讀輸出時同時看：原已接受步數、可比較步數、缺失狀態、正向累積、負向累積、淨累積，以及逐步明細。淨值相同不表示正負抵銷程度相同。不同任務的loss尺度、接受步數與原路徑不同，目前不直接跨任務比較淨總和。

程式對應：`comparisons[].J`為c；`A`為完整淨累積；`A_positive`、`A_negative`為正負累積；`A_partial`為已有比較的部分和；`missing_steps`與`status`保留完整性。

## 9. 特殊狀況與快取

| 狀況 | 目前處理 |
|---|---|
| 剩餘方向norm≤1e-8 | 不移動；有效loss為L(x_t)，c等於原步改善 |
| 沒有剩餘方向權重（例如唯一錨點） | 未定義，記錄缺失 |
| 等距試走超出[-1,1] box（容差1e-8） | 不可比較，不裁切或另縮步，不填0 |
| 原迭代沒有接受步 | 跳過；不是把各錨點分數設0 |
| 全程沒有接受步 | `no_accepted_steps`，完整A不可用 |
| 任一必要比較缺失 | `incomplete_steps`，完整A不可用，保留部分和與缺失明細 |
| 模型回覆缺少、形狀錯誤或非有限 | 檢查失敗，不當成有效0分 |

原型在當前迭代內重用已有完整模型回覆，使用float32輸入鍵，對相同鍵的衝突回覆作檢查；未命中時評估全部模型。這是查詢節省，不改分數公式，亦不是跨模型或歷史資料的學習估計。

## 10. 成本與實作範圍

若m個錨點、m個模型、T個接受步，未命中快取時每步最多m個替代位置，各需m個模型評分，工作量約T m²個模型輸入評估。影子分支只試走當步，不接續整條搜尋。

既有20團隊資料：baseline8,448、單步歸因新增3,839，合計12,287；相對baseline增加45.4%。同批baseline加完整參與者LOO合計33,120，本方法合計少62.9%。這是已測小型設定的結果，非一般規模保證。

目前`local_anchor_step_v1/kernel.py`對新回覆取abs，對應target=0，且以case中的alpha當作方向移除正規化權重；已測設定相容。概念公式可寫出一般target與a，但不能宣稱現有程式已支援任意target／a≠α。推廣須另立版本驗證，不修改歷史結果。

## 11. 已知驗證與目前採用決策

**已完成：**原計算與狀態重建驗證；992組比較與96個短程分支核對通過；既有小型成本記錄。詳見[驗證結果](anchor_step_validation_results_20261020.md)。

**未建立有效性：**總和代表全程品質、比較步長穩定、全部拒絕／停止活動、外部品質一般代表性與跨場景泛化。半步敏感與短程延續未通過原門檻，結果保留。

**目前採用決策：**依使用者確認維持原c及signed總和，將它作為已接受步的局部作用帳本。後續效果變化不回頭重寫當輪分數，亦不將總和宣稱為已驗證的最終品質歸因。本次僅詳細文件整理，沒有新實驗或公式調整。
