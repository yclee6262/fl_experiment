# 錨點池候選：抽樣 C^A 與方向資源 R 實驗設計
日期：2026-11-03。狀態：設計完成，尚未執行。依使用者決策暫停模型池研究，排除直接解選項價值 Q。本輪不改基本池、不結算真實獎金、不修改Notion、alpha或原搜尋。

## 1. 目標與比較邊界

候選一維持原錨點價值定義，以較少移除分支近似完整有號累積C^A。候選二改用原路徑方向資訊，支付「提供不易替代的方向資源」，不是改善品質估計。兩者分開驗收；不得把R和C相關性高當成經濟正當性，或要求R一定逼近完整LOO。

主要參考為現行完整錨點C^A，而非完整參與者LOO。LOO只作成本參考。錨點池固定500研究單位，已知全部資料時先累積有號分數，再按可靠正淨值分配；缺資料held、沒有可靠正值reserved，最大餘數取整、owner ID破同分。不把抽樣未選到輪次誤標為資料缺失。模型池停止推進；錨點池單獨便宜不代表未來完整三池必然勝過LOO。

## 2. 候選 S：均勻抽樣 C^A

完整參考 C_it=F(x_minusA_it)-F(x_full_t)，S_i=sum_t C_it。保留所有評分模型，只扣owner已形成方向分量H_i，其他方向權重不重配；完整與移除分支依原縮步／接受規則，移除只跑當輪。

主版本採完成原搜尋後的離線抽樣。已知實際T輪（包含拒絕、模式切換、停止輪），按固定種子均勻不放回抽k輪，所有owner共用同一抽樣輪集合。k=max(1,ceil(p*T))，p∈{0.10,0.25,0.50,0.75}；p=1作回歸控制。T=0保留池，不抽樣。抽中每輪的所有owner皆計算，不能因分數或預期正負挑人或換輪。

每輪納入機率π=k/T；估計 S_hat_i=(T/k)*sum_{t sampled} C_it。固定路徑下S_hat對S無偏，但取正值、資格判斷及正規化後的獎金不保證無偏，必須直接驗證分配。

使用完整參考同一凍結數值門檻tau_i=max(1e-8,sum_t rho_it)。離線重算時使用已保存的參考tau僅限統計對照；實際稀疏執行不得免費取得未抽輪移除loss或rho，須事前規定可由baseline資訊取得的保守算術界，或另報固定tau=1e-8的獨立版本並兩邊同用。工程階段若無可審核的界，停用自適應tau作部署主張，不偷讀完整分支。抽樣不確定性與浮點容差分開報告，不能靠放寬tau掩蓋抽樣錯誤。

每人權重=max(S_hat,0)且須超過所用tau；所有人皆零時reserved。共用樣本讓成員比較條件一致，但仍可能漏掉稀有關鍵輪。先不自適應抽樣，不依看過的C增加樣本。

## 3. 候選 R：方向資源報酬

有效錨點方向 u_kt=(z_k-x_t)/||z_k-x_t||，沿用原搜尋距離與邊界步長有效條件。對owner i的錨點k，r_kt=min_{l:owner(l) != i} ||u_kt-u_lt||/2。方向同向為0，相反為1，介於0與1。即使反向，也只表示不同，沒有品質正負。

owner分數 R_it=sum_{k owned i, valid} a_k*r_kt，其中a為凍結的原方向權重。不按錨點數量另加獎；同owner同位置複製且權重守恆拆分應不變。使用原權重代表支付已投入方向資源的加權獨特性，權重本身不由貢獻結果調整。這是預先選定的owner聚合方式，不改成事後最有利的max。

若owner沒有有效錨點，R_it=0；若整輪沒有有效方向，該輪R全為0。存在有效方向但沒有其他owner的有效方向，最近鄰未定義，標null、整案R池held，不任意賦予滿分。

跨輪使用平均 R_i=(1/T)*sum_t R_it，T=0 reserved。平均避免單純輪數倍增使原始分數變大，但不宣稱能抵抗操控搜尋路徑；同一任務正規化分配下平均和加總比例相同。完整有效資料時按可靠正R比例分500，沒有正R則reserved。此為影子資源報酬，不與C混合，不加入額外品質探測。

R使用方向幾何與既定權重，不需模型新評分、不用25點尺度、也不用移除分支。相同方向不同距離在R視為可替代，這可能漏掉割線距離提供的不同資訊，列為必要測試。

## 4. 第一階段：純離線抽樣與公式測試

資料：20個已讀歷史團隊251輪1033 owner-round，來源method5_cost_experiment_20261030_attempt_04。兩個seed00團隊作工程回歸，與主要seed10–19團隊不重疊。全部仍是舊資料探索，不能稱獨立確認。

先核對封存及來源、完整C^A、owner槽位、原始方向有效條件；讀取層把可用baseline和完整移除參考分離。抽樣器只收到允許的抽中C，不得存取未選分數。R計分器只收到baseline錨點、權重、owner、輪前位置及方向有效資訊。

每隊每個p用2000個固定種子（0至1999）離線重複；同一seed生成輪次隨機排列，較高k取相同排列前綴以配對。這些是抽樣實現，不能算2000個獨立團隊。先封存種子與規約，依結果不補seed。

S指標：每人S_hat分布及偏差、正負／近零資格一致率、正C漏發與負C誤發、每案q的總變差TV=0.5*sum_i |qhat_i-q_i|、最大個人份額差、整數金額差、reserved狀態一致。某一版本reserved時，將「保留款」增列成分配向量的一個分量，避免任意將null比例填零造成假相似。若held不混入TV，單列失敗。

R指標：非零／reserved／held、集中度、最大個人份額、同owner權重守恆複製、重排／重播等價、幾何微擾敏感性。C^A僅為作用診斷，另列R正且S^A負者的影子付款，直接呈現「資源不同但端點作用不佳」的取捨，不靠截掉這些案例美化結果。

必測手算：單一關鍵輪、強正負抵銷、全零／負、T=1/2/3的小輪數、微小可靠正值、同方向不同距離、零方向、只有一個有效owner、owner多錨點、反向錨點、等權／不等權、精確複製與權重守恆拆分。均用獨立Fraction或Decimal參考，不使用實作自己產生標籤。

## 5. 第二階段：凍結機制案例

沿用T2已保存48個解析設定作開發機制重播，不稱新保留。涵蓋正向有益／有害、反向有益／有害、共線無作用、全部拒絕、邊界、抵銷。R必須呈現這些類別，不以只有正向成功案例作驗收。

在執行前另外寫死成對新參數：至少各類2案，共16案；參數、原函數、起點、權重與預期機制先由獨立解析計算建立後封存，原solver執行後不得換掉不符預期者。未列明實際參數及獨立預期前，不允許自稱完成新保留設計或啟動該部分。

關鍵檢查：幾何完全相同而loss曲率不同的有益／有害配對，R應相同。這是辨識上限的預期證據，非程式bug；如果研究要求「只獎勵改善品質」，純R因無法區分這種配對就不能升級成果獎金。若願意支付方向資源，則保留為另一付款理由，請使用者在看完具體錯配與份額後決定，不自動改變契約。

抽樣C另外用預先寫死的多輪帳務序列測漏掉稀有制衡及正負抵銷；這些僅測抽樣統計，不偽稱原solver產生。真實多輪行為依20團隊回放，兩類證據分開。

## 6. 第三階段：真實稀疏執行與成本

先完成離線診斷，僅將通過分配穩定門檻的最低p作候選；若沒有通過，結論為當前抽樣預算不可用，不事後改門檻。候選在同一資料的成本重跑屬工程確認，不是獨立分配效度。

同隊、同機、同原solver、空白獨立快取：
A完整錨點C；B實際只執行抽中的錨點分支；C原搜尋+R；D完整參與者LOO成本參考。全部包括一次原搜尋、必要觀察與分配，不執行模型池C/U/N。各臂可重用自身baseline及自身分支，不能免費拿完整C回覆。未抽輪不執行消融。主候選種子預先固定0/1/2，不選最省seed。

一暖機三次交錯計時；報實際模型樣本、邏輯查詢、快取命中、baseline與額外成本、核心/必要輸出時間。R須零額外模型樣本但統計時間全額記錄。抽樣成本不直接按p乘完整成本，因快取與縮步會改變實際開銷。隔離程序記憶體可後補，不使用共用程序ru_maxrss當每臂增量。

兩角色完整流程尚未重測，不能將錨點單池節省外推三池總成本。分析不得改alpha、主搜尋接受規則或停止條件。

## 7. 事前驗收與停止條件

共同硬門檻：來源hash、固定完整baseline數值與查詢序列（忽略不影響回覆的快取執行差異）、分數重現、資料完整性、預算守恆、獨立帳務核對全部通過。任一硬失敗保存並停止升級。

抽樣C研究候選門檻（本設計建議，不歸因老師）：在乾淨與污染各自10隊中，每隊2000種子至少95%的影子分配TV<=0.05，且最大個人份額差<=0.10；reserved狀態一致率>=95%。可靠非零S符號一致率每隊>=95%，近零另報。同時實際額外模型評分至少比完整錨點C少30%，整體時間不得增加。這是探索篩選條件，不是公平性定理。若只有部分團隊過，明列適用範圍而不稱普遍通過。

R工程門檻：無額外評分、同owner等價拆分／重播不變、所有邊界正確標記。經濟門檻分開：原方向資源的零/高分是否符合預定定義；如果無作用或有害方向獲得集中獎金，必須呈現而非調參掩蓋。單憑R技術通過不表示適合錨點成果池。

研究上限：離線與合成每階段180秒/100MB；真實模型階段120萬推論/900秒，超額保存部分結果並停止。不新增模型訓練、pooled、truth或真實付款。新目錄exclusive-create，保留全部失敗版本。
