# 共享代理路徑的獨立離線驗證登錄

2026-10-20。開發16個coalition品質分數、32個固定分散面板品質分數均未在兩情境達到0.5。這些失敗保留；global-free配分尚未成立。本輪驗證另外一件事：代理能否在較少模型查詢下產生足以近似完整移除品質排序的端點。

固定單一方法：原正常custom signed回覆記錄＋原查詢包圍盒20%外擴9×9格點＋Delaunay分片線性多模型代理（凸包外nearest並記次數）＋原custom30在代理上完整角色移除。選linear9理由：開發離線相關0.80/0.68，同最低情境相關下Clean較高，且CPU小於RBF；沒有改正負或新擬合係數。該方法仍逐人作代理模擬，**不是嚴格非LOO**。

## pooled界線與本輪可證明之事

所有proxy與真實LOO解先鎖定，才讀凍結pooled逐解評分。離線C_proxy=E(z_proxy,-i)-E(X_full)，參考C_LOO=E(X_full,-i)-E(X_full)。pooled只驗證已產生解，不進alpha、求解、選點或刪人。這個C_proxy可作離線低查詢基準，**不能當成不用pooled的部署分數**；即使本輪通過，也不宣稱老師希望的完全由過程statistics得貢獻已達成。global-free主目標仍保留，不把offline驗證混為通過。

## 固定新資料與驗收

新seed2026102200–2026102219，各Clean與controlled_poison，共40團隊；資料、20個local models與pooled新建，沿用既有固定資料生成／訓練／coalition與uniform alpha設定，不研究alpha初始化。保存來源快照、每案語義資料hash；不得與舊seed資料重複。資格失敗、準備失敗皆保留，不換seed補樣。

每案同X0、target0、box[-1,1]、custom30。真實參考同時刪模型、候選、alpha並正規化，保留解與history、calls/samples/時間。全部資料準備完、全部proxy端點完成、全部真實參考解完成後，才離線算pooled；不得中途查看效果決定停留種子或調方法。

主指標：每情境平均團隊內Spearman >0.5、seed-bootstrap10000次RNG20261020的95%下界>0、有效覆蓋>=90%（至少18/20團隊）。下界>0.5另外報告，不能與點估計過0.5混稱。兩情境各自驗收，不用混合總平均遮住其中一邊失敗。完全同分留空、不填0；C範圍<=1e-4另外揭露。另報signed方向一致、端點距離、C差值及品質變化，不調方法。

成本：正常solver一次、共同格點探測、代理CPU、pooled離線評估與真實LOO參考分列。相同normal+proxy的模型samples需<=normal+LOO的70%才通過樣本成本門檻；實測時間另配對驗證，不能以樣本減少自稱時間一定降低。準備成本屬共同研究資料生成，不是算法部署每次需重訓。

上限：40資料準備／每案120秒、準備合計1800秒；40正常solver＋最多160真實LOO＋160代理模擬；所有參與者模型查詢合計500,000samples、求解CPU300秒。單案參考10000samples／30秒；不超時重啟同資料來挑結果。程序技術失敗可補上記錄完整的修復版本，不能看效果後改統計或方法。
