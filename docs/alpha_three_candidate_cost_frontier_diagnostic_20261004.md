# 初始 α 候選數量的品質—成本曲線：既有資料離線診斷

## 問題與方法

原五候選方法各以 Uniform（A）、Stage 0 品質權重（B）、MSE power 1.5、Corr precision 0.5、Target-local 執行一次 Stage 3，再用事前 Stage 0 資料擬合的 B 權重殘差校正分數選出交付 X。前一輪選解資訊缺口診斷沒有找到跨情境一致的簡單風險門檻；因此本輪檢查**固定少做候選求解時，品質與 API 請求成本如何交換**。

`analyze_alpha_cost_frontier.py` 從既有、選解重播通過的乾淨基本、4 倍樣本量不平衡與 25% 低品質參與者三批資料，各取 seeds 1900–2019 的原五候選 X 和內部分數。預先列出七種候選集合：單次 A、單次 B、A+B、A+B+Target-local、A+B+MSE power 1.5、前四組（省略 Target-local）、原五組。每個集合都從**自身候選中選內部分數最小者**；pooled evaluator 只在事後計算交付誤差。它不使用 pooled 分數作當輪選擇，也不從候選全集中挑出事後最有利的 α。

單次 A／B 只計相應初始化與 Stage 3 請求；多候選方法計各候選初始化、Stage 3，加上每位 agent 一次盲測校正請求及每個候選一次選解評分請求。這個公式在所有 seed 上與原五候選保存的「方法獨立請求量」逐項相等；另在先前四候選正式批次 seeds 900–1019 上，反事實四候選的 pooled 分數與方法獨立請求量均 **120／120 逐項吻合**實際 runner 結果。這驗證重播與計數口徑，不能證明新的三候選品質。數字不包含共用模型訓練、資格檢查、proposal 或研究用外部評分，也不是整批同時計算七法的實際總成本。所有候選均有效且 box 可行，完整鍵與原五候選選擇均經核對。四候選重播資料保存在 `alpha_weight_outputs/alpha_cost_frontier_validation_v2_900_120/`。

**重要限制：三批 seeds 已用於先前方法研究。**這只是已求解候選的離線反事實與方法設計資料，沒有新資料上的非劣性或品質優勢。原四候選法已另在獨立 120 seeds 正式測過，雖節省約 20% 請求，卻未通過事前 `+0.0005` 的 pooled 品質非劣門檻；不能以此處描述性數字取代該負面結果。

## 判讀與下一步

**A+B+MSE 是值得設計獨立成本／品質比較的候選，但尚非改良結果。**它目前只提供一個明確、可解釋的計算成本下降方案：保留均等分配、Stage 0 預測品質與較強品質集中三個不同初始 α；不新增可信標記，交付仍由原內部規則決定。現有資料沒有證明它比五候選品質更好，也沒有證明其品質損失在可接受範圍內。

下一個正式比較前，需先固定**應用上可接受的 pooled 誤差增加量**或模型請求／誤差的價值比，並明定尾端風險如何處理；不可看過這批描述性結果後，把舊 `+0.0005` 門檻調寬，仍稱為獨立驗證。若目標是嚴格的「pooled 品質更好」，現階段仍須保留原五候選作主要基準，不能只因成本下降就宣稱找到更好的 α。

## 真正三次求解的流程 pilot

已在 `run_validation_calibrated_alpha.py` 增加配對研究用 `--portfolio-three` 與只做三組 α 求解的 `--three-only`。前者同 seed 保存原五候選及三候選選解，並分開計入各方法獨立成本；後者實際只執行 A、B、MSE power 1.5 三次 Stage 3，保存三候選交付解。兩個模式都仍將 pooled evaluator 限於交付後評分。

乾淨基本情境 seeds 0–4 的兩個獨立流程 pilot 分別保存在 `alpha_weight_outputs/alpha_three_candidate_paired_pilot_v1_20261004/` 和 `alpha_three_candidate_only_pilot_v1_20261004/`。配對模式 10／10、只做三次模式 5／5 個選解變體均重播通過；兩邊 5／5 seed 的資料、proposal、local-model checkpoint、pooled evaluator checkpoint、pooled 資料 SHA-256 完全相同。15／15 個共同候選的 X、α、pooled 分數及方法成本，與 5／5 個三候選交付解全部逐項吻合。實際候選 Stage 3 次數為只做三次模式 **15 次**、配對模式 **25 次**。

此 pilot 原五候選／三候選平均 pooled 誤差為 `0.014757／0.011167`，方法獨立模型請求為 `2031.0／1261.2`（約少 37.9%）。五個 seed 已用於其他流程驗收，樣本量亦不足；這些數字**只驗收流程與成本，不能當成正式品質優勢**。仍須事前定義經濟門檻及新 seeds，才可正式判斷品質與成本取捨。

低品質情境亦用 seeds 0–4 完成配對流程 pilot，10／10 個選解變體重播通過；原五候選／三候選 pooled 均值為 `0.023963／0.024261`，方法獨立平均模型請求為 `1690.8／1090.2`。這個 pilot 的品質方向和乾淨 pilot 相反，進一步說明不能憑五筆結果下結論。

## 低品質情境 180-seed 嚴格品質與成本正式比較

在正式執行前，`docs/alpha_three_candidate_preregistration_20261004.json` 固定全新 seeds **2400–2579**、低品質單一情境、三候選與原五候選、16 個來源 SHA-256、分析命令與成功門檻。正式門檻採使用者原先「品質更好且符合經濟邏輯」的嚴格解讀：三候選減五候選的 pooled 絕對誤差配對平均差，以 seed 做固定 RNG、10,000 次 bootstrap 的雙側 95% 區間上限必須低於 0；180／180 配對有效可行、無較高失敗率；方法獨立模型 API 請求平均至少減少 **35%**，且不增加可信標記。35% 是根據前述開發與 pilot 的研究成本門檻，**不是實際貨幣損益門檻**。本次不把真實函數分數回饋選解；也不以正式結果重新挑候選集合或門檻。

正式輸出在 `alpha_weight_outputs/alpha_three_candidate_lowquality_formal_v1_20261004/`；180／180 個 seeds 的 720 條摘要與 900 條候選記錄完整。外部評分、box 可行性及選解從保存模型重播通過：**360／360 個選解變體、16／16 個事前來源雜湊相符**，沒有觀察交付失敗或新增可信標記。決策檔為 `alpha_weight_outputs/alpha_three_candidate_lowquality_decision_2400_180.json`。

| 指標 | 原五候選 | 三候選 A+B+MSE |
|---|---:|---:|
| 平均 pooled 絕對誤差 | 0.015665 | 0.015799 |
| pooled 中位數 | 0.011964 | 0.012225 |
| 平均 truth 絕對誤差（診斷） | 0.013482 | 0.013925 |
| 平均方法獨立模型請求 | 1869.57 | 1130.12 |
| 平均方法內本機秒數 | 0.08297 | 0.04896 |
| 有效可行交付／觀察失敗 | 180／0 | 180／0 |

主要配對差 `E_three−E_five` 的平均為 **+0.000134**，95% 區間 **[-0.000819,+0.001166]**，跨零；三候選較好／相同／較差為 **35／109／36**。平均每條件少 **739.45 次**方法獨立模型請求，減幅 **39.55%**。所以**成本門檻通過，嚴格 pooled 品質改善門檻未通過，整體門檻未通過**。不能宣稱三候選優於五候選，亦不能因請求量較少就宣稱有貨幣淨收益。

尾端風險不可忽略：三候選相對五候選的第 95 百分位 pooled 退步為 **+0.004717**，最大退步在 seed 2515，為 **+0.049296**；原法選 Target-local，三候選選 B，truth 也變差。最大 pooled 改善在 seed 2547，為 **-0.034366**，同樣是原法選 Target-local、三候選選 B，但 truth 反而變差。共有 **14／180** 個 seed 的 pooled／truth 方向相衝突。這些事後案例只用於解釋方法風險，不回饋本批選法。

平均請求可拆為初始化／Stage 3：原五候選 `24.0／1845.57`、三候選 `12.0／1118.12`。配對批次實際仍計算五個候選，所以方法獨立請求量是「若只採該方法」的計數，不是整批實驗的總請求量。每 seed 共用準備成本另存於 `shared_costs.jsonl`，平均模型訓練約 3.72 秒、資格檢查 0.99 秒與 40 次模型請求、固定 proposal 約 0.132 秒；研究用 pooled evaluator 訓練／保存約 5.17 秒，與方法 Stage 3 成本分列。這些本機秒數不是實際網路部署延遲。

**研究決策：**保留原五候選作高品質比較基準；三候選可保留為節省請求的明確選項，但需先由實際應用確認可接受的 pooled 誤差損失或誤差價值與查詢價格，才可能判斷它是否具有經濟收益。若堅持 pooled 品質也要嚴格更好，本次獨立低品質比較不支持提升三候選為主要方法。這個結論僅限合成、二維、target 0、固定三人與本研究的低品質設定，不能外推到乾淨／不平衡或真實資料。
