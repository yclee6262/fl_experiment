## 11｜依 α 分散度選四候選：獨立正式結果
**方法定義**：原五候選分別用 A、B、MSE power 1.5、Corr precision 0.5、Target-local precision 產生一個 Stage 3 解。本版先用既有 Stage 0 盲測與 local models 算出五組 α，固定保留 A、B，再從其餘三組中選兩組，使留下的四組 α 之**六個兩兩 L1 距離總和最大**；分數相同依固定順序處理。只為這四組做 Stage 3，仍用原本 B 權重全域 ridge 校正分數選交付 X。pooled／truth 不參與挑組或選解。

經濟概念是：同樣支付四次倒推成本時，選覆蓋較不同資訊權重的候選，減少重複查詢。不過 α 向量距離只是資訊分散的代理量，不保證實際 X 品質。成本已包含**全部五組 α 的初始化計算**、選組本地時間、四次 Stage 3 與候選評分；配對研究額外跑第五次只供原五候選對照。

在已用過的 330 seeds 上篩選固定與多樣性方案後，這版的描述性 pooled 差（新減原五候選）平均約 +0.000081、少約 369 次請求；這是**選法後的開發資料**，不能當正式證據。5-seed pilot 的 20／20 條條件、10／10 次選解重算通過，原 A、B、五候選解與舊版完全一致；pilot 平均請求原法 2031.0、新法 1639.8。

**事前登錄的獨立正式比較**使用全新 seeds 1100–1279。門檻為 180 個有效配對、新減原法 pooled 差的 10,000 次 bootstrap 95% 區間上限小於 **+0.0005**、平均模型請求至少少 15%、無較高失敗；區間上限小於零才另稱嚴格品質改善。`0.0005` 是研究容忍度，不是已驗證的業務門檻。

正式結果 720／720 條摘要條件完整、兩法各 180／180 個有效交付解、360／360 次選解可重算，15／15 個來源雜湊相符。原五候選／動態四候選平均 pooled 誤差 **0.015052／0.015282**；新減舊配對平均差 **+0.000229**，95% 區間 **-0.000277 到 +0.000800**。新法較好 12、相同 156、較差 12；pooled／truth 的逐 seed 優劣方向衝突 10／180。

平均模型請求原法 **1881.417**、新法 **1510.683**，少 **370.733 次（19.705%）**；本機方法內平均耗時 0.127596／0.105027 秒。若每次請求成本為 `c`、每降低一單位 pooled 誤差的價值為 `v`，只按觀察均值計的損益平衡需約 `c/v > 6.19×10^-7`；沒有真實 `c`、`v`，不能宣稱貨幣淨收益。

**判定：未通過。**品質差區間上限 +0.000800 超過事前 +0.0005；查詢節省成立，但品質風險沒有被限制在預設範圍。原五候選仍是主方案，依原規則不擴到複雜情境，也不事後放寬門檻。下一步研究會檢視 Stage 0 盲測資訊是否不足以可靠區分候選，並完整計入增加標記資料的成本。
