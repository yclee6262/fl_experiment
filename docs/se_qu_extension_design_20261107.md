# SE／QU 固定 50/50 補充比較

## 授權與範圍

2026-11-07 使用者要求 SE、QU 與目前八方法比較。本次授權限此補充比較；不擴張到動態 α、selector 調參、pruning 或付款。舊交接的暫停狀態由本次明確要求在此範圍內取代。

## 已固定設計

- SE = 0.5 S + 0.5 E；QU = 0.5 Q + 0.5 U。QU 對應既有 quality_shrink，並非從未實驗的新方法。
- 原八法 A、Q、E、EU、EQ、S、SU、SQ 全數保留。
- 先混合 α，再一次呼叫原 Stage 3 best_of（內含兩個既有求解引擎），不混合最終 X，也不先各解兩次再選 X。
- 重用報告原 90 seeds、三批各 30、三情境，固定模型、coalition、proposal、20 筆盲測與 evaluator；只補跑兩法 540 條件。
- 新結果單獨保存，不覆蓋原 2160 筆。這是歷史 cohort 補充分析，不是獨立確認。
- E 失敗沿用原 E 回退 Q 的規則，SE 仍固定與 S 對半；保留 audit。所有失敗與中斷保存。
- pooled／truth 不傳入初始化與倒推。交付決策先落盤，pooled 僅事後評分，truth 僅診斷。

## 統計與驗收

主要指標以 seed 為單位，先等權平均三情境 pooled 絕對目標誤差。兩新法各對八基準，再加 SE 對 QU，共 17 比較。200,000 次配對 bootstrap，Bonferroni family error 0.05，固定 RNG 20261107。各情境平均僅描述；不根據結果更改比較家族。

共同有效 seeds 作配對，另列全部失敗，不以刪除失敗宣稱改善。批次一致性要求校正上界負、三批平均差負、至少兩批普通 95% 區間上界負，且完整共同有效配對；即使通過也不能稱新獨立驗證。

每批重載全部新結果，核對 α simplex、X box 可行（1e-8）、pooled 重評（1e-7）、模型與資料雜湊。每批第一 seed 再獨立求解兩法三情境共 18 筆，核對 α、X、pooled、truth。新 α 另對既有 E/S/Q/A 的 50/50 算術驗證。有效交付不等於全域最優。

成本記錄初始化與 Stage 3 秒數、模型請求／樣本量；SE 必需六筆非自身評估，QU 無支持查詢，無額外標籤。對角線查詢另存為診斷。歷史八法與新法耗時不是同時測量，只作描述，不聲稱通過嚴格相對時間門檻。
