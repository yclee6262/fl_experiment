# 錨點當輪作用：候選解法與最小實驗設計

日期：2026-10-20。狀態：設計提案，未實作、未執行、未登錄為正式確認。

## 1. 研究問題與既有證據

研究問題：能否利用 custom 搜尋過程中的資訊，以低成本估計錨點對「當輪選擇方向與改善」的作用，累計後形成穩定、可解釋的錨點分數？

分配比例是第二階段的制度設計，不是分數有效性的證明。基本報酬、錨點報酬、模型報酬仍分開；本輪只研究錨點。

來源：

- [雙角色 v2 有效性結果](dual_role_validity_results_20261020.md)：錨點投影分數與 anchor-only removal 的平均排名相關，Clean -0.0556、污染 0.38，均未通過既定效果門檻。零新增模型查詢不等於有效。
- [既有診斷](contribution_diagnostic_results_20261020.md)：先前單步移除累計與 anchor-only 內部／外部效果仍弱，不能只換評分者就宣稱問題解決。
- [單步移除設計](local_anchor_step_value_proposal_20261020.md)：已有刪除方向後比較一步的方案；本提案不把它重新命名為新方法。

目前尚不能把方向相反、負投影或負累計解釋成參與者造成品質傷害。實際 custom 接受條件是內部 loss 嚴格下降；步長會縮減、調整，並非整段固定。實驗中的共同步長是用來控制比較條件。

## 2. 三種候選解法

令 x_t 為原搜尋位置，v_it 為錨點 i 已有的方向分量（包含原方向權重），g_t=Σ_i v_it，下降方向為 -g_t。模型集合與 objective 的 alpha 全部固定。

### A. 原搜尋方向統計：零新增查詢的對照

保留既有分數：接受步的實際內部改善，乘 v_it 在 g_t 上的投影比例，再累計。逐步保存正負抵銷、接受／拒絕、secant／dynamic 狀態。

優點：直接沿用原搜尋紀錄。限制：這個版本已未通過全程角色效果驗證；它衡量方向組成，不能預先稱為品質貢獻。本輪只檢查它是否至少對當輪作用有辨識力，不改符號或事後調時間權重。

### B. 單錨點方向試走：方向本身的選項價值

從相同 x_t，沿 -v_it/||v_it|| 試走共同距離 h_t：

V_it = L(x_t) - L(x_t - h_t v_it/||v_it||)。

正值表示這個方向單獨走能改善；負值表示單獨走會變差。零向量表示沒有方向建議，另列，不除以零。

限制：方向單獨不好，仍可能與其他方向互補；方向很好，也可能完全重複別人的方向。因此 V 是「可用選項價值」，不是它對實際合成步的邊際作用。每個狀態完整測試成本約 m² 個單模型輸入評估。

### C. 小幅增減方向作用：推薦的局部診斷基準

不移除錨點、不重跑整段搜尋；只在離線分支比較同一狀態下，小幅增減該錨點原方向分量：

- 固定 δ=0.10。
- g_it^+ = g_t + δ v_it；g_it^- = g_t - δ v_it。
- 將兩個方向正規化，以同一 h_t 產生 z_it^+、z_it^-。
- 定義可接受改善 U_L(z)=max(0, L(x_t)-L(z))。
- 局部分數 D_it=[U_L(z_it^+)-U_L(z_it^-)]/(2δ)。

正值：在當前其他錨點共同作用下，多一點此方向分量比少一點更有利。負值：少一點較好。兩側都無改善時 D=0，但保留原始兩側 loss，不把零解釋成完全沒有資訊價值。

這是有限幅度的方向敏感度，不是假定可微的導數，不是 full-removal，也不是唯一公平分帳。分數總和不必等於當輪改善；所有方向一致時，正規化後可能完全相同而全部得零。這表示局部方向敏感度無法分出冗餘提供者，不能解讀成大家都沒有價值。

此處改變的是離線影子方向，不更新原 alpha、原方向權重政策或原搜尋軌跡。完整測試每狀態約 2m² 個模型輸入評估，不能先聲稱比 LOO 全面便宜。

## 3. 推薦最小一輪：先驗證當輪，不立即累計分潤

先做 A 對 C 的局部比較；B 保留為後續互補／冗餘診斷，本輪不一併執行。目的是找出失配發生在當輪，還是當輪累計到全程的過程。

### 資料與步驟

1. 沿用四個舊 pilot 團隊及 20 個舊開發團隊（Clean 3 人、污染 5 人各 10 團隊），固定模型、起點、alpha、custom 30 與原設定。全部屬舊資料探索。
2. 優先讀既有完整軌跡；缺必要資訊時，才用不改搜尋行為的 recorder 重播基準。記錄重播成本，不能算成免費。核對原接受點、loss、模式與停止原因。
3. 每條軌跡固定取方向迭代索引 0、5、10，包含有試走但最終拒絕的狀態。提前停止導致不存在的索引另列，不補零、不改挑其他步。
4. 在每個存在且可比較的狀態，產生所有 g_i^± 與原合成方向。取 h_t=min(0.01, 所有這些下降方向的最大盒內可行距離)。距離以原問題座標計算，限目前 [-1,1] 的 2D 設定。
5. 若任一方向無法正規化，或共同 h_t≤1e-8，整個狀態標記不可比較；保留原因，不分別截斷方向以製造不等步長比較。這會限制結果對邊界狀態的適用性。
6. 使用固定原模型面板評估兩側點，計算 D。原合成方向亦以共同 h_t 評估一次，作為組合方向對照。所有分支均不寫回 solver。
7. 先鎖定所有點、模型回覆與分數，再由 frozen pooled evaluator 離線評估這些已產生的試走點。

外部局部參考採用「內部接受規則下交付點」：若 L(z)<L(x_t)，y(z)=z；否則 y(z)=x_t。令 U_E(z)=E(x_t)-E(y(z))，D_E=[U_E(z^+)-U_E(z^-)]/(2δ)。不能讓 pooled 決定接受哪個點，也不能將外部惡化截成零。

### 比較與主要指標

- A 的逐步投影統計對 D、D_E：零查詢統計能否識別當輪作用？拒絕步的既有 A 為零，應保留此限制。
- D 對 D_E：內部方向敏感度是否對應外部品質作用？
- 每狀態 Spearman，先在團隊內平均，再按團隊統計；相同 seed 的不同情境保持配對，不把各錨點／各步當成獨立樣本。
- 主檢驗為 D 對 D_E，Clean／污染分開。A 比較、正負號一致率、負分但外部有益比例、平坦／不可比較比例均如實列報。
- 單步改善差使用 1e-4 為研究死區；排名參考的兩側外部改善差在錨點間範圍≤1e-4，標記近乎平坦、排名未定義，不補零。D 的相應尺度是除以 2δ 後的門檻。
- 舊 anchor-only／full-removal 是全程次要參考，不能當作單步 D 的唯一真值。本輪只抽三個時點，不把其和冒稱全程累積貢獻。

### 成本上限

完整探測加一個原方向控制點，每狀態最多 m(2m+1) 個單模型輸入評估，不以 batch API 次數冒充樣本數：

- 20 開發團隊：3×[10×3×7+10×5×11]=2,280。
- 四 pilot（兩種情境各二團隊）：456。
- 合計最多 2,736；提前停止、快取可能減少。基準重播、pooled 評估及獨立驗證另計。
- pooled 端點評估最多：開發 600、pilot 120，共 720（每狀態包含共同起點）。快取只按實際命中扣減。

同時報 wall time、模型 samples、API calls、快取、儲存與重播成本；分開比較原搜尋及既有 LOO。這是稀疏離線診斷成本，不能外推為每輪所有錨點的正式部署成本。

### 驗收與停止

技術驗收：原軌跡與解不變；所有分支可重建；獨立驗證器從原始回覆重算 U、D、D_E，容差 1e-10；pooled 存取發生在分數鎖定之後。至少各情境 8/10 團隊有可比較且非平坦的排名；若不足，判定此設計證據不足。

探索效果門檻：兩種情境各自團隊平均 Spearman >0.5，且各 97.5% seed-bootstrap 區間下界 >0（兩情境的固定檢查）。這是本提案的實用篩選規約，不是老師指定門檻或正式有效性證明。

若 D 對 D_E 未通過，停止把這種局部內部敏感度推進成品質報酬。若 D 通過而 A 未通過，結論是「當輪作用可觀察，但目前零查詢統計仍不能估計它」。不能靠調 δ、h、翻符號、換指標或追加 seed 救同一輪。

即使通過，也不直接付款：下一階段須在同一完整 solver 狀態下檢查 1／3／5 步延續，判斷局部幫助是否抵銷或反轉，再決定如何累計；不能僅把正分相加。

## 4. 低成本化與獨立驗證

若局部基準有意義，才研究「每輪隨機抽一個錨點，做兩次影子試走」。每輪約 2m 個模型評估，不是 2m²；選取機率必須事前固定且大於零，保留樣本數與不確定性。

在原軌跡完全不受影子查詢影響、以已知機率抽樣的前提下，可用逆選取機率加權估計完整局部分數總和；它僅對這個固定軌跡上的總和有抽樣意義，不能據此宣稱 full-removal 無偏。少被抽中的人不應直接當低貢獻者。

嚴格零新增查詢時，未嘗試方向的實際結果不可直接觀察；只能提出待驗證的代理統計，不能保證從原紀錄唯一還原每個錨點的因果貢獻。

獨立確認資料：探索通過後另登錄 40 個未使用團隊（每情境 20），先稽核 seed 與資料未重用，再凍結參數、程式雜湊、排除規則及成本上限。現在不建立／執行確認集。新函數、高維與異質模型屬後續外推，不能以換 seed 代替。

## 5. 負分與分配比例：只做影子制度測試

保留 signed 原始分數。負值只表示所定義的比較中較不利，不自動代表參與者沒有服務價值。

可比較一個保底公式：

p_i=(1-λ)/m + λ w_i，Σ_i w_i=1，w_i≥0。

其中 λ 是事先約定的差異化比例，均分項只針對符合事前履約資格的參與者；它是錨點池內的保底規則，與另外的基本報酬需清楚列帳，避免重複聲稱同一服務價值。

影子例子可固定 λ=0.2，w 取分數排名權重（由低到高 1、2、3，同分平均排名），避免分數單位任意影響 softmax。三人即使分數為 -2、1、4，比例仍為 30%、33.33%、36.67%。這是制度選擇，非貢獻比例的科學推導。

全部非正或差異未被辨識時，影子規則退回均分；不能把「相對沒那麼差」說成創造收益。要測試同分對待、排序單調、負分保底、總和為一、對小噪音及重複錨點的敏感性；排名轉換也可能因微小分差跳動，因此技術性滿足上述性質仍不證明公平或抗操弄。

實際金額維持不受研究分數控制。未建立貢獻有效性前，不採用 λ>0 的實際成果分潤。
