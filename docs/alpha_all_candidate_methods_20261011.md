# α 初始化候選方法總清單與統一比較

本輪把使用原 20 筆資格資料的 25 種單次 α 初始化，放進相同流程重新比較；另補跑 2 種增加標記的初始化，共 27 種公式／規則。主要品質是交付 X 的 pooled 絕對目標誤差，越低越好。

## 納入同一張比較表的方法

| 方法 | 具體做法 |
|---|---|
| A：均勻權重 | 所有人等權，三人各 1/3。 |
| B：品質反比 | 共同 20 筆資格盲測的個人 MSE 加 0.00001，倒數正規化。 |
| 固定一半品質收縮 | 一半 A 加一半 B。 |
| 最佳組合向均勻收縮 | 20 筆擬合非負且總和 1 的組合，最小化混合 MSE，再與 A 各一半。 |
| 目標同儕品質收縮 | B 乘其他模型對個人候選點接近目標的指數分數，再向 A 收縮一半。 |
| 目標附近品質反比 | 資格輸出越接近目標越加重；距離尺度 0.5，加入五筆全域 MSE 的保護，再取倒數。 |
| 品質反比強化 1.5 | 分數為 (MSE＋0.00001) 的 −1.5 次方，正規化；比 B 更集中。 |
| 固定相關權重 0.5 | 未中心化誤差二階矩與個人 MSE 對角矩陣各一半，求最小風險的非負組合。 |
| 最佳單一模型 | MSE 最低者權重 1，其他 0；所有候選點保留。 |
| 局部偏差風險（原 20 筆） | 資格殘差做 ridge 擬合，在候選點平均位置估偏差平方加剩餘誤差，取倒數。 |
| 邊際資訊混合一半 | 拿掉一個模型預測後 B 混合 MSE 增加量取正值正規化，再與 B 各一半；非參與者倒推貢獻。 |
| 目標品質與邊際資訊混合 | 目標附近品質與邊際資訊權重各一半。 |
| 重抽樣品質 | 同一批資格點共同有放回抽樣 1,000 次，每次算 B，再平均權重。 |
| 品質留出收縮 | 抽中資料算 B，未抽中資料選向 A 收縮比例，平均 1,000 次。 |
| 指數品質權重 | exp[−(MSE−最小 MSE)/τ] 正規化；τ＝max(中位 MSE,0.00001)。 |
| 最佳組合留出收縮 | 抽中資料擬合混合 MSE 最佳組合，未抽中資料選向 A 收縮比例，平均 1,000 次。 |
| 保守品質 | 1,000 次抽樣的個人 MSE 第 90 百分位取倒數；不是信賴上界。 |
| 切分保守品質（不收縮） | 20 次五折切分，各用 16 筆估保守權重，平均 100 組。 |
| 保守品質＋留出收縮 | 相同 100 個切分，以另外 4 筆選向 A 收縮比例，再平均權重。 |
| 自適應相關權重 | 一次五折，16 筆擬合、4 筆評混合 MSE，從 0／0.25／0.5／0.75／1 選矩陣強度，全量重估。 |
| 只保留最佳兩人 | B 中 MSE 最低兩人保留並重新正規化，其他為 0；仍用共同 Stage 3 目標。 |
| 重抽樣勝出頻率混合 | 共同抽樣 512 次，統計每人 MSE 最低的頻率，與 B 各一半；不同於平均倒數權重。 |
| 最佳組合向 B 收縮 | 全 20 筆混合 MSE 最佳組合與 B 各一半。 |
| 純最佳組合 | 全 20 筆求非負且總和 1 的混合 MSE 最佳組合，不收縮。 |
| 留一驗證選 A 或 B | 逐筆留一，以另外 19 筆估 B，留出混合 MSE 與 A 比較，選一法；平手選 A。 |

所有 α 非負且總和為 1；共用原 Stage 3 目標：各模型對目標的絕對誤差，以 α 加權。固定候選點、box 限制、best_of 求解器、30 次 custom 迭代。較早的稀疏／stacking 實驗曾用另一個混合預測目標，本輪只沿用其 α 公式，不能直接當作歷史實驗重播。

## 名稱不同但公式相同

- uniform_stacked_half 與「最佳組合向均勻收縮」相同，合併為一個方法。
- top_two_expertise 與 sparse_top_two_alpha 使用同一種最佳兩人權重；本輪固定共同求解目標，不加入跳過零權重模型的求解變體。

## 本輪比較規格

- 乾淨、低品質、樣本量不平衡三情境；固定三名參與者、二維、正式目標 0、box −1 至 1。
- 每次資料重複中 25 法共用資料、local 模型、原 20 筆資格資料、候選點與凍結 pooled evaluator。
- 先驗收小型試跑，通過後使用 30 次全新資料重複；主文只呈現方法與 pooled，不堆疊重現編號。
- 每方法每情境都有平均、中位數、四分位數、失敗狀態，以及相對 A／B 的配對差；平均排名為探索結果，不宣稱已確認通用優勢。
- 三情境等權平均先固定為每種情境 1/3，僅作整體觀察；仍分開列出各情境，避免隱藏失效。
- pooled 不參與 α、solver、選解或參數調整；truth 只作附錄診斷。
- 既有輸出保留，本輪程式、模型、資料及結果另外封存。
