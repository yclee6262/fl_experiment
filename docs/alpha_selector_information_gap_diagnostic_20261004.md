# 初始 α 五候選選解的資訊缺口診斷

## 問題與資料

前一輪多個新初始 α 候選在獨立比較中未建立穩定 pooled 品質優勢；既有診斷亦顯示，五候選的內部選解分數有時未選中事後 pooled 最好的 X。本次先檢查：**交付 X 附近的 Stage 0 盲測資料量、local models 的預測分歧，能否指出選解高風險案例？**這一步只診斷現有選解，沒有新增 α、候選求解或交付決策。

使用已完成且選解重播通過的三個情境，seeds 1900–2019，各 120 個：乾淨基本、4 倍樣本量不平衡、25% 低品質參與者。每個 seed 只看原五候選（Uniform、Stage 0 品質、MSE power 1.5、Corr precision 0.5、Target-local）的既有交付 X。這批 seeds 已參與之前的研究，**本次所有關聯均是事後探索，不是獨立驗證**。

對每個交付 X 計算：

- `nearest_blind_distance`：X 到 20 個 Stage 0 盲測點的最近歐氏距離。
- `blind_points_within_0p25`：距離 X 不超過 0.25 的盲測點數。
- `kernel_effective_n_0p25`：以 bandwidth 0.25 的 Gaussian 權重計算 `(ΣK)^2/ΣK²`；反映有效樣本集中度，但遠處點仍可能給出看似不低的數字，因此另報距離及權重總量。
- `kernel_mass_0p25`：上述 Gaussian 權重總和，反映 X 周圍資料覆蓋。
- `local_prediction_std`：固定 coalition 中，各 local model 在 X 的預測標準差；只是模型分歧，不是已校準的不確定性。
- `internal_score_margin`：五候選內部分數最低與次低的差；越小表示內部排序越接近。
- `internal_score_best`：已交付候選的最低內部絕對 target 誤差。

診斷用結果 `selector_regret_posthoc = E_pooled(X_chosen) − min_j E_pooled(X_j)`，其中 `j` 只涵蓋原五個已求解候選。pooled 最佳候選僅作離線參考，**沒有輸入 α、內部分數或交付規則**。數值接近零時可能是不同候選得出同一 X；另以 `regret > 1e-6` 統計明顯差異。三批既有實驗的選解重播結果均為通過；本分析另核對 360 個 seed 的完整鍵、候選可行性、內部選擇及交付 pooled 分數一致性，並重載模型計算 X 處 local 預測。沒有在本分析重新訓練 evaluator 或重算 pooled 分數。程式與逐 seed 資料分別在 `analyze_selector_information_gap.py`、`alpha_weight_outputs/alpha_selector_information_gap_v2_1900_120/`。

## 結果

| 情境 | 有明顯選解遺憾的 seed | 平均選解遺憾 | 最近點距離與遺憾 Spearman | kernel 權重總量與遺憾 Spearman | local 預測分歧與遺憾 Spearman |
|---|---:|---:|---:|---:|---:|
| 乾淨基本 | 60／120 | 0.002610 | -0.059 | +0.040 | +0.075 |
| 4 倍樣本量不平衡 | 67／120 | 0.003688 | -0.079 | +0.062 | +0.123 |
| 25% 低品質 | 63／120 | 0.004449 | +0.137 | -0.171 | -0.014 |

所有列出的 Spearman 關聯都很弱，而且「資料少使選解較差」在乾淨與不平衡情境沒有同方向趨勢。低品質情境中，kernel 權重總量最低四分位的平均遺憾為 0.007201，最高四分位為 0.003964；這是**已使用資料上的描述性差異**，不能據此設定取得標記或額外求解的觸發門檻。local 預測分歧與內部分數差距也沒有跨情境一致的排序訊號。完整四分位結果、每個 seed 的特徵與遺憾保存於輸出 JSON／CSV；沒有把 360 個不同情境的 seed 混成單一正式檢定。

## 決策與下一步

**目前不加入僅憑距離、kernel 覆蓋或模型分歧的自動觸發規則。**本輪數據不足以支持它們可靠辨識應多買標記或多做 Stage 3 的案例；單憑低品質情境的四分位差，可能產生選法偏誤。也不能把事後 pooled 最佳候選當成可部署的選解器。

下一個真正不同的假說，是在候選 X 已產生後，使用**與原 20 筆 Stage 0 標記獨立的可信選解資訊**，只服務於比較候選 X，而不是再改同一批資料上的 α 混合比例。先釐清實際應用能否取得這類標記、每筆價格及可接受延遲；若只能從合成真實函數取得，結果只能支持有該付費查詢能力的合成設定。正式方法應預先限定標記數、取得規則及成本，pooled evaluator 仍僅作交付後主要品質評分，並使用未參與設計的新 seeds 檢驗。
