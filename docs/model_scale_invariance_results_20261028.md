# 模型池第一階段：固定端點尺度換算驗證結果

日期：2026-10-28。執行前規約：`docs/model_scale_invariance_design_v1_20261028.md`。新輸出：`contribution_analysis/model_scale_invariance_experiment_v1_20261028`。

**已完成：固定端點下，一致縮放模型全部loss並同步換算探測尺度時，標準化貢獻維持一致。354個可比較變體通過，6個原未定義變體仍為null。這是尺度換算的代數／數值驗證，尚未證明模型決策品質或搜尋尺度不變。**

## 1. 實際做法

重用T3的60個已讀解析設定、原接受full/minus端點、原common階段loss。59設定有minus端點，1設定無剩餘正權重，保留原未定義。這些資料不是新的獨立保留或實務確認。

共同探測固定25點[-1,−0.5,0,0.5,1]²，非依C選點。各模型s=Q90(loss)−Q10(loss)，線性插值。固定完整團隊v與尺度，用C_norm=Σv_m(loss_minus−loss_full)/s_m，另存own和others。正權重模型s≤1e−12則未定義，不用epsilon硬除。零權重模型不參與評分。

每次只換一個模型，將其探測及兩端點loss一起乘0.1、10、100，其他模型、原端點與v不變。所有360變體中354可比較、6原無端點未定義。量的是同一對結果，不重跑方向／縮步／接受，也不重新產生排除端點。

## 2. 一致性結果與反例控制

60個baseline與360個一致換算變體完成；C/own/others最大baseline差4.55e-14，符合事前|Δ|≤1e−10+1e−9|baseline|；可辨識非零符號沒有翻轉。標準化尺度在放大時一起改變，正比例因子可相消，這是方法構造的預期性質，不是新品質能力。

例useful_information_0：原C約0.1；換算後C=0.05，own=0.075，others=-0.025。把任一模型全部loss乘10且重估對應尺度，這些換算後數字維持相同（容差內）。若故意只把target端點loss乘10、不換尺度，C變成0.725。這個控制確實能揭露不一致換算，但不代表正式鎖版本後允許此操作。

## 3. 原尺度反例及品質限制

T3個別尺度類六個設定的full端點均−0.1、minus均+0.1。以固定25點校準後：

| 原模型0尺度倍數 | 原C | 標準化C | 原解析D |
|---:|---:|---:|---:|
| 2 | 0.1 | 0 | -0.2 |
| 4 | 0.3 | 0 | -0.2 |
| 8 | 0.7 | 0 | -0.2 |
| 3 | 0.2 | 1.89501e-14 | -0.2 |
| 6 | 0.5 | 1.89501e-14 | -0.2 |
| 10 | 0.9 | -1.13659e-14 | -0.2 |

標準化不只是把原C除上一個共同常數；它調整每個模型在共同尺中的相對影響。59個可計算設定有12個原C與標準化C的正／負／近零分類不同（±1e−10），不能要求新分數保留原排名。這不是權重alpha更新，而是新的離線評分尺，仍須另驗證是否符合付款理由。

重要反例仍存在：有用不同資訊_0的標準化C=0.05、原解析D=0.2；過度樂觀接受_0的標準化C=0.05、原解析D=-0.2。分數仍可相同而解析品質好壞相反。尺度消除不等於準確度、可信性或公平性成立；D只引用舊鎖定診斷，不進新公式。

## 4. 邊界與獨立核對

12項技術測試通過：有號／分解、一致倍增、零／近零尺度、無minus、零權重、非有限／負loss、probe缺失、端點長度、非零target下預測倍增≠loss倍增，以及絕對尺度可靠性門檻的邊界。近零s在更換單位後可能跨絕對1e−12門檻，因此主不變性只限所有panel都具可靠尺度；不宣稱任意精度、退化尺度的資格永遠不變。

獨立Fraction reference不匯入生產score，從raw probe／endpoint loss重算分位數、尺度與C分解，共核對479個panel，最大絕對差9.1e-14。3000個解析探測回覆另用有理數多項式核對；common端點與原API回覆、座標、鎖定順序連結通過。120個故意C+1／尺度+1篡改（含null改0）全被發現。原未定義不是被漏掉或填0。

## 5. 成本與資料角色

新解析探測函數評分3000次（60×2×25），變體只是保存數字乘法與重算分位數，不重查模型；不是已測神經模型校準延遲。新訓練模型呼叫0、搜尋0、訓練0、pooled0、實際付款0；主流程0.512秒，含測試／hash／探測／數字變換／內嵌reference與保存，不含最終audit／報告。未測RSS/native memory或部署成本。

探測點規則於本輪執行前固定，但舊搜尋端點早已存在；本輪是現在離線校準，不能說原搜尋前已校準。若未來要用於新搜尋，需要先鎖模型版本及尺度。只有原target=0的一組模型消融端點，沒有同一團隊所有owner的排除端點，本輪沒有生成或聲稱驗證模型池付款比例。
