# A／E／B 定義、反例與成本驗證 v1

日期：2026-10-27。執行前固定；本輪為機制驗證與舊資料探索，不是歷史正式確認。研究方法名稱使用「切線法／割線法」，程式識別碼保留原名。授權：根據驗證實驗設計去實作並整理結果。

## 1. 固定目標與邊界

不更動 A、E、B 公式、原 host_server 演算法、alpha 或權重決策。三種輸出分開，沒有總分或分潤。無完整 LOO 比較、刪人、訓練、付款、pooled evaluator 或真實任務 truth 載入。所有分支只作離線診斷。

計算正確性不等於公平；合成資料通過不等於實務泛化。既有兩案只作開發資料。新合成種子是未用於規則調整的保留機制驗證，仍非獨立真實任務確認。人工反例可反駁普遍主張，不能估計其實務發生率。

## 2. 固定實驗

1. A 手算與分配性質：原手算投影 [3,1,-1]；owner 合併、正交、零方向、強抵銷由原 49 項測試重跑。另以同一一維凸二次目標 f(x)=10+x+4x²，比較錨點 [.1,.2] 與 [.1,.9]。相同起點、步長和權重，檢查同一更新與同一改善是否仍有不同 A。該結果說明分配依方向訊號規約，不當成誠信攻擊證據。
2. E 模型品質反例：模型為 r(x)=10+x、2r(x)、r(x)+5、10−x，均勻權重，起點 0，單輪搜尋。用固定 21 點 [-.5,.5] 的已知合成 r 算評分 RMSE。驗證 E 端點恆等式，觀察較差評分能否獲得更高 E。合成參考僅用診斷，不進入搜尋或權重。
3. B 手算幾何：共線反向、非共線有益、非共線有害、精確抵銷及近抵銷。固定向量與簡單解析目標驗證符號；此為方向介入核對，不宣稱任意向量一定出自該目標的原搜尋。
4. 舊資料 B 分支：原兩案全部有效輪、全部 owner（包括 B=0），從原始模型回覆重建 H_o。移除 H_o、不重估其他來源，不移除其模型、不重訓、不重跑後續輪。主比較共同可行的相同實際步長：s=min(原首試實際步長, 替代方向 box 可行步長)，兩方向都走 s；s=0 列無共同位移，替代零方向列未定義。另以原 eta、原 10 次縮步與嚴格接受條件各自完成單輪，失敗端點保持原點。效應 D=L(無該方向分量端點)−L(完整方向端點)，D>0 表示該分量對這個局部分支有益。界線 ±1e−8；另報 ±1e−6 敏感度。不將 D 或 B 改成報酬。控制分支必須重現保存的首試點及原接受端點，否則停止。
5. 保留合成驗證：種子 27101–27112；前六案二維、後六案八維，K=4、M=3，正定二次固定確定性模型、固定非均勻權重，每次 12 輪。每案控制／紀錄對照、獨立 scalar 與原 solver 重播；同 owner 複製首錨點且拆半原權重；共同尺度乘 7；第一模型固定加入 ±1e−6*x[0] 的微小回覆擾動；起點首維 +.01。全數保留，不依結果增種子或修改公式。報原始單位及正規化份額變動、零改善／未定義與端點變化；不同起點不是要求貢獻不變。
6. 成本：四組 (K,M,D,輪上限)=(3,3,2,10),(8,8,8,20),(16,16,16,30),(8,3,8,20)，固定種子 28101–28104。各一組暖機及七組交替順序的控制／紀錄配對；暖機不進中位數。每組離線 A/E/B、序列化各七次；另一次 Python 配置峰值，與時間測量分開。控制本身包含最小 query counter/digest，模型為便宜合成函數，因此相對開銷不當成部署結論；報原秒數、比值、呼叫數、有效輪數、輸出 bytes。15% 沿用工程目標，未通過即明列，不調規則以追門檻。

## 3. 成本上限與保存

CPU 單執行緒；保留合成搜尋 12×7=84 次；成本 4×16=64 次，A 兩次、E 一次，共 151 次新合成搜尋。舊資料僅分支目標評分，不啟動完整新搜尋。每次原 observer 上限 20,000 筆／60 秒；另全流程最多 300,000 API 呼叫、5 分鐘、250MB。超限保留 failure，不補 favorable cases。

## 4. 驗收與停止

計算 gate：原 49 項測試全過；每筆新紀錄 A/E 守恆、獨立重建、原 solver 重播、控制／紀錄查詢與結果一致；owner 等價拆分容差 atol=rtol=1e−10，尺度份額容差 1e−8，失敗保留且不得宣稱通過。舊模型 hash、原結果、輸入快照任何不符即停止。

反例 gate：E 若出現評分較差但 E 更高，拒絕「E 即模型品質」；B 若同時有有益／有害／無效反例，拒絕「B 即保護收益」；A 若相同成果分配不同，僅能支持訊號歸屬規約，不能宣稱唯一或公平價值。B 反例若不足，報未觀察到，不補造真實證據。這些是預期可能的研究負面結果，不是技術失敗。
