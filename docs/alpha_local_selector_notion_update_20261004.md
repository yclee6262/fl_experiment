## 9｜後續嘗試：依候選位置選擇初始 α（2026-10-04）
**這是初始 α 的選擇規則，不是第十一個 α 公式。**原五組 α 與五次 Stage 3 不變；新法只改從五個候選 X 中選哪個交付，因此最終 α 仍是被選中候選所用的那組權重。

### 具體方法與經濟意義
原方法以 Stage 0 的 20 筆盲測資料，對 B 權重集成預測的有號殘差做一次全域 ridge 校正。新法對每個候選 X，按盲測點到 X 的距離給權重 `K_j(X)=exp(-||x_j-X||²/(2×0.25²))`，各自重新估計局部 ridge 偏差；截距懲罰 0.01、座標係數懲罰 1。交付內部分數 `abs(sum_i B_i f_i(X)-local_bias(X)-target)` 最小且符合 box 的候選。這只用 Stage 0 標記、local models 與候選 X；pooled／truth 都在交付後評分。

經濟概念是：在相同五次求解的資訊取得預算下，讓更接近候選 X 的既有盲測經驗影響權重方案選擇。它沒有多做 Stage 3，但局部計算仍需計時；這不是付款或公平分潤規則。

### 證據：開發、pilot 與獨立正式
- **開發**：在已用過的 30／60／60 seeds 上，從多種校正規則中選出 bandwidth 0.25；三批 pooled 配對平均差（新減原五候選）分別 -0.000423、-0.000617、-0.000495。因為規則是事後從多種嘗試中挑出的，不能作確認證據。另試的 bootstrap 專家機率、邊際資訊增益、前兩位專家及三個舊 shrink 權重，沒有跨批次穩定改善訊號。
- **5-seed pilot**：20／20 條條件有效、10／10 次選擇重算通過；A、B、原五候選的 X 與舊 pilot 完全相同。原全域／新局部 pooled 均值 0.014757／0.014407；兩者模型請求均 2031.0。pilot 只作流程驗收。
- **事前登錄的獨立正式，seeds 800–859**：240／240 條條件完整；雙方各 60／60 個有效交付解、120／120 次選擇重算通過；13／13 個來源雜湊一致。原全域／新局部平均 pooled 誤差 **0.014729／0.015467**。新減舊的 60-seed 配對平均差 **+0.000738**，10,000 次 bootstrap 95% 區間 **-0.000608 到 +0.002374**，跨零；較好 5、相同 43、較差 12。**未通過事前的品質改善門檻。**

正式批次的平均模型請求兩法同為 **1901.5**；本機方法內平均耗時原法 0.153112 秒、新法 0.153147 秒。truth 均值原法 0.012572、新法 0.012415，逐 seed 的 pooled／truth 優劣方向有 8／60 衝突；truth 是診斷，不取代事前 pooled 判準。新法未建立更好的 pooled 品質或經濟效率，故**保留原五候選全域校正為目前主方案，不進入複雜情境**。
