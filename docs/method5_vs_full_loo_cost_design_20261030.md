# 法五三池流程與完整參與者 LOO：成本比較設計

日期：2026-10-30。狀態：設計完成，尚未執行本次新比較。不預設新方法較便宜，不修改已選定的分數與資格規則。

## 研究問題

在相同團隊、模型、起點、目標、原搜尋版本及停止條件下，產生完整三池影子分配所需的實際模型評分與執行時間，是否低於產生完整參與者 LOO 分數所需的成本？兩者估計對象不同；成本優勢不是 LOO 效果替代性的證明。

已知風險：歷史四方案比較的 A2＋M 為 38541 次模型評分，完整 LOO 為 28537 次，前者多 35.1%；該數字不是最新 C^A＋正 C 資格 C＋N 的結果。來源：contribution_four_way_comparison_results_20261022.md 第6–7節。必須新跑整合流程，不能拼接不同實驗總成本。

## 比較臂與交付物

主比較 New：一次完整原搜尋及必要觀察紀錄；全部 owner 的逐輪錨點方向移除；全部模型的逐輪評分移除；固定完整 F 端點補評；搜尋前尺度探測；方向去重與 U/I/N；有號累積、資格、整數分配；基本池履約帳與必要輸出。不能只報模型池或只報統計後處理。

主比較 LOO：一次完整原搜尋；依序從原始起點完整移除每位參與者的全部錨點及其模型，按凍結既有 full-removal 規則重建剩餘權重並重新搜尋至原停止條件；各最終端點用固定完整 F 補評，產生 D_i=F(x_final_minus_i)-F(x_final_full)。基本池相同服務帳成本另列且對稱加入。LOO 不必為沒有要求的角色分解額外付費；不得額外加無必要處理讓它變貴。

次要角色匹配診斷（不取代主要比較）：若需要比較兩種角色資訊的價格，另報 anchor-only 全程重跑與 model-only 全程重跑的雙角色 LOO。不可只用這個較昂貴對照宣稱勝過完整參與者 LOO。

## 公平執行口徑

每臂獨立空白成本帳及快取；共同模型、同設備、同精度、單執行緒、同批次策略。基準搜尋只計一次。不得從另一比較臂、歷史結果或暖機取得免費評分。

主試驗定位為完整搜尋後的離線分配，可重用本臂 baseline 已有的精確回覆。New 的錨點／模型兩角色可共享同臂快取；LOO 各移除分支同樣可共享。鍵含模型與版本、loss/目標、精確輸入及必要執行上下文。快取不得改變分支決策；若模型非確定性，停用或另立規約。25點尺度探測等新方法專屬查詢全額計費，不視為免費歷史校準。

另外列無快取的邏輯評分需求；若未實跑無快取版本，明確只稱推論需求計數，不宣稱無快取時間。逐輪即時計分是不同快取時序，未執行不得將離線結果外推即時成本。

## 指標與公式

評分樣本單位是一模型對一個位置的真實評分；另報 API 請求數、批次大小、快取命中。各臂 Q_total=Q_base+Q_extra，r_Q=Q_New/Q_LOO，節省率=1-r_Q。分開報新增成本比與整體成本比，不能只選有利者。

時間包含觀察器、探測、原搜尋、消融、補評、特徵、分配與標準必要帳本輸出；另報已載入模型的計算核心時間、載入時間、端到端時間及峰值記憶體。測試、獨立稽核、研究壓力分析不混入單次部署成本，另列研究總成本。若某臂持久化大量非必要研究 trace，另報其成本，不將任意診斷 I/O 當演算法必需。

每團隊一暖機加三次交錯計時，順序事前固定輪換；每次清空評分快取。記錄個案中位數與範圍、總比值、中位數比值、勝出團隊數、最差個案；乾淨／污染分層。模型異質時另列逐模型次數與推論秒數，不能假定每個模型價格相同。未實測遠端服務不換算雲端費用或部署延遲。

## 資料、階段及驗收

工程開發先用已驗證的兩個錨點團隊，核對完整原搜尋、接受端點、C^A 與分配重現。模型 C、U/I/N 從原始回覆獨立重算。高維尺度探測不自動擴充：先核對團隊維度與25點規則是否適用，否則先保存適配設計，不把不同規則默認為已驗證。

凍結整合程式及來源後，在既有四方案20團隊上配對量測；兩個開發團隊若重疊須標記，不能稱全數獨立保留。先建立完整名冊、來源hash及可載入性檢查，不因結果慢而排除團隊。這是歷史資料新成本實驗，不是新應用泛化證明。解析模型可作工程測試，不取代真實保存模型的主要成本結果。

技術門檻：所有方法保持原搜尋數值與停止語義、缺失／失敗狀態；必要資料完整；獨立核對實際評分帳、快取鍵、分數及付款比例。任一失敗保留證據並停止比較，不先報低成本。

成本判讀事前固定：整體 r_Q<1 才能說這批資料評分量較少；兩情境都<1 才能說兩情境皆較少。預設實質節省目標為兩情境 r_Q≤0.8（研究提案門檻，非老師要求），時間亦須無明顯增加；時間量級太短或變異大則列未建立時間優勢。若只有平均勝出，只能報平均，不說每案或穩定較便宜。未達門檻不得改β、縮減應計輪、漏分支或降低LOO迭代額度。

預算上限沿既有比較量級：主要量測最多120萬次模型評分、900秒；另獨立稽核最多10萬次評分、300秒。超額停止並保留部分結果，不把未完成案例當成0成本。0訓練、0pooled、0truth、0實際付款。

## 未通過時的處置

先依探測、錨點分支、模型分支、完整F補評、觀察／帳務逐項定位成本；只能另版研究不改分數的精確快取或共用計算。新實作須重現分數與資格再量測。抽樣輪次、近似方向、只算部分owner屬新估計器，需另立有效性驗證，不可偷換為現在完整方案。

在新比較完成前，Notion提案的「低成本尚未建立」維持有效，不以舊J或舊A＋M的數字替代本流程證據。
