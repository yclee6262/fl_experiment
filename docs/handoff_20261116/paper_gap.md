# Proposal 與目前研究進度：逐章落差

盤點日期：2026-11-16。基準為專案內 `paper/proposal/main.tex` 與其四章原稿；不是 Downloads 中其他 PDF 版本。本文核對原稿、現行程式與本地完成報告，沒有重新執行正式研究或核驗所有原始數據。後續結果若有版本修訂，以較新的修訂／稽核為準。

## 結論

目前缺口主要是**論文主張與證據的重新對齊，以及後續成果尚未寫入**，並非只缺做實驗。原稿已有四章及三種子原型表格；後續已完成動態權重、初始化、角色貢獻、排除自評、成本與低成本近似等研究，但不少結果不支持原先預期優勢。

不能可靠地用「論文完成百分之幾」表示差距。可明確列為：4 個既有章節需更新，新增實驗結果／討論／結論內容；其中方法章的動態更新、貢獻定義、剪枝與分潤段落需實質改寫，不能僅補數字。就交學長的初稿而言，可先依現有證據寫出完整敘事，未驗證事項如實列限制，不必先把所有新實驗做完。

## 初稿中必須分開定義的量

- r：事前資格／聲譽；α：模型共識目標的控制權重；β：候選解融合或搜尋係數；q：特定貢獻定義截正後的份額。初始化 α、動態 α 更新、β 搜尋不是同一件事。
- 錨點排除、模型排除、單輪共同移除 J、從共同起點完整參與者 LOO，干預對象與時間範圍不同。
- 搜尋時使用的模型集合，與端點鎖定後最後評分使用的集合分開描述。CA 的 peer 最後評分不表示搜尋已移除 owner 的模型。
- F、Fminus、pooled、synthetic truth 分開；pooled／truth 不作線上可得訊號。歷史資料被反覆查看後，不能重新稱為獨立確認資料。
- 歷史合約最低保障與服務基本池不是同一規則；預算／保留額守恆、數值可重播、品質有效與公平性也不是同一驗收。

## 建議初稿章節與補寫順序

1. 先寫「方法版本表＋研究問題＋證據表」：鎖定主文研究範圍、符號及主比較，不預設尚未成立的優勢。
2. 改寫方法章：既有協作反推主流程 → 靜態 α 初始化及選擇 → 角色貢獻與評分尺 → 成本與影子分配定義。動態更新、剪枝與三池未定稿部分標為歷史研究／待驗證延伸。
3. 由已完成報告整理結果章：α 品質／成本、貢獻效度、排除自評、成本近似；保留負面結果、失敗列、信賴區間與資料重用說明。
4. 補討論與結論，再回頭改緒論、文獻與摘要。圖表逐一附 cohort、版本、樣本數、指標及原始結果位置。
5. 完成論文編譯、引用與圖表檢查，才稱為可交付初稿。這次沒有代寫或編譯論文正文。

這些不是「為交第一版初稿必須全部再跑」的清單；可先寫為限制，若要維持相應強主張才需補證據。

| 欲主張的內容 | 仍缺什麼 |
|---|---|
| 初始化優勢可泛化 | 新生成且未參與方法選擇的資料／模型確認；已存在方案，尚未執行 |
| 低成本分數可替代完整LOO分配 | 在清楚移除定義、同尺度與預定精度／成本門檻下的新模型確認；目前探索未通過 |

| 優於完整baseline矩陣／低通訊優勢 | 按原稿逐項對照公平預算、同資料、端點品質、傳輸bytes及呼叫samples。現有本機評分成本不等於端到端部署測量 |
| 實務有效與隱私保證 | 真實服務／外部資料驗證與明確威脅模型；不交換權重本身不是正式隱私保證 |
