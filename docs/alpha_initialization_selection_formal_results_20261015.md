# α 初始化與選擇策略：三批獨立確認結果

日期：2026-10-15。原C/P與八固定方法已完成三批獨立確認；沒有根據確認資料改規則、增減樣本或淘汰方法。


**本輪判讀：P平均最低，且P−SQ通過完整穩定門檻；P對EU/E/Q/C尚未建立穩定優勢。P−A雖有整體校正區間全負，但只有一批一般95%區間全負，未達至少兩批門檻。C的品質比較均未通過，且方法時間約1.67倍EU，超出1.5倍預算；P約7.42倍，成本在10倍內，仍不足以支持取代固定EU。**

## 已完成：測了什麼

- 三批各30新案例，共90案例、2700條方法／策略結果；三情境共同合格案例為90，共同資格失敗案例0。失敗不補抽。
- 固定20筆盲測、IDs1/2/20、三模型、2D、target0、box[-1,1]、best_of/custom30。四混合法固定50/50；不更新α、不pruning、不結算、不新增標籤。
- C用五折混合預測RMSE先選α方法，再獨立倒推一次；P用八固定α各倒推，再以共同Q加權local絕對目標差選X。選擇介面不接收pooled或truth。
- 八固定方法與C/P共用同案例資料、模型、盲測與提案。C/P決策封存後才離線pooled評分，truth僅診斷；各批中途描述分析關閉，三批完成後統一正式分析。
- 18項相關pytest測試通過，另以人工資料驗證共同資格失敗的正式彙整。每批逐條重載、每批事前指定第一個seed完整重播；重播不是新品質樣本。
- 11項主比較、200,000次完整seed配對bootstrap與Bonferroni同時區間。穩定門檻另要求三批平均皆負、至少兩批一般95%區間全負、完整有效配對及觀察失敗率不增加。

## 待驗證：證據與適用邊界

- 歷史開發60案例僅用來估變異與檢定力，不訓練selector。假設真實差−0.001，以常態區間近似bootstrap與三批門檻，原90案例規模的近似穩定檢定力約1.3%–27.2%；這不是精確power保證。依事前固定預算完成90案例，沒有依確認效果加樣到顯著。
- 不顯著不是等效；微小收益、其他目標／維度／參與者數、不同盲測數量與真實遠端API成本尚未獨立確認。L及歷史pooled監督selector未納入本輪。
