# V+U、C^M+N、V+N及整體成本比較

本輪為已知資料上的比較研究，先凍結後執行。使用既有20隊神經網路與前次80隊解析模型（3/5人各兩情境各20隊），均已被分析，不稱獨立確認。30輪上限，相同起點與權重；不接續前次60輪未完成批次。

九臂：B、VU、CMN、VN、A_VU、A_CMN、A_VN、J、LOO。A為完整C^A，V僅原trial紀錄讀取。U沿用25點Q90-Q10尺度及標準化斜率最近鄰RMS。模型分支保留全部錨點，以剩餘模型正規化權重重算當輪方向與接受結果。C^M用完整F比較端點，I=端點距離/原輪eta，N=U/(10+U)*I/(1+I)。VN為取得I仍跑相同模型分支，並保留C^M作診斷。J為每輪同時移除錨點和評分模型，剩餘錨點及模型權重各正規化，原輪狀態重設分支loss後只跑一輪，最後完整F比較，原路徑不變。LOO共同移除後從頭重跑。

模型池分配主設定80%表現、20%資訊，資訊額度敏感性10%、30%。VU表現V資訊U；CMN表現有號累積C^M資訊N；VN表現V資訊N。先跨輪累積，分配只取>1e-10正值，資訊資格同本方案表現正值；分母零保留。輸出比例而不實際付款。檢查C^M負者取得比例、資訊額度占比、集中、保留以及分配總變差。負C^M是固定內部標準下的模型當輪淨效果，不直接稱外部有害。

每臂空快取、臂內共用精確model-point結果，尺度探測在原搜尋後執行；組合固定先錨點後模型分支，共同F補評計入。模型池獨立成本與組合實跑成本皆報，不直接相加。VN與CMN取得相同所需資訊，預期評分成本一致；V讀紀錄零模型呼叫。原搜尋結果及呼叫序列必須一致，歷史C^A/C^M/N/U、LOO須重現，J對照既有共同移除結果（相同定義範圍）。若定義或數值不一致停止，不默默替換。

每隊暖機一次、計時三次、循環交錯版本；成本主指標單次實體評分數，原搜尋與額外成本分列，按資料與3/5人情境分列，時間補充。新實驗上限12,000,000次實體評分、20分鐘。達上限保留未完成，不擅自加碼。來源hash、案例、參數於執行前保存。pooled/truth、alpha更新、pruning及付款均不執行。
