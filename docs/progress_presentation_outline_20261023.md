# 教授進度簡報內容規劃

日期：2026-10-23。用途：下一次教授進度報告。此為內容規劃，尚未製作PPT或更新Notion。

## 報告主張與篇幅

建議主題：「α 初始化策略的比較：模型互補性、候選點支持度與交付解品質」。主文15頁，約20–25分鐘；α主線約八成，貢獻研究一頁摘要，細節放附錄。

開場可說：依照老師先前建議，本階段改以交付X的pooled品質比較α策略；建立組合與支持度兩條方法線並完成同資料比較。EU平均最佳，但尚未建立穩定優勢。另外已研究個別貢獻的局部與全程差異，尚無可取代完整移除的可靠低成本方法。

## 附錄建議

1. 完整方法與機器ID對照，歷史B→Q、EB→EQ、SB→SQ；不把舊quality_shrink當現在Q。
2. Q、E、S完整公式，SLSQP限制與數值停止；求解權重w與Stage3求X分開。
3. 本輪原12比較與追加4比較完整CI；原六確認／後加純法的時間順序。
4. 實驗控制與可重現性：資料、模型、accepted X、來源hash、重載及重播；詳細seeds放此，不當主文敘事。
5. 重抽樣獨立研究結果與文獻：文獻名稱與主張需另核對原論文；未核對不填虛構引文。其平均不可與本輪數值直接排名。
6. 貢獻四方案定義、內部D_L與外部D_E、四方案獨立成本、近零／失敗與探索性限制。
7. pooled/truth衝突與coverage；pooled是主要研究尺度，但不是無誤差真實品質。
8. 其他歷史α方法只作備查；不要在主文列所有試過的變體而沖淡兩條主線。

## 製作簡報前的核對清單

- 本規劃不是新實驗或老師批准。確認報告時長；若只有10–12分鐘，刪獨立例子頁6、合併8/4、合併11/10、貢獻頁移附錄，保留設計、結果與不確定性。
- 全文繁體中文，品質法統一Q；初始化A與貢獻錨點A分開命名。
- E/S例子逐項核算，與實驗表明確區分。
- 第10–12頁從原始分析檔產生圖，不從四捨五入摘要重抽樣。
- 不恢復使用者已刪的E盲測目標／倒推目標比較小節；必要語義限制以簡短備註或問答說明。
- 結果頁不寫「顯著優於」「均勻一定合理」「貢獻公平」「α不重要」。
- 貢獻J少26%是本輪統一快取口徑的模型評分成本，非端到端時間加速，且非通過預設成本條件。
- 方法與結果每頁有可追溯來源；主文不放冗長程式名、seed範圍或除錯史。
