# 當輪 j 拆成自己／其他模型評分：結果

2026-10-27。**分析、獨立驗證與原分數精確保留核對完成。新增搜尋與模型推論皆為0。**

主要結論：拆解能解釋一部分內外反號案例，但不能據此全面去掉自己的評分。原反號中，其他模型已與pooled同號、由自己的評分改變合計方向的比例，乾淨33.8%、污染24.4%；更多案例在其他模型合計中仍與pooled反號。固定同一批外部分母比較，只看其他模型的同尺度平均，方向一致率反而下降13.3／7.2百分點。

因此，建議保留「自己評分部分、其他評分部分、原j」三欄作診斷，不改原j，也不把其他模型評分直接採為新貢獻算法。本批沒有通過下一輪去除自己評分候選的研究優先門檻。

## 1. 範圍與資料

[分析規約](j_self_other_diagnosis_plan_20261027.md)固定後執行。全部20個既有開發團隊、5起點、5450個共同移除端點對，400筆參與者×起點累積。乾淨每隊3人，污染每隊5人。模型、權重、端點、搜尋路徑及原j全部保留。

來源為起點敏感度實驗保存的各模型原始回覆及pooled端點評分，以及前輪j當輪品質診斷。兩個來源完成receipt的全部hash、來源報告與本輪輸入均核對。pooled只對已產生端點離線查表，不進入任何搜尋、alpha或移除決策。

這是已揭露舊資料的後續探索，不是獨立新資料確認。來源20隊只有10隊／情境，不能把5450分支當成5450個獨立樣本。

## 2. 如何拆解

對被移除的參與者i，固定兩個端點：原團隊當輪端點x_full、移除i後的當輪端點x_minus。

每模型k先給出同端點評分差 delta_k=|f_k(x_minus)|−|f_k(x_full)|。原目標為0。

| 欄位 | 定義 | 正確解讀 |
|---|---|---|
| own | w_i×delta_i | 本人模型如何評價自己缺席造成的端點差 |
| other | Σ(k≠i)w_k×delta_k | 其他模型如何評價i缺席造成的同一端點差 |
| 原j | own+other，數值上直接沿用歷史原值 | 原完整評分面板的判斷 |
| other_mean | other/(1−w_i) | 剩餘模型平均的同尺度診斷；不是原j |

own與other保留原完整團隊權重，沒有各自重新正規化。原j、own、other皆可正可負。own與other相加須在1e-10容許內回到原j；累積OWN+OTHER也須回到原J。

**這不是錨點貢獻與模型貢獻的角色拆解。** own不是該人模型在求解中造成的因果作用；other也不是其他人的功勞。兩者都是對「移除i」這個端點差的不同評分來源。

本輪不重新搜尋，因此不能用它判斷若部署時排除某個評分模型，方向、縮步與最終解會怎麼改變。

## 3. 反號案例由哪個部分構成？

只在原j與pooled差j_E明確反號的案例中，分成以下三類。epsilon=1e-4，只分類、不改原值。原始反號筆數乾淨359、污染591。

| 原反號案例的其他模型評分 | 乾淨 [95%探索區間] | 污染 [95%探索區間] |
|---|---|---|
| 已與pooled同號，加入own後合計反向 | 33.8% [24.9%, 42.7%] | 24.4% [14.6%, 33.9%] |
| 仍與原j同號，仍反向於pooled | 41.5% [30.3%, 51.6%] | 58.6% [48.2%, 70.7%] |
| 其他模型合計接近零 | 24.7% [19.7%, 30.4%] | 17.0% [9.6%, 24.8%] |

三類互斥，合計100%。先同隊同起點內算比例，再同隊跨有效起點平均，最後情境團隊等權。區間按團隊bootstrap10000次、seed20261027；不是合併筆數比例。

第一類支持「自己的評分確實會改變部分端點對的合計方向」。但不能把它稱為自利、灌分、故意操縱，也不能推成只要排除自己的評分就會更準。

## 4. 公平比較：全面只看其他模型會更好嗎？

固定同一分母：abs(j_E)>1e-4。乾淨1387筆、污染2666筆。任何被比較的內部分數近零都算未命中，不因other難判而排除。

| 評分方式 | 乾淨同號率 [95%區間] | 污染同號率 [95%區間] |
|---|---|---|
| 原j | 59.8% [54.6%, 64.2%] | 57.7% [51.1%, 63.9%] |
| own，原權重部分 | 58.9% [54.3%, 62.7%] | 54.7% [51.7%, 57.4%] |
| other，原權重部分 | 44.8% [40.1%, 49.7%] | 49.5% [43.7%, 55.0%] |
| other_mean，剩餘模型平均 | 46.5% [41.5%, 51.7%] | 50.6% [44.9%, 56.0%] |

同隊配對的other_mean減原j一致率：乾淨−13.35百分點 [−21.75, −3.67]；污染−7.15百分點 [−11.82, −1.97]。本批不是改善。

other與other_mean的精確正負方向相同，表中不同主要來自固定epsilon下的近零分類。對比保留原權重部分與同尺度平均，避免把縮小尺度引起的近零增加，全部誤認成品質變化。

**為何原j不是前輪的69%／70%？** 前輪以內部abs(j)>epsilon作分母；本輪公平比較以外部abs(j_E)>epsilon作固定分母，所以包括「外部有作用但原j近零」的案例。分母改變，不是原算法或品質退步。

保留前輪原分母作交叉核對：原j仍是乾淨68.9%／污染69.9%；other_mean為51.5%／57.3%。在這個口徑，移除自己評分也沒有得到整體改善。

## 5. 排名與累積診斷

| 指標 | 原j／原J，乾淨／污染 | other_mean及其累積，乾淨／污染 |
|---|---|---|
| 當輪跨人rho對j_E | 0.390／0.336 | 0.211／0.184 |
| 當輪可排名輪覆蓋 | 78.9%／76.6% | 73.5%／79.1% |
| 累積值對同端點J_E的rho | 0.740／0.516 | 0.520／0.482 |

每個rho均先隊內起點平均，再情境等權。各方法有不同可排名輪，不能把條件rho當成完全相同子集上的配對優勝；覆蓋必須一起看。本輪主要公平比較仍是固定外部分母的同號率。

研究優先門檻要求兩情境至少8有效隊、20反號分支，反號集中other已同號比例>=30%且下界>10%，以及other_mean同號改善>=10百分點且下界>0。**兩情境均未通過完整優先條件**；乾淨反號解釋有訊號，但整體改善為負。原j、own、other、other_mean也均未通過局部品質探索篩選。

不以本輪「自己部分」或「其他部分」挑新冠軍，不改權重，也不以有用案例宣稱新方法有效。

## 6. 評分分歧與落差拆解

所有分支中，own與other明確異號比例為乾淨30.5%、污染27.7%。在abs(own)+abs(other)>epsilon的分支，自己的絕對作用占比平均61.7%／45.3%。這高於各自原均勻權重1/3與1/5，但端點本來就是移除本人所產生，存在條件選點；不能直接解讀為模型自利或因果過度影響。

在外部明確非零的分支中，模型評分差三分類（正／負／近零）並不全一致的比例，乾淨76.9%、污染83.7%；全部模型都與pooled同號的比例僅21.1%／16.0%。這顯示模型分歧普遍，但還不能指出是少數固定壞模型造成全部問題。逐模型400筆起點表與80筆隊內模型表已保存，可追溯每個實際模型在本端點集合上的條件評分表現；不作一般準確率或刪人依據。

原gap=j−j_E也精確拆成：

- own_gap=w_i×(delta_i−j_E)。
- other_gap=Σ(k≠i)w_k×(delta_k−j_E)。

兩者相加為gap。自己的落差絕對占比平均乾淨34.7% [32.8%, 36.8%]、污染28.8% [26.7%, 30.8%]。這是兩個可能相互抵銷的gap部分之絕對比值，不是「本人造成多少品質誤差」的因果百分比，也不能和前面的abs(own)占比混用。

## 7. 代表案例

每情境依固定規則各選一個other已同外部、以及other仍同原j的反號例，排序指標是min(abs(j),abs(j_E))最大。

### 例一：本人評分把合計方向改回去

污染seed2026101611、起點2、agent15、第4輪：

| 部分 | 差值 |
|---|---:|
| own | +0.062211 |
| other | −0.032483 |
| 原j | **+0.029728** |
| pooled差j_E | **−0.023072** |

其他模型合計認為移除後較好，與pooled同向。本人模型給出更大的正向部分，使原合計認為移除後較差。這是固定端點下可直接核對的方向改變。

### 例二：拿掉本人評分仍無法解決

乾淨seed2026101610、起點1、agent7、第2輪：own=+0.003186，other=+0.013488，j=+0.016674，但j_E=−0.024276。扣掉本人評分後，其他模型合計仍反向於pooled。

另一個污染例seed2026101618、起點3、agent3、第4輪：own=+0.005429（與j_E=+0.020647同向），other=−0.024304，原j=−0.018875。這次是其他模型合計使原結果反向。

乾淨other已同外部例亦保存：seed2026101616原起點agent13第4輪，own=+0.010874、other=−0.000366、j=+0.010508、j_E=−0.020985。此例other方向雖相同，幅度仍遠小於外部差，不能只憑方向稱完整修復。

前輪兩個最大反號例原樣核對：乾淨屬other仍反向；污染屬own改變合計方向。沒有事後更換案例。

## 9. 已完成、未建立有效性、下一步提案

**已完成：**原j／J精確保留下的評分來源拆解、反號三分類、公平同分母比較、逐模型表、gap恒等式與獨立核對。自己的評分確實解釋一部分端點對的方向改變；其他模型合計也會產生分歧。

**未建立有效性：**去掉本人評分可改善整體品質、own等於模型角色貢獻、other等於其他人功勞、任何部分可作分潤、pooled是真實部署效用、新團隊泛化或完整LOO替代。沒有識別模型操縱或因果過度影響。

**下一步提案：**保留原j、own、other三欄及累積，作固定任務／路徑下的研究紀錄；不採other-only，也不將兩部分各自轉成報酬。去除自己評分候選本輪未達研究優先門檻，不直接啟動新資料確認。

若研究目標仍是品質貢獻，下一步先用本輪逐模型表定義可部署的獨立評分驗證問題，另訂規約與開發／獨立資料分界；不以pooled挑模型、調alpha或作部署決策。若目標只需內部作用，可沿用原j而把本拆解作解釋。這次不自行改新算法或啟動新實驗。
