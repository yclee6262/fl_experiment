# 當輪錨點 LOO：計算、步長與短程延續驗證結果

日期：2026-10-20。**已完成本輪授權的舊資料探索與獨立驗證。單步計算可重建；步長穩定及直接累計為全程貢獻的支持門檻均未通過。**

## 先用白話說結論

這個分數確實回答：「在這個位置、用這個距離走一步，如果少一個錨點的方向，內部 loss 會差多少？」

但是，某個錨點當下讓我們多改善，並不代表它留下同等大小、同一正負方向的後續效果。後續搜尋可能補回落後，也可能走到更好的位置。因此可以保留它作**當輪局部貢獻紀錄**，目前不能將直接加總稱為已驗證的全程錨點貢獻。

這次也發現比較距離會影響結果。這不使原定義的數字算錯，卻表示分數是「固定比較條件下的局部作用」，尚不能稱為穩定的一般個人價值。

## 做了什麼

依[目前設計](anchor_step_loo_current_design_20261020.md)與[執行前規劃](anchor_step_validation_preregistration_20261020.md)，使用四個舊 pilot、20 個舊開發團隊（Clean／污染各10），固定已訓練模型、2D、3／5人、uniform alpha、target=0、box與custom30。

全部兩分支均保留完整評分模型與alpha；只在選定的當輪排除錨點方向，使用內部 L 計分。沒有重訓、alpha更新、模型角色貢獻或分潤實驗。

主公式不變：

`c_it = min(L(x_t), L(z_without_i,t)) - L(x_(t+1))`。

`A_i = sum_(原軌跡已接受步) c_it`。

本次完成四部分：

1. 重跑歷史測試與獨立重建，核對來源、權重、接受規則與覆蓋。
2. 所有992個已接受步×錨點組合做原距離／半距離比較；原尺度重用舊分數，半尺度兩分支均重新評估。
3. 每團隊固定第一個已接受步，產生完整與各錨點排除後的有效位置；後續兩邊恢復全部錨點，以共同的原步後控制狀態續跑1、3、5次迭代。
4. 內部分數與全部分支點鎖定後，才用 frozen pooled evaluator 離線評估已產生的有效點；truth未載入。

這是一次排除造成的位置差異延續實驗，並非之後持續移除錨點。替代分支的當前／global-best位置與loss改為自身有效結果，位置相關查詢重算；eta、模式與迭代索引沿用原完整步後設定。原控制設定有利於固定比較，但不是替代分支自行重新選步長的完整反事實。

## 已完成：計算與狀態重放通過

- 歷史11項測試及原獨立 verifier 通過；另4項狀態引擎測試涵蓋原解一致、續跑、terminal、secant→dynamic與位置變更。
- 24個完整重放的模型查詢數、順序hash、逐迭代位置、模式、接受歷史與最後解都符合歷史原紀錄。
- 24個完整分支的短程續跑查詢逐一符合原後續序列。狀態引擎由凍結原程式增加AST狀態輸入與紀錄，未修改歷史solver。
- 獨立 verifier 不匯入新狀態引擎，另作24次原方法重播、25,984個去重後參與者回覆重評，以及1,331個pooled點重評。
- 96個排除分支、992個半距離比較全部核對；模型回覆重評差0、內部loss與c最大差5.55e-17、pooled重評差0。
- 歷史程式、來源與結果hash保持不變。通過的是實作／資料一致性，不是分數效度。

## 結果一：現有分數只涵蓋原已接受步

20開發團隊：

| 項目 | Clean | 污染 |
|---|---:|---:|
| 已記錄方向迭代 | 111 | 140 |
| 有接受更新 | 91 | 122 |
| 沒有接受更新 | 20 | 18 |
| 已接受步×錨點比較 | 273 | 610 |
| 上述比較缺失／越界 | 0 | 0 |
| 試走總數 | 464 | 517 |
| 其中拒絕試走 | 373 | 395 |

接受更新迭代覆蓋為82.0%／87.1%；現有方法不計38個無接受更新迭代。其中20個secant失敗、18個dynamic失敗，沒有零合成方向停止。拒絕trial可能出現在最終成功縮步的迭代，不能與無接受迭代混為同一分母。

四pilot另外109組，總計992組。幾何沒有缺失，不等於拒絕／停止資訊已被計入。

## 結果二：比較距離改變會影響累計分數

將比較距離從原實際接受距離改為一半；完整與排除分支均在該半距離重新計算內部loss及接受結果，沒有挑較好的尺度替換主公式。

|---|---:|---:|
| 團隊內平均排名相關 | 0.65 | 0.68 |
| 探索95% seed區間 | [0.35,0.90] | [0.33,0.90] |
| 原明確非零A的符號保留，團隊平均 | 83.3% | 72.0% |
| 有效排名團隊 | 10/10 | 10/10 |
| 預定步長穩定門檻 | 未通過 | 未通過 |

規約為平均排名至少0.8且明確非零符號保留至少90%。未通過不代表應改用半步，而是不能宣稱分數對比較距離穩定。

## 結果三：當輪差異常被後續搜尋改變

每團隊僅第一個已接受步；該步排除一次後恢復所有錨點。deadzone=1e-4。先在團隊內算比例，再按10個團隊平均，不把所有人當成獨立樣本。

| 後續迭代 | Clean符號保留 | 污染符號保留 | Clean平均排名相關 | 污染平均排名相關 |
|---|---:|---:|---:|---:|
| 1 | 53.3% | 65.0% | 0.50 | 0.45 |
| 3 | 46.7% | 56.0% | 0.44 | 0.28 |
| 5 | **40.0%** | **49.0%** | **0.00** | **0.09** |

五次迭代後的詳細狀態：

| 指標 | Clean | 污染 |
|---|---:|---:|
| 保留原明確正負方向 | 40%，CI[20%,60%] | 49%，CI[40%,59%] |
| 反轉為相反方向 | 30%，CI[13.3%,50%] | 47%，CI[36%,58%] |
| 消退至近零 | 30% | 4% |
| 排名相關95%區間 | [-0.5625,0.5625] | [-0.24,0.42] |

符號比例兩情境均有10/10團隊明確初始作用；Clean有兩團隊的跨錨點差異近乎平坦，排名未定義，保留案例不補零。

預定延續門檻要求符號保留≥80%、反轉≤10%，且足夠團隊有平均排名≥0.5、區間下界>0。兩情境均未通過。這支持「當輪局部作用不穩定延續」的入口狀態診斷，尚不能指定全軌跡每一步的機制，亦不能據此證明任何形式的累計都不可能。

### 代表案例：當下幫很多，之後另一分支追上並超越

Clean seed2026101613、agent10，依事前規約選「初始絕對作用最大的五步反轉案例」：

| 時點 | 完整分支內部L | 當輪排除分支內部L | 差值c |
|---|---:|---:|---:|
| 當輪 | 0.017235 | 0.112984 | +0.095749 |
| 續跑1次 | 0.016107 | 0.042305 | +0.026198 |
| 續跑3次 | 0.014204 | 0.013770 | -0.000434 |
| 續跑5次 | 0.013366 | 0.012306 | -0.001060 |

兩條路後續均保留agent10錨點。原本少了它而落後的分支，後來追上且內部loss更低。這說明一筆+0.095749的當輪紀錄，不能直接當作保留下來的全程收益；並非計算符號錯誤。

污染代表例seed2026101619、agent3由+0.071343降至五步後-0.000180；但同一五步分支的pooled差仍+0.032444，另提醒內部與外部品質也可能異向。

## 結果四：pooled只作離線診斷

對原全部已接受步的有效位置比較，先逐步做團隊內錨點排名，再團隊內平均，最後情境平均；平坦步不造出排名：

| 當輪內部c對離線外部差值 | Clean | 污染 |
|---|---:|---:|
| 平均排名相關 | 0.1663 | 0.4640 |
| 探索95% seed區間 | [-0.0700,0.4125] | [0.2832,0.6376] |
| 內部明確作用的外部同號率，團隊平均 | 63.4% | 74.7% |
| 外部反號率，團隊平均 | 34.6% | 23.2% |

污染情境存在局部正向關聯，但不代表所有情境有效，也沒有推翻內部累計對全程效果的既有失配。本輪沒有以這些值選參數或修改分數。

## 成本與預算

pilot先完成技術與成本檢查，再按事前公式凍結開發上限98,240 samples／120秒；開發實際29,178 samples，未觸及上限。以下全部是本輪**驗證研究工作**，不是單次部署算分成本：

| 參與者模型輸入評估 | 四pilot | 20開發團隊 |
|---|---:|---:|
| 完整原搜尋狀態重放 | 1,083 | 8,448 |
| 半距離診斷 | 576 | 4,752 |
| 共用完整短程續跑 | 509 | 2,837 |
| 各錨點排除後短程續跑及起點核對 | 2,182 | 13,141 |
| 小計 | **4,350** | **29,178** |

主要執行合計33,528；獨立驗證另有原solver重播9,531、去重回覆重評25,984，合計35,515。因此本輪新增研究參與者模型評估總量69,043，scalar API calls與samples相同。四個狀態測試的人工objective與歷史單元測試不算實際參與者查詢。

pooled主要離線評估去重後1,331點（pilot167、開發1,164），獨立再評1,331點，共2,662；與參與者模型成本分列。完整執行各phase wall time約0.399／1.504秒（含載入與寫軌跡）；獨立驗證約1.448秒。環境為本機單執行緒小模型，並非網路API效能保證；沒有新增冷啟動或遠端效能實驗。

既有單次原方法成本仍沿用舊報告：20團隊baseline+單步歸因12,287 samples，相對baseline+完整參與者LOO33,120省62.9%，但相對baseline增加45.4%。不能把本次額外診斷成本當成該算法部署成本，也不能把舊成本比例外推新規模。
