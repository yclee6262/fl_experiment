# 同團隊穩健端點品質：開發登錄

2026-10-20。共享代理的原團隊mean_abs在Clean已0.70，污染只有0.19；與pooled離線代理0.80/0.68的差距提示單一高誤差評分者可能主導uniform內部尺。本族測不改求解alpha的穩健端點評分，不刪參與者，也不把個人誤差或支持度直接當貢獻。

重用原3/5人團隊在固定代理端點及baseline的signed預測，Q先取各人abs(f-target)，再依以下三種固定彙整：

- trim20：兩端各去floor(m*0.2)個誤差再平均。
- upper20：只去最大floor(m*0.2)個誤差再平均。
- winsor20：兩端各floor(m*0.2)個誤差替換為相鄰保留值再平均。

m=3時k=0，三方法等於mean_abs；這不是新獨立訊號，完整揭露重複。m=5時k=1。score_i=Q(z_proxy,-i)-Q(X_full)，全程固定原團隊評分，solver仍原uniform alpha。三種方法×四代理設定=12候選（有代數重複），全部保留；零新增模型查詢。不能按情境選不同規則、反轉正負或調trim比例。

同20舊開發團隊、同LOO、同團隊內Spearman／seed bootstrap10000/RNG20261020。兩情境均>0.5、有效覆蓋>=90%才可選；最小情境相關最大，平手5格、linear、方法名稱排序。此前6族152個global-free候選（有重複）均未通過，4個offline_E診斷另列。

若通過，需在新40團隊任何LOO／pooled品質揭露前凍結單一方法與配置，才能進入該全新資料的獨立確認。新資料生成不讀效果，仍可用於已凍結新方法；若已揭露效果則需另保留新seed。確認兩情境平均>0.5、95%下界>0、有效覆蓋>=90%；全成本與非嚴格非LOO邊界沿用總計畫，不把穩健評分當作已授權pruning或alpha更新。
