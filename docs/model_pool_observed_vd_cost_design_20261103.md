# 模型池低成本觀察分數 V/D：執行設計

## 目的

錨點池維持完整的逐輪內部 loss 移除 (C^A)。本實驗只改模型池：不再為每一位模型重跑搜尋，也不額外建立探測點。它檢查原始切線法／割線法搜尋已留下的兩類資訊能否完整讀取，並量測整體成本是否低於完整 participant LOO。

## 固定的兩個模型指標

設完整模型權重的內部 loss 為 (F)，當輪原點為 (x_t)，實際接受的終點為 (x_t^F)。原始搜尋依序試過的候選點為 (z_{t,1},z_{t,2},\ldots)。

對模型 (i)，以其餘模型的原權重正規化，從已記錄的 trial 中取第一個能使其餘模型 loss 嚴格小於原點的候選 (z_{t,i}^{-i})。若不存在，取原點。定義：

\[
V_{i,t}=F(z_{t,i}^{-i})-F(x_t^F).
\]

因此，(V) 表示「在實際已出現的候選順序下，少了模型 (i) 時，決策會落到比完整決策差多少的點」。它是已觀察決策服務的影子分數，不是把模型移除後重新搜尋的品質結果。

令 (G_{i,t}) 為模型 (i) 在當輪組合搜尋方向中的加權向量分量，且 (g_t=\sum_iG_{i,t})。定義：

\[
D_{i,t}=\frac12\left\|\frac{g_t}{\|g_t\|}-\frac{g_t-G_{i,t}}{\|g_t-G_{i,t}\|}\right\|.
\]

當兩個分母為零時，標為未定義而不以零代替。(D) 只表示方向是否會因少一個模型而改變；本輪不將它轉為付款。

## 對照與成本口徑

1. **完整 (C^A+V/D)**：原始完整搜尋一次；每輪為每位參與者做一次完整錨點移除分支；(V,D) 只讀取該次搜尋已快取的模型 loss 與方向。
2. **full LOO**：原始完整搜尋一次，再為每位參與者完整移除後重跑整個搜尋。

成本以 cache 空白時的實體模型評分次數計。兩臂都使用凍結的 20 個歷史主案例、相同起點、30 輪、相同模型與權重。觀察 (V/D) 後會驗證所有讀取都是 cache hit；若有新的實體模型呼叫，該觀察分數不再符合本設計。

## 驗收與停止條件

- 原始完整解、full LOO 解均須逐筆重現既有凍結結果。
- 完整 (C^A) 的數值須與既有錨點分支一致。
- (V/D) 讀取造成的新增實體模型呼叫必須為 0。
- 任一重現失敗、方向重建誤差超過 (10^{-10})、或觀察讀取出現 cache miss，即停止並標記失敗。

本實驗不更新 alpha、不改搜尋決策、不做 pruning、付款或 pooled/truth 評估。
