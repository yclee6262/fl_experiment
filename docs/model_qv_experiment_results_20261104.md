# 錨點 C^A＋模型 Q/V 實驗結果

## 判讀

新方案能完成分角色計算，Q也確實捕捉V未涵蓋的方向作用。但完整計算Q的成本明顯高於full LOO，且獨特性逐輪加權可能使方向淨效果為負的模型取得正Q。因此目前適合保留為研究候選，不宜直接視為已完成的低成本模型池分潤方法。

## 已完成

實作位於 `contribution_analysis/model_qv_v1/`，完整結果位於 `contribution_analysis/model_qv_experiment_20261104_attempt_02/`。既有20隊凍結神經網路案例完成回歸；另完成40隊新種子解析模型案例。每隊四個版本，各暖機一次、交錯量測三次，分數與呼叫數重跑一致。原搜尋各版本相同、既有C^A與LOO重現，方向重建通過，V讀取新增呼叫為零。六項機制測試通過。

40隊解析案例含一般、完全重複、方向係數不同、方向與偏置不同各10隊。同組種子跨情境配對，並非40個獨立種子，也不是新訓練神經網路的確認集。不同係數本身不預設有益或有害，改善由固定完整內部F比較。此次不使用pooled/truth。

## 計算方法

錨點C^A沿用完整逐輪錨點方向移除。模型方向分支僅扣除模型i的方向分量G_i，保留全部錨點與完整評分F，依原初始步長、十次縮步與接受規則得到x^{-G_i}。

\[
C^{dir}_{i,t}=F(x_t^{-G_i})-F(x_t^F),\qquad
Q_i=\sum_t\frac{U_{i,t}}{10+U_{i,t}}C^{dir}_{i,t}.
\]

U沿用25點Q90-Q10尺度、實際有效且去重方向上的標準化斜率最近鄰RMS差。V沿用固定原trial序列中，忽略模型i評分後的第一個可接受候選，再由完整F比較。兩者分開保存，正負Q跨輪累積。

## 分數與模擬分配

| 指標 | 既有20隊 | 新解析40隊 |
|---|---:|---:|
| participant-round | 1,033 | 2,900 |
| Cdir為正的輪次紀錄 | 607 | 1,543 |
| Cdir為負的輪次紀錄 | 323 | 1,116 |
| 累積Q為正的模型 | 48 / 80 | 92 / 160 |
| 累積Q為負的模型 | 32 / 80 | 48 / 160 |
| Q正、V近零 | 0 | 4 |
| V正、Q非正 | 32 | 65 |
| Q正、未加權累積Cdir負 | 5 | 11 |

完全重複的兩個模型在全部10隊中每輪U均為零，因而Q為零，符合「獨特性」定義。但這只表示它們不提供獨特資訊，不能解讀為沒有一般模型服務價值。

Q與V提供不同角色訊號：解析案例有4位Q正而V近零，顯示Q能辨認V漏掉的方向作用；也有大量V正而Q非正，表示接受判斷作用不代表方向作用有益。

關鍵問題是逐輪U加權會改變正負效果的權重。例如既有clean seed1610、模型索引0（原agent 6）：未加權累積Cdir=-0.000128123，但Q=+0.00000166128，V=+0.00240879。它在獨特性較高的輪次改善較多，而方向整體有號總和仍為負。因此Q正的正確解釋是「獨特性加權作用為正」，不能直接稱為「方向淨改善為正」。

模型池採Q/V各半、兩部分分別按可靠正值正規化的模擬下，最高個人比例的團隊平均約59.3%（舊）與60.5%（新）；最極端單人分到92.3%與98.7%。舊案例1隊無正Q，保留該隊一半預算。Q比重提高至75%時，平均最高比例上升至63.0%與69.2%。因此能算出固定預算比例，不代表分配均衡或公平性已建立。

## 未建立有效性

此次驗證支持計算定義、重現與角色互補，但沒有建立公平付款、誘因、防操弄或外部品質的有效性。六個受控機制檢查是局部測試，不可延伸為所有真實團隊的品質保證。正負Cdir本身就是本方案內部效果定義，不能拿它與Q的公式關係作為獨立品質證據。

成本目標未通過；目前Q也存在有用獨特性與方向淨改善異號問題。模擬的數值門檻1e-10是固定的數值處理，不是經濟意義的最低貢獻門檻。基本池與正式付款未整合。

## 下一步提案

先保留C^A+V為已知成本參考，將完整Q視為高成本的方向效果基準。若仍要推進Q，先確認是否要求「未加權累積Cdir也必須為正」作為獨特性獎金資格，並以現有資料重算分配，不必新增模型評分。這是待選規則，尚未在本次主結果使用。

成本優化應針對22,292／42,992次的模型方向分支，研究抽樣輪次與不確定性，而不是優先移除一次性尺度校準。抽樣方案需另凍結設計，完整Q作參考，不直接宣稱可替代。
