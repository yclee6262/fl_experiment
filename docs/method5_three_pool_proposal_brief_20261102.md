本提案將切線法／割線法搜尋中的報酬分成三個池。**每位參與者都須同時提供有效錨點與模型評分服務**，再依兩種角色的作用分別計算獎金。

| 獎池 | 支付依據 |
| --- | --- |
| 基本貢獻池 | 完整提供服務，且錨點與模型累積分數沒有同時為負 |
| 錨點貢獻池 | 錨點方向使當輪決策改善多少 |
| 模型貢獻池 | 模型評分帶來的決策改善，以及有實際作用的獨特資訊 |

總預算為 $B=B_0+B_A+B_M$，個人總報酬為 $P_i=P_i^0+P_i^A+P_i^M$。各池獨立計算，未分配款保留，不自動轉入其他池。

**共同評價標準：**$F(x)=\sum_jv_j|f_j(x)-y^\star|$，其中 $f_j$ 是模型預測、$y^\star$ 是目標、$v_j$ 是固定權重且合計為 1。F 越低，表示依團隊內部標準越接近目標；不等於已證明外部真實品質更好。

以下保留目前已實作的當輪移除方法；近期討論的純觀察低成本方法尚未納入本版。

## 一、基本貢獻池：完整服務的基本報酬

### 做法與公式

參與者須完成有效錨點交付及規定的模型評分。完成服務後，**只有錨點與模型累積分數都為負，才不發基本費**；一正一負，或其中一項為零，仍具基本費資格。

令 $d_i=1$ 表示兩種服務皆完成，否則為 0；$S_i^A$、$S_i^M$ 分別為後兩節定義的錨點與模型有號累積分數。資格為 $e_i=\mathbf1\{\neg(S_i^A<0\ \land\ S_i^M<0)\}$。

基本費：$P_i^0=b_i d_i e_i$，其中 $b_i$ 是事前約定的固定費，且 $\sum_i b_i\le B_0$。

分數須完整可計算；未知值不能當成零。實作時沿用數值容差，近零視為零，不因浮點誤差判定負值。基本費的負分判斷使用 C 的累積值，不使用非負的 N 或已截正的獎金。

### 例子

假設每人基本費 100，且三人都已完整提供服務：

| 參與者 | 錨點累積 $S^A$ | 模型累積 $S^M$ | 基本費 |
| --- | ---: | ---: | ---: |
| 甲 | 3 | −1 | 100 |
| 乙 | −2 | 1 | 100 |
| 丙 | −1 | −0.5 | 0 |

這是「履約＋雙負排除」的基本報酬，不是無條件保障。**雙負排除為本次新增提案，尚未實作驗證；先前僅按履約付款的驗證不能直接套用。**

## 二、錨點貢獻池：獎勵讓當輪結果更好的方向作用

### 做法與公式

每輪從原搜尋位置出發，先取得完整團隊的接受結果 $x_t^F$。再暫時扣除參與者 i 的錨點方向作用，依相同初始步長及原縮步／接受規則，得到 $x_t^{-A_i}$。

移除時保留全部評分模型，其他錨點權重不重配；分支只跑當輪，不改變後續原搜尋路徑。

單輪貢獻：$C^A_{i,t}=F(x_t^{-A_i})-F(x_t^F)$。

有號累積：$S_i^A=\sum_tC^A_{i,t}$。正值表示保留該錨點作用使結果較好；負值表示該輪移除後反而較好。先累積正負值，再決定獎金，不逐輪只取正分。

令 $w_i^A=S_i^A\mathbf1\{S_i^A>\tau_i^A\}$，其中 $\tau_i^A$ 為數值可靠性門檻。錨點獎金為 $P_i^A=B_A w_i^A/\sum_jw_j^A$；無可靠正值時保留整池。

### 例子

某輪完整結果 loss 為 8，移除甲的錨點方向後為 10，則甲得 $C^A=10-8=2$。即使甲的方向與其他錨點相反，只要使最後結果更好，仍會得到正分，因此能反映有益制衡。

若三人跨輪累積為 $S^A=(3,2,-1)$，錨點池 500 就分為 **300、200、0**。

## 三、模型貢獻池：決策改善 C＋資訊補充 N

模型池分成兩個額度：**80% 按正淨改善 C 分配，20% 按具正 C 資格者的資訊 N 分配。** 80／20 是目前研究設定，不代表已證明最適。

### C：模型評分讓決策改善多少？

暫時移除模型 i 的評分，保留全部錨點，以剩餘模型重新計算當輪方向、縮步與接受結果，得到 $x_t^{-M_i}$。剩餘評分權重正規化，但兩個端點最後都用原完整 F 評價。

單輪分數：$C^M_{i,t}=F(x_t^{-M_i})-F(x_t^F)$；有號累積：$S_i^M=\sum_t C^M_{i,t}$。

例如完整端點 loss 為 8，移除模型後的端點以同一把尺評為 9.5，則該模型本輪 $C^M=1.5$。

### N：資訊是否獨特，而且影響決策？

N 同時看兩件事：

- **U：獨特性。** 模型對搜尋方向的判斷，是否與其他模型不同？
- **I：決策影響。** 有沒有這個模型，當輪接受端點差多少？

對當輪有效探測方向 k，模型的標準化斜率為 $g_{i,k,t}=[\ell_i(p_{k,t})-\ell_i(x_t)]/(s_i h_{k,t})$。其中 $\ell_i(x)=|f_i(x)-y^\star|$，p 是原割線錨點或切線探測點，h 是實際探測距離；$s_i=Q_{0.90}(\ell_i)-Q_{0.10}(\ell_i)$ 由事前固定共同探測點取得。目前二維實驗使用 25 點。

去除完全重複探測方向後，令方向數為 $K_t$，獨特性為 $U_{i,t}=\min_{j\ne i}\sqrt{\frac1{K_t}\sum_k(g_{i,k,t}-g_{j,k,t})^2}$。

決策影響為 $I_{i,t}=\|x_t^F-x_t^{-M_i}\|_2/\eta_t$，其中 $\eta_t$ 為原輪開始步長。

資訊分數為 $N_{i,t}=\frac{U_{i,t}}{10+U_{i,t}}\frac{I_{i,t}}{1+I_{i,t}}$，累積為 $R_i^N=\sum_tN_{i,t}$。

若資訊與別人完全相同，U 為零；若沒有改變接受端點，I 為零。任一為零，N 就為零。N 本身不判斷改善方向，所以必須另有正 C 資格。

### 分配公式與例子

令 $w_i^C=S_i^M\mathbf1\{S_i^M>\tau_M\}$，$w_i^N=R_i^N\mathbf1\{S_i^M>\tau_M,\ R_i^N>\tau_M\}$。其中 $\tau_M$ 是數值門檻；目前為 $\max(10^{-8},T\cdot10^{-10})$。

模型獎金為 $P_i^M=0.8B_M\frac{w_i^C}{\sum_jw_j^C}+0.2B_M\frac{w_i^N}{\sum_jw_j^N}$。分母為零時保留對應額度，不轉給另一額度。

假設模型池 500，三人的累積如下：

| 模型 | 累積 C | 累積 N | C 獎金 | N 獎金 | 合計 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 甲 | 3 | 0.2 | 300 | 25 | 325 |
| 乙 | 1 | 0.6 | 100 | 75 | 175 |
| 丙 | −0.2 | 0.8 | 0 | 0 | 0 |

丙雖然資訊不同，但淨 C 為負，不能領模型獎金；其基本費仍須合併錨點分數判斷是否「雙負」。

**目前接受的取捨：**小幅正 C 者可能因為是唯一有合格 N 的人，取得全部 20% 補充額度。實驗已出現此情況，本版暫不加入漸進式調整。

各成果池以完整資料計算，取整採最大餘數法。現有驗證支持限定情境下的計算與帳務正確性，尚未建立公平性、抗操弄與部署有效性。pooled 僅作離線驗證，truth 僅作診斷，不作分配輸入。

## 四、與完整 LOO 的差異及成本比較

### 兩者回答不同問題

| 方法 | 計算方式 | 回答的問題 |
| --- | --- | --- |
| 本提案 | 原路徑每輪分開移除錨點方向、模型評分，再累積 | 參與者在原搜尋中，透過兩種角色影響當輪決策多少？ |
| 完整參與者 LOO | 從頭共同移除該人的錨點與模型，沿新的路徑搜尋到底 | 如果整次搜尋沒有這個人，最後結果差多少？ |

完整 LOO 的分數為 $D_i=F(x_{\mathrm{final}}^{-i})-F(x_{\mathrm{final}}^F)$。逐輪累積不等於完整 LOO，因為移除後的後續路徑與停止時間可能改變。

### 實測結果：目前新流程較貴

相同保存模型、起點、CPU 與搜尋規則，兩邊皆允許各自的精確快取；新流程完整計入尺度探測、兩類分支及分配。

| 情境 | 本提案評分次數 | 完整 LOO | 增加 |
| --- | ---: | ---: | ---: |
| 乾淨 10 隊 | 9,206 | 6,111 | 50.6% |
| 受控污染 10 隊 | 30,212 | 21,303 | 41.8% |
| 合計 20 隊 | **39,418** | **27,414** | **43.8%** |

20 隊全部較貴。本機核心計算時間的各隊中位數加總約為 **1.365 秒對 0.813 秒，約 1.68 倍**；不外推大型模型或遠端部署延遲。

### 為什麼只重算一輪，還是比較貴？

本方案每輪都做兩種角色移除，共約 $2nT$ 個局部分支；完整 LOO 則是 n 條完整重跑路徑。局部分支仍可能反覆縮步並呼叫多個模型，完整 LOO 也可能提早停止。

本輪成本主要來自：

| 新流程工作 | 實際評分次數 |
| --- | ---: |
| 原搜尋 | 7,325 |
| 錨點逐輪移除 | 17,472 |
| 模型逐輪移除 | 11,698 |
| 25 點尺度探測 | 2,000 |
| 共同 F 補評 | 923 |

U 的方向特徵補讀已全部命中快取；主要負擔是兩類移除分支，不是 N 的公式。即使假設免除全部尺度探測，仍比 LOO 多約 36.5% 評分。

**提案定位：目前可作分角色的局部貢獻與分配研究，但不能宣稱比完整 LOO 便宜。** 若低成本為必要條件，後續須研究共用計算或新的純觀察分數，再另行驗證。

本成本結果來自原基本池履約規則；新增的「雙負排除基本費」尚未重測，不能標示為已完成新版整合驗證。結果依據為研究報告「法五完整貢獻流程與完整參與者 LOO：成本比較結果」（2026-10-30）。
