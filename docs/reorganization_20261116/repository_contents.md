# Git收錄與本機資料

2026-11-17。本次提交收錄主程式、實驗入口、測試、必要相容連結、封存原始碼、研究規約／報告、分類清單與精簡驗證紀錄。

`archive/legacy/`仍被測試和舊匯入引用，因此一併收錄。`contribution_analysis/`只收錄明確列出的程式套件直接原始碼，以及三個保留介面引用的凍結source_snapshot；不將整個實驗結果庫加入Git。`.gitignore`內逐套件列出例外，方便審查。

下列本機資料不在提交內：訓練模型、alpha_weight_outputs、貢獻度逐案端點／查詢事件、實驗CSV／圖表、簡報產物、可重建快取，以及含字型與編譯檔的論文原稿資料夾。原先已追蹤的早期結果改為取消追蹤；本機檔案保留。

一般單元測試、模型訓練型小範例及FedAvg執行入口可用程式與依賴環境執行。歷史初始化重播需額外提供指定source下的local_models、盲測／提案與evaluator；24團隊成本重播需額外提供原registration及records。這些資料從本機保留目錄取得；Git提交本身不構成完整研究資料發行包。詳見[執行指南](README.md)。

位置驗證器在沒有本機論文bundle的checkout會跳過該bundle雜湊檢查；bundle存在時仍檢查原有36檔。資料缺失不應靠移除舊規約hash檢查來繞過。
