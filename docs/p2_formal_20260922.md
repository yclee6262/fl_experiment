# P2 正式比較結果（2026-09-22）

## 問題與預先固定的判準

本階段回答：動態更新 α 是否比靜態權重產生品質更好的最終 accepted X，且改善能否抵銷額外查詢成本。

正式主要指標為凍結 pooled evaluator 的
`E_global(X) = |f_global(X) - Y*|`。合成真實函數誤差 `E_true` 是次要診斷，不取代主要判準。每個 seed 的四種方法共用資料、local models、候選點、coalition 與 evaluator；evaluator 只在演算法結束後評分，不回饋 α 更新、選人或 pruning。

正式 seeds 為 100–129。方法、最多 20 rounds 與其他參數沿用 pilot 後固定的版本，未依正式結果重新選參數：

- A：Uniform α，不更新。
- B：Stage 0 品質權重，不更新。
- C：Uniform 起始，固定步長 0.5 更新。
- D：Uniform 起始，Guarded 更新，初始步長 0.5。

Clean 使用 Stage 1 coalition 與 uniform 內部 evaluator；Poison 使用固定 5 人、含 1 名污染者的受控 coalition 與 trimmed 內部 evaluator。兩者皆為 2D、target 0、不啟用 pruning。

## 完整性與重現驗收

- Clean 與 Poison 的 manifest 均為 `complete`。
- 每個情境各有 30 seeds × 4 方法，共 120 列；沒有缺少方法或配對 seed。
- 240 個 accepted X 全部從保存的 checkpoint 重載 evaluator 後重評，`mismatches=0`。
- 所有正式 seeds 都保留。Clean C 的 seed 108 產生 1 個 box-infeasible accepted X，列入品質與失敗率，不排除。
- Poison B 的 seed 103 沒有可正規化的正貢獻，保留為 invalid q；付款使用 `opt_fallback`，沒有把 fallback 回寫為更新 q。

## 主要配對結果

沒有任何 B、C 或 D 相對 A 的 `E_global` 信賴區間完全小於零，因此正式結果未建立穩定的外部品質改善。D 的平均誤差在兩個情境略低於 A，但差值區間跨零，且成本約為 A 的 16.4–16.5 倍，不能據此支持動態更新作為目前的主要方案。

`E_true` 的六個配對比較同樣全部跨零。pooled evaluator 與 truth 在正式 seeds 的 evaluator test truth RMSE 平均為 0.01128、最大為 0.01328；這是代理評估限制，正式主要判讀仍依預先固定的 `E_global`。

## 機制指標與品質的關係

相對 A，C 與 D 的 α–q L1 在兩個情境多呈穩定縮小：

- Clean C：平均差 -0.6981，95% CI [-0.9029, -0.4793]。
- Clean D：平均差 -0.4283，95% CI [-0.5905, -0.2792]。
- Poison C：平均差 -0.2224，95% CI [-0.4234, -0.0204]。
- Poison D：平均差 -0.3493，95% CI [-0.4926, -0.2058]。

同一批正式結果中，外部 `E_global` 沒有穩定改善。因此「α 更接近 q」目前只證明數值一致性提高，不能作為 delivered X 品質改善的替代指標。D 的內部 `L_eval` 相對 A 在 Clean 與 Poison 均有穩定改善，也沒有轉化成穩定的外部品質優勢。

## P2 決策

P2 不支持把目前的動態 α 更新列為主要方案。下一階段採取以下決策：

1. 以 A（Uniform、不更新）作目前主要品質／成本基準；B 可作較便宜的靜態對照，但未顯示品質優勢。
2. C／D 保留為研究對照，不進入 P4 更新調參；正式結果已顯示一致性改善不足以證明 X 改善。
3. 依計畫進入 P3，先驗證目前 q 實際衡量的是候選點影響，並以小型完整參與者移除反事實作參考。
4. P3 比較以原始帶符號貢獻 `C_i` 為主，保留 invalid q；主要結果仍由 frozen pooled evaluator 評分。
5. P3 完成前不啟用 pruning，避免把尚未驗證的負貢獻估計直接用於移除參與者。

Clean C seed 108 的 box failure 另列為 P4 前必須處理的工程問題：先建立可重現測試並確認限制是在求解器內保證或只做事後檢查；不得回頭刪除該 seed 或改寫本次 P2 正式結果。
