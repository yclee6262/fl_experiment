# 共享回應代理：開發登錄

2026-10-20；在共享有限位置庫四方法未通過後另立新假說，該負面結果保留。

## 假說與適用範圍

共享位置庫缺少角色移除後的新路徑。改用本次正常custom搜尋已取得的signed模型回覆及共同格點，建立各模型回應的插值代理，再在代理上模擬完整角色移除的custom30。真實模型不逐人從頭跑；但代理仍逐人模擬反事實，所以這是**低查詢LOO近似，並非嚴格不含LOO的統計方法**。不依賴歷史數據複製或校準，代價是2D插值有維度與路徑不連續限制。

## 固定方法族（先鎖定再觀測相關）

- 正常求解只增加被動signed回覆記錄，必須逐查詢hash、history與baseline解完全一致；20案重放記錄為研究成本，不假裝部署需要多跑一次。
- 共同探測點：原正常搜尋所有查詢位置的逐維包圍盒，各方向寬度至少0.05，再向外擴20%，限制於[-1,1]；取5×5或9×9規則格點。兩解析度嵌套；所有模型在相同格點回覆，scalar API逐點計calls/samples。
- 兩種固定插值：Delaunay分片線性（凸包外nearest補值並記錄次數）；thin-plate RBF，nearest32點、degree1、smoothing1e-10。SciPy官方文件規定degree1的點需非共線、零smoothing需位置互異；本設計以float32去重和格點保障幾何，另保留數值失敗，不看相關調參。
- 四個代理端點設定=兩解析度×兩插值。每個i在代理上同時刪模型與候選，原剩餘alpha正規化；原X0、box、custom30、退火與模式沿用。不能用真實LOO位置校準代理。
- 產生並鎖定所有代理端點後，才向原模型查端點，形成四種可部署Q分數（平均絕對、絕對誤差中位數、signed中位數絕對值、signed平均數絕對值）的差值。共16個主候選，全報告。
- 另在全部分數鎖定後，讀pooled對代理解作離線品質驗證，形成4個offline_E診斷。它可檢查代理路徑是否接近參考，但**不得混稱global-free方法通過**，不可用來產生代理位置、修改alpha或刪人。truth不用。

## 資料、門檻與成本

沿用20個舊探索團隊與80個完整參與者LOO效果，全數視為開發。16方法完整揭露，按兩情境最小平均Spearman選單一候選；兩情境均>0.5、有效覆蓋>=90%才有資格獨立確認。只offline_E過門檻代表離線代理可行，尚未滿足部署可得配分目標。

團隊同分留未定義，不能填0；近乎無差異1e-4另列。以seed bootstrap10000次、固定RNG20261020，完整披露嘗試數。若通過，依總計畫保留全新seeds2026102200–2219確認；確認前凍結單一版本與成本方案，不能開發後再調同批稱驗證。

開發上限：20次真實正常重放、320次代理模擬、20,000額外真實模型samples、600秒代理運算；零新訓練與真實LOO求解。pooled離線評估另列。正常+方法samples需<=正常+真實LOO的70%，時間需另實測，不能只憑查詢少宣稱省總時間。精度改變及代理成本均保留，不以失敗案例消失製造高相關。
