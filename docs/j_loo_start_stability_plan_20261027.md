# J 與完整 LOO：起點敏感度及成本實驗規約

日期：2026-10-27。執行前設計；結果另存，不回寫本文件的歷史狀態。

## 1. 目的與範圍

使用者授權依前次設計實作、執行與判讀。主要候選只有共同移除當輪累積值 J 與完整參與者 LOO。這一輪執行「穩定性＋小規模成本」最小設計；不擴大為新團隊、新人數、新模型訓練或獨立泛化確認。

起點是任務條件。此處測量跨起點敏感度，不要求條件貢獻必須不變；未通過穩定門檻不等於計算錯誤，也不能證明沒有貢獻。

## 2. 資料與起點

沿用 layer2 cases.json 的舊開發團隊：乾淨及 controlled_poison 各10隊，seed 2026101610–1619，共80人。技術 pilot 使用同一檔案 pilot 每情境首隊，共2隊，不加入開發統計。

每隊5個起點：s0=原 fixed_start；sx+=s0+(0.25,0)；sx−=s0−(0.25,0)；sy+=s0+(0,0.25)；sy−=s0−(0,0.25)，逐座標裁切到[-1,1]。不根據模型、分數或 pooled 挑選。若同隊起點重複、非有限或不可行，先停止檢查，不自動換起點。是局部軸向擾動，不涵蓋所有可行起點。除起點外，模型、錨點、權重、target=0、box與 custom30 全固定。

## 3. 方法

J：每個起點先執行完整團隊原搜尋並擷取輪前狀態。對每個實際進入的外層輪（包括拒絕與停止輪），從該狀態同時移除該人的錨點與模型；剩餘錨點權重與模型權重各自正規化，依原規則執行一完整外層輪，允許原10次縮步。重算移除目標下的目前及錨點 loss，保留原輪的 eta、模式、delta。j=L_ref(移除後端點)−L_ref(原當輪端點)，J=Σj。各輪獨立，不接續移除軌跡。

完整 LOO：同時移除該人的錨點與模型，從與完整團隊相同的本次起點搜尋，最多30輪，保留原早停。D_L=L_ref(移除最終解)−L_ref(完整最終解)。不改為移除後錨點均值起點。

L_ref固定為原完整團隊的均勻模型絕對誤差平均，與既有 S3/S4 同口徑。正值表示移除後較差。評分面板僅在分支解固定後比較，不回流移除決策。所有分數保留正負；不翻號、裁切、調權重或加步長權重。分數缺失不作零。

## 4. 指標與事前篩選

epsilon=1e-4，僅供分類與可計算性。先每隊計算，再情境團隊等權；不把同隊5起點、10起點對或參與者當獨立樣本。情境各10隊，bootstrap10000次，seed20261027，95%探索區間。兩情境同seed重抽時可配對，但不宣稱多重檢定正式確認。

主要指標：各方法每隊10個起點對的跨人 Spearman 平均；任一向量跨度<=epsilon或人數<3則該對不可排名。另列有效對比例。每人10對的正負翻轉率，分母為兩端皆明確非零者；另報至少一端非零時的三分類改變率、全近零比例，避免把消失漏掉。報每人跨起點 max−min、平均絕對分數尺度及其比值，分母接近零則缺失。

跨起點穩定研究門檻：每情境>=8隊可排名，平均有效排名對比例>=80%；平均rho>=0.8且95%下界>0.5；有翻轉分母的團隊>=8，明確非零人×起點對>=20；平均翻轉率<=10%且95%上界<20%。兩情境均通過才稱「本範圍跨起點穩定」。此門檻是本輪研究篩選，不是通用經濟公理。

次要：每起點J對D_L的rho、以非零D_L為分母的符號一致率（預測近零算未命中）、NMAE=sum|J−D_L|/sum|D_L|，先隊內跨起點平均。替代篩選沿用rho>=.8且下界>.5、符號>=.85且下界>.7、NMAE<=.25且上界<.5，每指標>=8隊有效；成本需兩情境總評分比<=.7。不得按最佳起點挑成功。

## 5. 成本與量測

每個方法、每隊、每起點都獨立執行完整 baseline；baseline不快取省略原請求。之後只精確重用該次 baseline 與該方法自己的 float64模型/輸入回覆，補查 L_ref 計費。不同起點、方法、重複不得互相免費快取。主要成本=baseline+分支+共同評分模型推論次數，另報baseline與新增。

每格執行1次記錄／暖機與3次量測；按團隊／起點／重複輪換J、LOO順序。rep0保留全部原始回覆、查詢帳、分支狀態與分數，並獨立量測 tracemalloc Python峰值；rep1–3不開tracemalloc，用同樣記錄流程量時間，要求結果與查詢次數相同。時間含baseline、狀態擷取（J）及分支計算／共同評分，不含模型載入、JSON落盤與 pooled。Python峰值不含PyTorch原生配置，不宣稱總記憶體。process RSS另列，不能按方法比較。固定單執行緒CPU；不外推API延遲。團隊人數固定3/5且情境混雜，不作人數擴展律結論。

## 6. 技術驗收與資源停止

執行前固定模型、設計、原solver、engine、資料與新程式hash。先跑合成測試與2隊×5起點pilot，獨立核對通過才開發20隊×5起點。

獨立驗證：重新載入保存的全部唯一模型回覆；以原未插樁solver重播baseline與完整LOO（核對查詢順序及完整回傳）；以既有獨立手寫解譯器逐輪重建J分支，不匯入新計分實作；核對分數、每筆快取帳、s0既有S3/S4分數及成本。容許絕對/相對數值差1e-10，原始回覆須完全一致。手算tie-rank／分類及聚合另核對。任一技術差異即停止，保留失敗，不事後改計分規約。

pilot+開發+所有時間重複推論總上限250萬次、模型回覆獨立重評100萬次、pooled含獨立重評3萬次；總牆鐘上限1200秒，各主階段600秒，輸出上限1GB。每次推論前與每案例檢查；超限停止，不補跑其他seed。4rep屬研究成本，不乘進單次部署成本。

## 7. pooled 與結果封存

內部分數與端點鎖定、技術驗收後，才載入凍結 pooled evaluator。評全部J原／移除端點及完整LOO／baseline端點，按模型／精確座標去重，獨立重載重評。J_E定義為同樣原端點對的 pooled差之和，D_E為完整移除最終差。只檢查J對J_E、D_L對D_E及J對D_E，不用 pooled選起點、改搜尋或決策。truth不載入。
