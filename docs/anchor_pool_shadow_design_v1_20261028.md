# 錨點池：有號累積與影子獎金驗證規約 v1

日期：2026-10-28。本文件於本輪執行前固定。授權：使用者要求依錨點池新設計驗證。模型池與基本保障算法不變，無實際付款。

## 1. 付款理由及限制

研究契約只獎勵固定團隊內部目標下、原路徑上的當輪錨點方向作用。C^A=排除該owner方向分量的接受端點loss−完整接受端點loss；保留所有評分模型，其他方向權重不重分配。不是完整LOO、最終品質、可加總社會剩餘或公平性證明。A與B不作成果獎金輸入。基本保障另按T1履約，不用負C扣費。

## 2. 凍結的影子分配候選

同一任務固定owner名冊、應計輪次、共同尺版本、數值單位和准入資格。本輪假設名冊中皆具錨點成果資格，不由C反推履約。按(owner,round)唯一槽位收件；完全相同內容可重播／換event_id，衝突值拒絕；非法owner、非有限數、缺少或未定義任一槽位皆不得產生該池個人金額。

S_i=Σ_t C_i,t，另保留正向總和、負向總和、覆蓋率。只在owner累積後套死區epsilon=1e−8；不可逐輪去負值或取正部。主候選w_i=max(S_i,0)，但|S_i|≤epsilon視為0。兩個對照為固定名冊等額，以及逐輪正部累加。三者均受相同資料完整性限制。

研究用池預算500整數單位，無貨幣意義。發放條件：所有槽位可定義，且主候選Σw_i≥0.001；否則保留全池。0.001是用來測試規則的事前固定參數，沒有品質、價格或最適性依據。觸發後釋出500，未觸發0；此硬門檻的跳躍另列限制，不能稱合理價格已建立。等額／逐輪正部對照沿用主候選同一釋出gate，避免混入不同發放金額。按精確有理數比例與最大餘數法取整；餘數同分按固定owner字典順序，不依事件順序或臨時身份。同owner先聚合，不能拆子身分取正部。

全零／全負不發成果獎金；缺資料或未定義時個人金額null，狀態held；已完整且低於gate時個人金額0，狀態reserved。不將held稱為無貢獻。不跨任務比較或分配，不混入模型分數。

## 4. 獨立驗證、成本與停止

生產累積器用Decimal；獨立reference不匯入engine，用Fraction從原槽位重建。所有可結算案例故意改金額、淨值、狀態應被發現。解析分支由獨立60位Decimal幾何／多項式／原接受規則核對；同owner拆分先聚合方向，不能將兩個消融取正部相加。

技術硬gate：所有預期、重播／重排／零輪／同槽拆分不變性、完整性、非負及預算守恆、獨立重建100%通過。任一失敗保留failure並停止升級，不刪案例。已定義負值仍可拒絕成果獎金，但不取消T1基本費。

經濟gate另列：不要求ΣC=總改善；若有重疊，只能稱角色邊際作用的規範性分配。實際改變錨點資源、權重、新owner或路徑不屬等價變換，不可默認抗操弄。沒有部署裁判或外部品質證據時，不升級成品質獎金；低成本／新真實任務／Sybil／串通／完整多輪操弄仍未建立。
