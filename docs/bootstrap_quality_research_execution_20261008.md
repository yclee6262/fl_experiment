# 重抽樣品質初始化：機制驗證與獨立比較

這是 2026-10-08 新一輪的研究規格。舊的 30-seed 結果提供研究動機，不作新版正式結果。A、B、簡單收縮與重抽樣均只做一次 Stage 3，固定原本的加權絕對誤差目標、box、best_of 與 Custom 30 iterations。沒有 α 更新、剪枝或結算。

## 方法與問題

- A：每人 1/3，檢查估計非均勻權重是否值得。
- B：將 1/(盲測 MSE+1e-5) 正規化，檢查重抽樣是否勝過直接品質權重。
- 簡單收縮：0.5×A+0.5×B；比例事前固定，不用正式 pooled 分數挑比例。
- 重抽樣：每次共同有放回抽 n 個盲測行，依 B 公式得到一組正規化權重，1,000 組權重平均。各 agent 使用同一組行索引，保留共同難度與誤差相關性。沒有重新訓練模型，沒有 1,000 次倒推。

需要分開回答：不同盲測資料下 α 是否穩定、單一資料內 Monte Carlo 是否穩定、最終 X 是否較好、改善是否超過簡單收縮、成本是否值得。沒有任何一項可由另一項直接推論。

## 探索設計

重用舊版 4100–4109 的凍結模型、固定 IDs [1,2,20] 與 pooled artifacts；這些 seeds 只作探索。每 seed 產生 10 組獨立 Uniform([-1,1]^2) 的校準資料，使用與 Stage 0 相同的合成精確標準答案。校準資料獨立生成，不取 pooled 訓練、驗證或測試資料。這個合成標記來源不代表真實部署可以免費取得答案。

每組資料取前 10、20、50、100 筆作巢狀比較，target 為 -0.5、0、0.5，共 14,400 個方法條件。固定已合格 coalition，不因新的盲測資料重新篩選參與者。因此研究的是初始化對校準資料的敏感度，不是完整資格篩選流程。

同一 seed、target 共用 proposal，同一 seed、draw、n 的各方法共用資料與逐筆預測。外部 evaluator 只在交付後評分。模型預測批次預計算在離線整批共享；不能將只算一次的 100 筆成本說成所有方法各自需要 100 筆。獨立執行成本依 n 分別列出。

每 seed 彙整其 10 次盲測；seed 才是統計單位，不把 100 次盲測當成 100 個獨立訓練情境。報告 α 分量變異數之和、X 分量變異數之和、pooled 誤差變異與每 seed 的第 90 百分位誤差。A 的 α 固定是預期現象，仍需看 X 與品質。

在 n=20、target=0 上，以 100／500／1,000 次重抽樣，分別與五個獨立 10,000 次結果的平均權重比較。這衡量有限重抽樣次數的數值誤差，不是最終 X 品質信賴區間。

## 預測重用與成本

新增可選的資格測試預測重用，舊入口預設仍重新呼叫 API。重用條件是相同模型版本、agent 順序、盲測行與標記；重載驗證核對模型及資料。實際用同一 α RNG 比較重新查詢與重用版本的 α、X、Stage 3 呼叫數，要求一致。沒有 Stage 3 prediction cache。

初始化時間使用完整 wall time，包含本地重抽樣運算；既有 StageCounter 亦採階段 wall time；新版另外明確保存初始化計算區間，並非 API 服務端耗時。另記 Stage 3 wall time、API calls、input samples、proposal 成本、原始訓練／資格成本。pooled scoring 不計入部署成本。

對額外校準資料的探索，A 不需要這些資料來算 α；B、收縮與重抽樣需要 n 個標記與 3n 個模型輸入。原本的資格檢查成本仍獨立保留，不能用這個 α 資料成本取代或重複相加原有資格檢查。正式原 20 筆重用路徑沒有新增標記，逐筆預測是已發生資格成本的重用，分析時不得再收一次完整資格費用。

## 新正式比較

先在探索用的 10 個 seeds 上，以原 Stage 0 20 筆、target=0、四種方法取得配對差值標準差。正式樣本數規則已在探索前登錄：使用最大的配對 SD，以 Bonferroni 九比較、名目 80% power、研究數值解析度 Δ=0.005 的常態近似規劃；至少 30、最多 120 seeds。0.005 是合成 benchmark 的研究解析度，不是經應用驗證的成功、等效或非劣門檻。若樣本數受上限限制，明確揭露不足，不能宣稱 power 已達標。pilot SD 也有估計不確定性。

正式 seeds 預留 4200–4319，啟動前再次確認未使用；N 與版本在正式開始前固定。不依正式結果增加／提早停止／挑參數。

主要確認比較是三情境、target 0、原 20 筆盲測下的重抽樣對 A／B／收縮，共九項。報告 10,000 次 seed 配對 bootstrap 的普通 95% CI 及 Bonferroni 同時 95% 區間（每項 99.4444%）。穩定品質優勢要求校正區間完全小於零、完整有效配對且觀察失敗率不較高。其他 targets 的新版獨立結果仍作探索性分析，不擴大確認主張。

## 可重評與驗收

完整識別鍵為 scenario、seed、draw、blind_n、target、method。每條件落盤，數值求解失敗保留狀態與成本；程式錯誤記 interrupted 並停止，不能當求解失敗。保存 X、α、MSE、逐筆校準資料與預測、solver traces、共享 proposal 與成本、evaluator coverage。

核對所有預期鍵、來源快照／模型／資料／結果雜湊；重產生校準資料、重載模型的逐筆預測與 α、重評 pooled／truth。成功解必須實際 box 可行，容差 1e-8；模型／α／分數重載容差 1e-7。負面、失敗及 pooled/truth 方向衝突全部保留。

新版正式另完整重播一個 seed，包括資料、模型訓練及 proposal，要求離散決策一致、X／α／分數差不超過 1e-7；時間不要求一致。正式結果若仍未建立優勢，保留 A／B，研究仍可完成交付。
