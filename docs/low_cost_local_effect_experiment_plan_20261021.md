# 低成本方法能否還原單輪作用：完整實驗規劃 v1

日期：2026-10-21。**本次僅完成來源核對與實驗規劃；未新增算法實作、未執行實驗。** 使用者確認設計後才進入實作。本文是探索規約草案，不是老師已核可或新的有效性結果。

## 1. 決策摘要

本輪只問：在原 custom 同一輪的狀態下，能否用較少額外模型評分，還原精確單輪 LOO 的內部 loss 差？

固定兩條方法，不建立大規模候選庫、不以歷史 LOO 訓練模型：

1. **N0：既有試走序列重評。** 零新增模型查詢；保留原輪實際試走的位置與順序，代數移除模型評分，再查該面板會接受哪個既有點。只估模型 m，優先回答使用者希望的「原搜尋中直接統計」是否足夠。
2. **N1：每個角色只試一次。** 重用原方向評分資料，以代數重建角色移除後的方向，每個角色最多額外評一個位置；完整與移除兩邊都截為一次試走。分別估 a2、m、j。這是低查詢的局部 LOO 近似，**不是零查詢統計，也不是完全不用 LOO**。

N0 是優先研究線；N1 是事先固定的少量新查詢比較線，無論 N0 好壞都依同一規約報告，不能事後稱為純觀察法。只接受零新增查詢的部署情境，即使 N1 通過也不能採用 N1。

本輪不將任何分數轉為分潤，不調 alpha，不進行 pruning、Shapley、模型重訓或大型新資料實驗；不修改原 solver、舊錨點算法與歷史結果。pooled 與 truth 均不載入。本輪無須再驗證外部品質，避免把「近似準確」和「品質有效」混為一談。

## 2. 已有證據及本輪新增問題

- 第一層原 A+M 未建立合併增益；污染情境合併相對 M 的排名差 −0.37，98.75% 區間 [−0.71,−0.05]。
- 第二層統一決策規則後，可加性仍未通過；c2 與 j 的標準化殘差為乾淨 22.5%、污染 20.1%。因此不能把錨點與模型近似分數相加冒充 j。
- 精確累積 J 對完整參與者 LOO 的外部排名為乾淨 0.55、污染約 0，整體驗收未通過。因此本輪即使成功，最多建立「單輪內部作用的低成本近似」。
- 先前方向分帳、共享插值／回歸代理已有研究。N0 直接重用本輪已評位置；N1 直接取得新位置的真實模型回覆，不擬合歷史資料或替身函數。以前的負面與正面結果均維持，不改名當本輪成果。

本輪四個固定估計組合：N0→m、N1→a2、N1→m、N1→j。不得事後增加平均、加權、翻號、半步或多試幾次等版本挑最好結果。

## 3. 精確驗證對象

原完整團隊共同尺：

\[
\ell_k(x)=|f_k(x)-T|,\qquad L_{ref}(x)=\sum_k\alpha_k\ell_k(x).
\]

本批 T=0。方向權重 a 與評分權重 alpha 分開；原實驗 a=alpha 不代表角色干預時兩者應一起改。

每輪從原完整團隊輪前狀態出發，精確標準依既有原 solver 執行一次外層迭代，最多十次縮步，可接受、不更新、切換或停止。取輪末目前位置，不取拒絕試走點或歷史最佳位置。四分支如下：

| 分支 | 錨點與方向權重 | 模型與評分權重 |
|---|---|---|
| F | 原全部 | 原全部 |
| A2 | 去錨點 i，剩餘方向權重正規化 | 保留全部 |
| M | 保留全部與原方向權重 | 去模型 i，剩餘 alpha 正規化 |
| J | 去錨點 i，剩餘方向權重正規化 | 去模型 i，剩餘 alpha 正規化 |

對 r∈{A2,M,J}，精確標籤為

\[
c^r_{i,t}=L_{ref}(x^{r}_{i,t+1})-L_{ref}(x^F_{t+1}),
\]

分別對應既有 a2、m、j。每輪排除分支不延續原路徑。a2 是第二層版本；第一部分舊等距、僅接受步的錨點 A 不作本輪標準，也不被新方法替換。

主比較是逐輪、跨參與者、相同角色的近似對精確差。累積和僅列次要描述，不新增全程 LOO／pooled 比較，不藉累積抵銷掩蓋逐輪錯誤。

## 4. 可用資料與嚴格資訊隔離

部署型估計器只可讀：原團隊模型身份／hash、權重、錨點、輪前位置與模式／eta／delta、原搜尋已取得的逐模型回覆，以及當輪正常搜尋實際試走的順序與結果。N1 另可呼叫其預先決定的單一新點。

每輪計分時間是原完整輪結束後；可用資料截至該輪結束，不可讀後續原輪回覆，不能把全軌跡快取當成當下已知。先前原輪的同模型同輸入回覆可重用。

需新增被動記錄器的話，只能記錄原本已呼叫的回覆；查詢數量、順序、solver 算術與主路徑均不變。從歷史混合檔抽資料，必須按來源事件／時間白名單建立乾淨 baseline-only 視圖。若無法證明某回覆來自正常搜尋，禁止送進估計器；改以凍結 baseline 重放取得，另外計研究成本。

分離三個介面／檔案區：

1. estimator_input：僅正常搜尋已知資料；不帶精確反事實端點、接受次數、oracle 分數。
2. estimator_output：近似分數、狀態、允許的新位置及成本，先鎖定 hash。
3. oracle_labels：第二層精確分支，只由分析與獨立 verifier 在近似鎖定後讀取。

已有人看過舊標籤，因此資訊隔離不使舊資料變獨立確認；它只防止實作直接偷讀標準答案。N0／N1 不可依照 oracle 成功縮步次數或最終端點挑候選。用過去分支回覆免實際重查時，仍須先由估計器獨立提出查詢，並在部署成本帳記成其應付的新查詢，不可假裝正常搜尋已知。

## 5. N0：零新增查詢的既有試走序列重評

### 5.1 固定算法

原輪實際嘗試點依順序記為 z1,…,zK，K≤10；原搜尋一接受便停止，所以沒有觀測的後續試步不能虛構。原輪零方向而無試步時 K=0。

對每個模型 i：

\[
L_{-i}(z)=\frac{L_{ref}(z)-\alpha_i\ell_i(z)}{1-\alpha_i}.
\]

1. 只對已有完整逐模型回覆的 x_t 與各 z 重組 L_minus_i。
2. 依原試走順序，選第一個嚴格滿足 L_minus_i(z)<L_minus_i(x_t) 的點；不是挑 loss 最小者。
3. 若全部不通過或 K=0，代理端點為 x_t。
4. 計算 m_hat_N0=L_ref(代理端點)−L_ref(原完整輪末端點)。完整共同尺值均已存在，新增模型 calls／samples 必須為 0。

這裡沒有重算移除後方向，也沒有新影子 solver；只是矩陣加減與順序篩選，約 O(nK) 算術／輪。n 是模型數。

### 5.2 可回答與不能回答的事

N0 可捕捉在原已試方向上，模型評分如何改變接受門檻與已觀測縮步選擇。但移除模型可能改變方向，或需要原軌跡未嘗試的位置；N0 無法知道那些位置的品質。它對 m 的還原能力是待驗證假說，不是等式。

只移除錨點不改評分面板，N0 沿相同原試走序列必然仍選同一點。因此不宣稱 N0 能估 a2，也不以 m_hat_N0 充當 j。原零方向輪 N0 預測 0，但精確移除後可能有非零方向；這是可檢驗的盲點，不把此類輪排除以美化結果。

例：共同 loss 在原位為 0.50，原試點 z1=0.55 被拒、z2=0.40 被接受。某移除模型面板在原位／z1／z2 的 loss 為 0.45／0.42／0.38，N0 選 z1，故 m_hat=0.55−0.40=+0.15。這只描述沿原位置序列的決策變化，精確 m 仍需允許排除後換方向。

## 6. N1：代數重建方向，每個角色最多一個真實試點

### 6.1 重用原方向評分矩陣

對錨點 k，u_k=(I_k−x_t)/||I_k−x_t||。secant 用原錨點回覆，dynamic 用原程式實際的有界探測 z_k=x_t+h_k u_k：

\[
b_{lk}=\frac{\ell_l(z_k)-\ell_l(x_t)}{h_k},
\]

secant 時 z_k=I_k、h_k=||I_k−x_t||。沿用原候選距離<1e-8、dynamic 有界距離≤1e-12 的跳過規則，不補不曾查詢的位置。這些 b 是原算法方向斜率分量，不宣稱是真梯度。

令 B_k=Σ_l alpha_l b_lk。三角色方向可由同一矩陣直接算：

\[
g^{-A_i}=\sum_{k\ne i}\frac{a_k}{1-a_i}B_k u_k,
\]
\[
g^{-M_i}=\sum_k a_k\left(\sum_{l\ne i}\frac{\alpha_l}{1-\alpha_i}b_{lk}\right)u_k,
\]
\[
g^{-J_i}=\sum_{k\ne i}\frac{a_k}{1-a_i}\left(\sum_{l\ne i}\frac{\alpha_l}{1-\alpha_i}b_{lk}\right)u_k.
\]

不以 a2_hat+m_hat 估 j。模型 i 對所有錨點的評分都在模型列中，錨點 i 則是方向欄。可用列／欄總和減法優化，但須用獨立直接雙迴圈核對，避免抵銷誤差。

由原 solver 可知：當輪 x、模式、delta、幾何相同，初始方向探測位置不依評分面板改變，故完整 baseline 的逐模型探測回覆足以重建三種移除的初始方向。這只適用本次凍結 custom 實作，不外推自適應探測位置的其他 solver。

### 6.2 一次試走與對稱截斷

各分支 r 只使用原輪前 eta_t 的第一次試走：

\[
z^r_i=x_t-\operatorname{bounded\_step}(x_t,-g^r_i/||g^r_i||,\eta_t)\,g^r_i/||g^r_i||.
\]

方向範數≤1e-8 時留原位。禁止用 oracle 的縮步次數或原完整輪最後接受距離挑新點。

對每個有效 z 最多取得全模型回覆一次，A2 依完整面板判斷接受，M／J 僅依移除後面板判斷接受；被排除模型的回覆只用於共同尺，不能影響接受。嚴格改善才接受，否則留 x_t。不再嘗試 eta/2、不轉模式重求、不續跑後續輪。

**完整分支也截為同樣的一次試走**：從原正常搜尋第一次試走與回覆可取得 x_F1，若原第一試拒絕則 x_F1=x_t；沒有試走也為 x_t。定義

\[
\widehat c^r_{i,t}=L_{ref}(x^{r,1}_{i,t+1})-L_{ref}(x^{F,1}_{t+1}).
\]

不能只截斷排除分支卻以完整十次版作另一端，否則單是較少求解機會就會產生偏分。N1 是以「對稱的一次試走差」近似「原完整當輪差」，不是改寫精確標準。

當完整與移除兩邊都在第一次接受時，兩者應與精確標準一致到技術容差。若任一需要後續縮步，便可能出現誤差；兩邊第一試都拒絕時預測 0，即使精確標準非零。這些情形完整納入驗收，不能只報第一試成功群。

誤差可在鎖定後精確分解為「移除分支截斷造成的共同 loss 差」減去「完整分支截斷造成的共同 loss 差」。此分解只作診斷，不拿來事後補正。

### 6.3 複雜度與方法性質

使用 n×K 斜率矩陣，可共享重建約 O(nKd) 的方向資訊；每個角色至多 n 個新位置、每點 n 個模型，新增最多 n² 個模型 input samples／輪；三角色同算最多 3n²。位置重複可精確快取，但成本必須同時報各角色單獨使用及整套共享使用。

沒有擬合回歸或插值，沒有推測新位置的 loss；新位置使用真實模型。它仍對每人做角色排除運算與試點，不能包裝為老師要求的嚴格非 LOO 方法。

## 8. 固定指標與驗收

### 8.1 技術硬門檻

- 原 baseline 有／無記錄版的所有 API 輸入、順序、數量與接受／模式／停止狀態一致；位置與 loss 不改。記錄器不能改加總順序或回寫重建方向。
- N0 實際新增模型 calls／samples 必須為 0；缺少正常來源回覆視為技術失敗，不補查後仍稱零查詢。
- N1 每角色每人每輪最多一個額外候選位置；缺少原方向資訊不能默默補探測。證實沒有額外完整求解、替身擬合、oracle／pooled／truth 輸入。
- 雙迴圈獨立方向重建及分數誤差≤1e-10×max(1,|參考|或向量範數)；不事後放寬容差。臨界接受／零方向因浮點順序翻轉，視為技術失敗，保留記錄。
- 角色無剩餘權重為未定義；非有限回覆、缺失、預算截斷不得填零。輸出完整缺失原因與 partial 累積。

### 8.2 主要效果指標

每情境、每方法—角色分別報，先團隊內統計再團隊等權，避免長軌跡支配。

1. **排名：**每輪跨參與者 Spearman，至少 3 人，精確與近似各自 range>1e-4；有效輪團隊內平均，再團隊平均。另報 oracle 非平坦但近似全平的比例，不能把它當無需排序。有效排名輪需占全部實際輪至少 50%，且占 oracle 可排名輪至少 80%。
2. **正負：**以 |精確分數|>1e-4 的角色輪為分母；近似同號且 |近似|>1e-4 才成功。近似零／缺失在此均算未還原，另列缺失；不能只在近似給出明確判斷的子集計成功率。正／負精確類的 recall 另列，防止只猜正分。
3. **數值誤差：**每團隊 NMAE=Σ|近似−精確|／Σ|精確|，分子分母皆涵蓋全部有效角色輪，含近零；分母≤(角色輪數×1e-4) 的團隊標記尺度不足，不拿微小分母相除。另報原單位 MAE、偏差、中位數與 p90 絕對誤差。NMAE 的零分預測恰為 1（尺度足夠時）。
4. **近零誤報：**精確 |c|≤1e-4 時，近似 |c_hat|>1e-4 的比例；避免在實際無明確作用時製造高分。

資料完整率以所有應有角色輪為分母，至少 95%；任何缺失仍列全帳。排名、符號及 NMAE 各至少 8/10 團隊可計，近零誤報至少 5/10 團隊有近零樣本才可作廣泛零分類主張。某符號類不足 3 團隊或 20 筆時，該方向辨識證據不足，不能宣稱完整 signed 還原。

排名以該輪所有原參與者皆有預測及標籤才可計；NMAE 與 MAE 的主團隊指標要求該團隊全部應有角色輪完整，避免刪除難例降低誤差。未完整團隊只列 partial 診斷，不進主平均，仍占覆蓋分母。覆蓋門檻與完整性同時適用，不能用缺失濾掉錯誤後宣稱通過。

### 8.3 預先固定的探索通過條件

每一方法—角色組合須在兩情境各自符合：

| 指標 | 門檻 |
|---|---|
| 平均排名相關 | ≥0.80，且區間下界>0.50 |
| 明確精確分數的符號一致率 | ≥85%，且區間下界>70% |
| 精確正／負分各自 recall | 各≥75%，並符合各類最小樣本數 |
| 團隊平均 NMAE | ≤0.25，且區間上界<0.50 |
| 精確近零時的誤報 | ≤10%；若近零資料不足，零分類能力標未建立 |
| 覆蓋、技術與成本 | 全部通過 |

這些是本提案事前選定的工程接受標準，不是老師指定、統計定理或已有結果。主比較為 4 組×2 情境×3 指標（排名／符號／NMAE）=24 項。統一按 seed 群組 bootstrap 10,000 次、固定 RNG 20261021，採 99.8% 百分位探索區間；同 seed 兩情境使用同一重抽索引，不把個人或輪次當獨立樣本。缺失造成可計團隊不足則標不通過，不用少量有效樣本區間取代覆蓋驗收。

N0 與 N1 在 m 的團隊配對差及 NMAE 改善完整報告，屬次要比較；不因多看指標而挑勝者。只通過排名時只能稱有排名資訊，不稱 signed 數值還原。只在一情境通過，不稱跨情境方法通過。

獨立確認若啟動，維持同門檻、同區間水準與公式；團隊覆蓋要求由 8/10 改為 16/20，其他比例不變。不以重新選最佳候選取代失敗。

## 9. 成本測量與資源上限

### 9.1 必須分開的成本帳

baseline、N0 算術／記錄、N1 各角色新增查詢、整套共享查詢、精確 oracle 參考、baseline 研究重放、獨立驗證、統計與寫檔，各自列 calls、input samples、unique points、快取命中、時間與儲存。部署型成本不含 oracle 與獨立重查；研究總帳包含所有實付項。

歷史第二層曾從前版分支快取起跑，不能直接把其「新增 0／新增 30,137」當各角色成本。須以 baseline-only 快取及固定 (輪次, agent_id,角色) 順序重建 standalone 精確參考成本；無未來回覆、無其他角色免費回覆。已保存原始輸入可用來核對成本，不必重新求解。總成本同時報 baseline+方法與純新增比較成本，避免 baseline 掩蓋開銷。

### 9.2 部署型成本通過條件

- N0：零新增模型 calls／samples；四 pilot 的配對計時中，記錄＋N0 計算中位耗時增量≤baseline 10%。
- N1 各角色：新增 input samples≤同角色精確單輪 LOO 新增樣本的 30%；baseline＋N1 總 samples≤baseline＋該角色精確 LOO 的 70%。兩情境分開驗收。精確比較新增成本為零時不計比值，也不宣稱節省。
- N1 記錄與計分的非模型運算／寫檔中位增量≤baseline 耗時的 20%；總端到端耗時須另實測並列。時間未省則只能說查詢成本下降，不稱全面加速。
- 計時固定 4 pilot，每案 2 組 warmup、10 組交替配對 baseline／N0／N1整套；模型載入後測、每輪清空各方法額外快取、禁止 warmup 回覆免費沿用。另列初始化、載入與持久化時間。本機小網路不代表遠端 API 成本。

### 9.3 本次探索的硬上限

- N0 估計新增模型樣本：0。
- N1 pilot：最多 20,000 新樣本、180 秒。
- N1 開發：最多 40,000 新樣本、600 秒。
- baseline 記錄重放與獨立原回覆重查：最多 100,000 新樣本、600 秒。
- 獨立 N1 端點模型重查：最多 60,000 新樣本、900 秒。
- pilot 配對計時：最多 400,000 新樣本、600 秒。
- 合計模型樣本硬上限 620,000；上述階段牆鐘合計上限 2,880 秒；單獨統計／分析最多 300 秒；輸出最多 2 GB。pooled=0、truth=0、模型訓練=0、完整全程移除求解=0。

若所需記錄全可來源核對，就不重放模型，仍記模型查詢的部署應付成本。N1 開發在已知輪數下未扣快取的上界為 3×(111×3²+140×5²)=13,497 模型樣本；按每案最多30輪保守上界為30,600。這是三角色各一次候選全面板的上界，不是實測或效果保證，不含研究重放與驗證。

pilot 若推估固定計時或開發無法在上限完成，先停止並報預算不足，不刪慢案例、不增加預算或看效果後調門檻。成本與效果都要通過，便宜但還原不了不算成功。

## 10. 必要的技術測試與機制診斷

合成測試至少涵蓋：

1. 方向列／欄分離：移除模型影響所有錨點斜率；移除錨點不移除其模型。
2. 不同 alpha 與 a 的可手算案例；零權重與剩餘權重為零的定義邊界。
3. N0 第一個接受點而非最低 loss；完整提早接受使後續點不可用；原零方向無試步。
4. N1 第一試即成功時與精確標籤相同；第一試拒絕、第二試成功時必須容許有近似誤差，不能拿 oracle 補答案。
5. 對稱截斷：兩邊政策相同且實際作用為零時不因只截一邊產生假貢獻。
6. 方向抵銷、盒邊界零步、secant 切 dynamic、dynamic 停止；取目前位置、缺失不填零。
7. 一步內非加性案例：直接重建 joint，不使用錨點＋模型分數代替。
8. 惡意輸入測試：混入未來輪、oracle 分支回覆、pooled 檔案必須被來源／介面檢查拒絕。

效果鎖定後才按 oracle 分層：同／異方向（角差≤1度記近似同向）、第一試成功／後續縮步／完全拒絕、原完整是否更新、secant／dynamic、邊界受限。每層至少3團隊與20筆才討論趨勢，仍屬描述，不以好看的層取代全輪主結果。

預定代表案例各方法—角色、各情境各取：最大絕對誤差、最大明確反號誤差、精確負分漏判、精確近零誤報；平手依 seed、輪次、agent_id 排序。不存在該類則寫無，不另換選例規則。N0 特別列方向改變造成的遺漏；N1 特別列縮步截斷的差。

## 11. 獨立驗證、保存與停止決策

獨立 verifier 不匯入新估計函式，從白名單正常回覆直接雙迴圈重建方向及接受邏輯，重算所有預測。精確標籤先核對第二層來源 hash／completion receipt／verification，不重寫歷史檔；另由凍結原控制流程及保存回覆核對所用標籤與對照身份。

N1 新端點以凍結模型重新查詢所有唯一點，核對 raw replies／dtype；統計用另一個明確 rank 與團隊彙整實作重建。baseline-only 時序成本由獨立快取模擬核對。技術不過先停，不進效果選擇；修復需留版本與原因，不能看效果改設計。

| 結果 | 允許結論與下一步 |
|---|---|
| N0 對 m 通過全部條件 | 零新增查詢在此舊資料可近似單輪 m；可提案獨立確認，不外推 a2／j |
| N0 失敗、N1 某角色通過 | 該角色可能需少量額外試點；仍屬局部 LOO 近似，不宣稱純統計成功 |
| 某方法只排名通過 | 只保留排名探索訊號；signed 數值還原未建立 |
| 效果過、成本不過 | 近似可用性未達低成本目標 |
| 技術過、全部效果失敗 | 保留負面結果，停止該固定設計；不改成兩／三次試走追通過 |
| 任一來源／隔離／完整性失敗 | 技術未驗收；不得對效果下正式結論 |

不自動啟動新確認、增加 seed、變步長、翻號、校準分數或乘品質權重。若要研究多次試走或其他方法，另立新假說、版本及授權。原 m／j 外部效度與累積對完整 LOO 的失敗，不因本輪近似通過而撤銷。
