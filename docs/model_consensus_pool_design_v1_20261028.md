## 1. 研究目標及不可超越的限制

上一輪30案的raw C、換算C、peer均只符合18/30；相同模型可觀測資料而相反診斷答案，證明僅換聚合式不能保證真實品質。此新候選只主張「各評價owner都支持的當輪局部改善下限」，不稱獨立品質、可靠模型識別、公平或已可部署付款。分歧採保守處理會漏掉正確少數，也可能被錯誤／惡意評價者否決；共識錯誤仍可能發獎。這些是必測限制，不是已修復問題。

不改原求解；保留每owner模型-only當輪消融。full與minus都從同一原輪狀態出發，保留全部錨點及其a、模式、初始步長和接受規則；minus排除該owner全部模型、剩餘v正規化。比較接受端點而非最後拒絕候選。所有模型只在端點確定後參與共同離線評分。原objective的尺度敏感仍可能影響端點，本方案不宣稱整條搜尋尺度不變。

## 2. 計分輸入與公式

任務先鎖owner名冊、模型ID與owner歸屬、原v、共同probe、模型版本、預期應計輪次、數值門檻及固定池預算B。owner必須唯一並具正原模型總權重；零權重owner或只剩單一正權重owner時不具可比較的model-only反事實，整池held，不默默刪名單。版本鎖是資料一致性條件，不冒稱身分認證。

每模型m的loss非負且有限。固定probe量出s_m=Q90(loss_m)−Q10(loss_m)，線性分位數；正v模型s_m<=1e−12則整池held。零權重模型保留紀錄但不參與評分。probe至少2點且各模型同數量，未提供或不完整拒絕／held。正式部署須先於搜尋鎖定；舊資料後校準只能標作探索分析。

針對受評owner i、原輪t及評價模型m：

d_mit = [loss_m(x_minus_i_t)−loss_m(x_full_t)] / s_m。

先按原v在每個評價owner k內正規化聚合，避免一個owner僅複製模型就增加評價票數：

z_kit = Σ_{m屬於k} v_m d_mit / Σ_{m屬於k}v_m。

所有評價owner（含受評者）固定共同一套；每個i不另選有利評價者。

l_it=min_k z_kit；u_it=max_k z_kit。

區間[l_it,u_it]是任意非負、總和1的owner評價混合所能得到的範圍，不是統計信賴區間、真實品質界或概率。

分類以固定deadzone=1e−10：l>deadzone為一致正向；u<−deadzone為一致負向；l>=−deadzone且u<=deadzone為近零；其餘為分歧／不確定。另存原v加權換算C、own與others及peer，只作診斷，不能在看到結果後替換主候選。

## 3. 跨輪及分配

保守累積S_i=Σ_t l_it；上界累積U_i=Σ_t u_it；對照中心累積也保存。此Σmin是允許每輪評價混合改變的更保守下限，不等於min_k Σ_t z_kit。保留有號累積，不能逐輪負值歸零後加總。

tau_i=max(1e−8, n_i*1e−10)只是固定工程deadzone，尚未建立硬體／模型誤差涵蓋。w_i=S_i若S_i>tau_i，否則0。當Σw>0，q_i=w_i/Σw_i，影子金額按B*q_i以最大餘數法取整，餘數同分按owner字典序。B為非負整數研究單位，禁止bool／小數／負數。預設500為測試值，不是建議價格。B=0仍可回報q，但所有金額0。

沒有可靠正累積：status=reserved，q=null，各金額0，reserve=B。任一預期(owner,round)缺漏、重複、端點未定義、版本／manifest hash不符、非法loss或owner映射不完整：status=held，q與金額null，reserve=B，列出原因，不把未知算0。預期輪次必須非空且唯一，不從收到的紀錄反推分母。不支援部分結算。基本保障及錨點池不受影響。

同一輪所有i必須共用相同full端點與full loss；slot含full/minus端點ID與loss向量、manifest hash及模型版本，對應數量／finite要核對。缺actual minus時未定義，不能用full補值。JSON輸入不執行外部程式，實作不處理真實付款。
