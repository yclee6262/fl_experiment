# 四種單次 α 初始化：實驗結果

日期：2026-10-08。以下結果僅適用於本輪合成二維、target 0、固定三人與原 Stage 3 目標；pooled evaluator 是主要品質標準。

## 完整性與驗收

- Pilot：seeds 0–4，60/60 條件，驗收：通過。
- 正式：seeds 4100–4129，360/360 條件，驗收：通過。
- 正式有效交付：360/360；來源與 artifacts 雜湊、可行性、pooled 重載及 α 重算均由驗收程式檢查。
- 重算 α 最大差：0.0。任何失敗保留在完整條件集合內，不以刪除失敗方式改善平均。
- seed 4100 乾淨情境完整重播：重新產生資料、模型、proposal 與四方法解，資料切分、模型參數、離散決策均一致，α／X／評分最大差 0；完整證據在 replay_verification.json。
- 程式回歸檢查：74 項測試通過，包含權重對齊、數值穩定、缺漏、重複條件、非有限分數、空 X、失敗成本保存與既有資料流。

## 實驗目的與具體方法

目的：在同一資料、模型、proposal、限制與 solver 下，檢查兩種新權重是否改善交付 X；同時確認新增計算是否值得。每種方法只執行一次 Stage 3 流程；best_of 內部仍比較兩條 solver 路徑，兩者成本全部計入，最後交付一個解。

| 方法 | 怎麼計算 | 需要的資訊／新增成本 |
|---|---|---|
| A | 每人 1/3 | 不需新增初始化預測 |
| B | α=norm(1/(MSE+1e-5)) | 重用資格測試已保存 MSE |
| 重抽樣品質 | 對原 20 筆共同有放回抽 20 筆；每次算 B；1,000 組 B 取平均。RNG=20261008+seed | 本版取得 3 次批次模型預測、共 60 輸入；不新增標記、不重訓、不做 1,000 次倒推 |
| 指數權重 | α=norm(exp(-(MSE-min(MSE))/τ))；τ=max(median(MSE),1e-5)；Uniform prior | 重用已保存 MSE；τ規則固定、不依 pooled 調參 |

例如 MSE=(0.01,0.04,0.09) 時，B 約=(0.735,0.184,0.082)，指數法τ=0.04，α約=(0.622,0.294,0.084)。重抽樣法必須看逐筆誤差，不能只由三個平均 MSE 推導。此例是教學數值。

## 情境與控制

- 所有情境固定 IDs [1,2,20]、2 維、target 0、box [-1,1]、可行性容差 1e-8、20 筆盲測、local models 30 epochs、pooled evaluator 100 epochs。
- 乾淨：三人各 500 樣本，標記 noise SD=0.05。
- 低品質：20 名訓練參與者中最後 5 名標記 noise SD=0.3；固定 coalition 中只有 ID20 受影響。外部評估維持乾淨資料設定。
- 不平衡：固定三人的樣本數為 229、247、917，最大/最小約 4；相同 epoch 下訓練步數亦隨樣本量不同。
- 四方法同 seed 共用全部資料、切分、models、proposal、evaluator。固定原 Stage 3 目標Σα_i|f_i(X)-target|、best_of、Custom 30 iterations；不更新α、不 pruning、不結算、不快取。
- pooled 在交付後評分，truth 只作診斷；未用外部分數挑輪次或調參。

## 欄位與 audit 字典

| 欄位 | 值代表什麼 |
|---|---|
| scenario / seed / method | 完整識別鍵；seed 共用資料與模型，method 只改初始化 |
| status / failure_stage / failure_reason | 執行狀態與失敗發生位置/原因；不是誤差分數 |
| delivery_status | valid 表示取得有限可行 X；none 表示沒有交付解 |
| final_solution / initial_alpha / agent_ids | 最終交付 X、固定初始權重、對齊的參與者順序 |
| stage0_mse | 每人原 20 筆盲測的平均平方預測誤差，順序同 agent_ids |
| final_box_feasible / max_box_violation | box 是否可行、超出上下界的最大距離；重新由 X 檢查 |
| actual_solver / solver_status | best_of 實際選擇的 solver 及數值停止訊息；有效交付不等同全域最優 |
| external_global_prediction / external_global_error | pooled 模型對 X 的預測及與 target 的絕對差 |
| final_target_error | 合成 truth 函數的目標絕對誤差，只作診斷 |
| initialization_requests / stage3_requests | 各階段的 local-model API 呼叫次數；批次一次也計一次 |
| initialization_input_samples / stage3_input_samples | 每次 API 實際輸入點數的累計；不能把批次 20 點說成只算 1 個輸入 |
| initialization_seconds / stage3_seconds | 本機各階段 wall time，包含權重計算/solver，而非只計模型 forward |
| external_scoring_seconds | pooled 事後評分時間，不混入 Stage3 |
| trusted_label_count / extra_trusted_labels | 原 20 筆標記／新增加可信標記數；本輪均 20/0 |
| artifact_path | 凍結 local models、pooled evaluator、資料與切分的相對路徑 |
| alpha_audit.fallback_reason | 權重計算是否退回基準及原因；空字串代表無 fallback |
| bootstrap_replicates / bootstrap_seed | 重抽樣次數與獨立 RNG 種子，不是倒推次數 |
| bootstrap_weight_std / q025 / q975 | 每人重抽樣權重的波動與分位數，不是最終 X 品質信賴區間 |
| recomputed_blind_mse | 從保存模型重算的原盲測 MSE，驗證與 B 使用同一資料 |
| temperature / temperature_ratio / prior | 指數法τ、比例 1、Uniform prior；不由 pooled 選擇 |
| pooled_delta / paired_n / excluded | 同 seed 方法誤差差值、有效配對數、未納入原因 |

## 判讀與後續

- 兩個新初始化法均未建立相對 B 的校正後穩定品質優勢；本輪不將它們替換為主要方法。保留 A 作一般基準、B 作低成本品質基準。
- 本輪只測固定原 Stage3 目標，結果不等同使用加權集成目標的效果；沒有新增 pruning、貢獻或付款實驗。
- 30seeds 提供本輪確認比較，仍需依效果大小與區間寬度理解證據；區間跨零不證明兩方法等效。
- 後續方向依結果決定：若只是改同 20 筆資料的權重仍沒有收益，優先研究事前可取得的新資訊、可信回饋或決策品質，而非依正式結果再調τ。

## 學術來源與改用邊界

- [Breiman：Bagging Predictors](https://statistics.berkeley.edu/tech-reports/421)：重抽樣與平均的穩定化思想；本輪改用於 B 權重，非直接複製其預測器訓練流程。
- [Dalalyan & Tsybakov：Exponential weighting, 2008](https://arxiv.org/abs/0803.2839)：平方損失下指數加權集成；本輪 median-MSE 溫度規則是固定的研究設計，不繼承倒推品質理論保證。
- [Smith & Wallis：Forecast Combination Puzzle, 2009](https://onlinelibrary.wiley.com/doi/10.1111/j.1468-0084.2008.00541.x)：估計權重的有限樣本誤差是等權有時較好的解釋之一；本輪不把它當作已證明的唯一失效原因。
