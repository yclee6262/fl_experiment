# 固定品質代理的排名共識：開發登錄

2026-10-20。前7族164候選尚無兩情境>0.5，不能靠改符號或換確認標準過關。各品質代理回答不同風險，本族測本次團隊內、無歷史係數的固定共識是否較穩定。

固定三個代理：原團隊mean_abs、原20模型池依既有mse最小3模型的abs(mean(signed f))、同三模型的mean(abs(f))。第一個保留本次團隊共同評分；第二個估計平均預測誤差；第三個保留模型分歧風險。k固定3、不依情境選，不學習權重，alpha不改。

沿用四個已鎖定代理端點設定，對每團隊每個代理的signed差值以rankdata(method=average)排名，固定取三份排名的mean（Borda）或median，形成2×4=8候選。排名分數只作相對排序，不能以0判負貢獻或混稱C的原單位；不付款、pruning。這是組合假說，已有單個代理開發結果的資訊；全部仍屬開發資料，不能宣稱無選擇偏誤的效果。
