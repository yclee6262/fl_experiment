# 每輪模型排除候選選擇：搜尋效果驗證設計

日期：2026-11-07。狀態：設計完成，尚未實作、尚未執行。

## 1. 研究問題與界線

每輪完整模型與各個暫時排除一模型的分支，都使用既有切線法／割線法。所有分支從同一主起點出發，保留全部錨點；用固定完整內部 F 選本輪候選，將選中點帶入下一輪。下一輪仍讓全部模型參與，不永久刪模型。

問題一：相同最多輪數下，新流程是否找到更低的完整 F？問題二：相同實際模型評分預算下，改善是否仍存在？問題三：改善來自選擇分支，還是接續狀態／停止規則改變？

本輪為搜尋方法實驗，C^M 只記錄為分支診斷。無貢獻分配、獨特性、基本費、alpha更新或pruning。完整LOO是在不同參與者集合求解與評估貢獻，本輪不以其成本當搜尋效率主要基準。

## 2. 凍結的演算法

固定 F(x)=sum_j alpha_j loss_j(x)，所有候選最後均用此 F，包含被排除模型的評分。目標、alpha、模型、全部錨點與可行域在一次搜尋中固定。alpha_i 必須小於1且剩餘權重和為正；無法排除的模型要顯式列為不可建立分支，不可除以0。

本輪主狀態 S_t 含 x_t、完整F loss、全程最佳點、eta、模式、delta、主歷史、錨點loss與輪次。

1. 保存 S_t；完整分支從這份主狀態執行一輪凍結求解，取得 xF 及完整分支結束狀態 SF。即使完整分支停止或零方向，仍建立其餘分支。
2. 每個 i 以 Fminus_i=sum_{j!=i}alpha_j loss_j/(1-alpha_i) 建立局部狀態，沿用既有 branch_state 語義：重設該分支目前／最佳loss與局部歷史；起點、eta、模式、delta均來自同一 S_t。保留全部錨點及原錨點方向權重，執行一輪原求解，得到 xminus_i。不是以完整分支結束後的點作起點。
3. 候選集合包含 x_t、xF、各個 xminus_i。每個候選須有限、符合原box容差，並完成全部模型的F評分。模型-點精確快取可跨同一執行內的分支共用。
4. epsilon_t=1e-10*max(1,abs(F(x_t)))。若最小F未比原點低超過epsilon，保留原點；否則取最低F候選。距最低F在epsilon內的候選視為同分，優先完整分支，再按模型固定ID順序選。此規則可能選到比數值最小值高epsilon的點，應明列為容差內最優。
5. C^M_i,t=F(xminus_i)-F(xF)；另存本輪分支額外改善 G_t=F(xF)-F(xchosen)。G_t只作當輪比較，不能直接加總宣稱等於新舊流程最終差距。
6. 主狀態採用xchosen；目前loss、global best與歷史全部以完整F更新。主歷史每外層輪只新增一筆，不能拼入排除分支的Fminus歷史。主錨點loss使用完整F，可重用快取。下一輪next_iteration=t+1。
7. eta、current_method、delta沿用SF的排程。排除分支只提供點，不帶入它自己的步長或Fminus最佳值。若完整分支提早break，取當時已定義的狀態，不推測其未執行更新。
8. 若採用點改善超過epsilon，清除主停止旗標並繼續；即使SF表示停止，也不能壓掉其他分支的改善。若沒有改善且SF已停止，整體停止；若完整分支只是由割線切換切線、尚未停止，允許依排程再執行一輪。另有外層輪數、評分預算及非有限值停止限制。

逐輪F只能在數值容差內不增加。這保證同一路徑的單步接受規則，不保證新流程最終優於原流程；新點會改變後續方向、步長運作與局部解。

## 3. 四個比較版本

| 代號 | 方法 | 用途 |
|---|---|---|
| O | 原始完整切線／割線求解，原生停止與排程 | 實用基準 |
| S | 新主狀態接續器，只建立完整分支 | 控制接續器、容差與停止規則的影響 |
| D | 新接續器，計算全部排除分支，但只採完整分支／原點 | 診斷成本對照；確認額外計算沒有污染主搜尋 |
| P | 新接續器，採用完整F最好的分支／原點 | 提案方法 |

固定輪數下D與S必須具有相同主點序列及核心狀態（數值容差內），D只能增加查詢／診斷紀錄。若不同，視為實作錯誤。

S與O比較用於偵測接續規則效果。容差過濾可能造成可解釋的微差；開發門檻要求終點F差<=1e-8*max(1,F初始)，主點差<=1e-7或能定位到原演算法近零停止／接受邊界。超出門檻先停止、修正或明確另版登錄，不把接續器效果歸功於分支選擇。

主要實用比較是P對O；主要機制比較是P對S。P對D只回答「已付出分支成本時，採用結果有沒有價值」，不能據此宣稱比原搜尋省成本。

鎖定實作及規則後才跑80團隊，不利用確認資料改門檻、步長或挑案例。這只能確認同生成器的新種子效果，不代表新任務、真實模型或不同alpha的外部有效性。歷史其餘團隊可另列重播，不能混入80團隊確認統計。

## 5. 兩種公平比較

### A. 相同外層輪數

四版本最多30輪，保留原／上述停止規則；允許提早停，不強迫跑滿。記錄每輪主F、最後F、完成輪數、分支採用率與全部實際呼叫。

判讀：P若較好，表示增加候選來源有品質價值，但不能單憑此結果宣稱計算效率更高。

### B. 相同評分預算

依模型數n設定每團隊預算 B=200n、500n、1000n，500n為唯一主要確認預算，其餘為敏感度。各方法最多300外層輪，讓便宜方法能在預算內多走；提早收斂者保留其終點，不強迫花完預算。記錄輪數上限是否先觸發，若有，不宣稱是純呼叫限制下的最優比較。

一次成本單位為一個模型對一個點的實際預測；快取命中不計新增呼叫。每個方法獨立快取；初始評分、梯度探測、退火試點、分支狀態建置與完整F補評均計入。不得偷用其他方法或舊實驗的快取。

每次真實模型呼叫前檢查預算，不能超額後再扣。完整分支先執行；排除分支的執行順序以case seed與輪次固定輪替，各方法一致，不以已知分數排序。固定輪數的最終同分選擇仍按ID，與執行順序分開。

預算用完在半輪時：只可從原點及已完成分支且完成完整F評分的端點中交付最佳點；未完成分支／評分的點不得交付。記錄partial_round=true、已完成分支、未完成階段和成本。這是固定預算交付規則，不將半輪算作完整輪。原O也只交付已完成接受與評分的點。

可用同一次跑到1000n的逐查詢紀錄重建較低預算交付點，但須以開發資料顯式重跑預算截止版本驗證等價，且交付過程不能使用截止後的資料。否則逐預算獨立跑。

## 6. 指標與統計

主要指標：新80團隊在B=500n時P對O的配對正規化改善：

R_k=(F_O,k-F_P,k)/max(F_initial,k,1e-8)。正值表示新方法較好。分母固定初始F，不用可能接近0的基準最終F放大比率。

統計以團隊為單位；四個設定等權。用固定seed=20261107、10,000次分層團隊bootstrap報平均R及95%區間。不得將同一團隊的模型或輪次當獨立樣本。P對S、30輪、其他預算及各設定均為輔助／探索性結果，不以挑選最佳預算取代主分析。

另列原始F差的中位數／四分位數、勝平負比例。勝平負容差為1e-6*max(1,F_initial)。若初始F已近0仍保留案例並標記，不能為了提高勝率刪除。

機制指標：排除分支採用次數、各模型分支採用分布、G_t、完整分支停止卻被排除分支救回次數、原點保留次數、模式切換、路徑長度。按完整輪分母報採用率，半輪另列。

成本指標：總呼叫、baseline/full branch、model-excluded branch、common F補評、快取命中；請求次數與真實評分次數分列。牆鐘時間先單次描述，不因少量廉價解析模型的時間就宣稱部署加速。

品質-成本圖：橫軸真實評分次數，縱軸可交付最佳完整F；比較同團隊，再彙整中位數及分布。結果文件至少提供3類代表案例：新法明顯改善、同輪改善但同成本較差、採用較佳當輪分支卻最終較差；若某類未出現明列0，不人工補造。

若現成資料已含獨立pooled evaluator，可在所有搜尋完成後另做離線品質檢查並另計評分成本；本輪確認解析資料未建立外部裁判，因此不把外部品質當已完成驗收。truth亦不進求解。

## 7. 實作驗收與停止條件

開發硬驗收：

- 凍結原solver與模型；保存source hash、manifest、候選端點、逐模型loss及完整主狀態。
- 所有分支從相同pre-state；沒有永久刪模型；full F與alpha固定。
- D/S軌跡一致；S/O接續驗收通過。
- 採用候選是容差內完整F最優；x_t保留；主F不得增加超過容差。
- 主歷史、全程最佳點全部屬於完整F；任何分支Fminus狀態不滲入主狀態。
- 所有交付點有限可行；分支全無改善、零梯度、完全相同模型、同分、邊界、預算在完整F補評中途耗盡等案例均有測試。
- 成本stage和總數一致；無跨方法快取；不可超出個別預算。

任一硬驗收失敗即停止確認階段。非有限值／求解異常保留失敗紀錄，不用刪案例後的成功子集宣稱通過。確認期若有交付失敗，先報完整失敗率且不給通過結論；修復須新attempt、保留舊結果。

資源上限：第一輪全部實作驗證與確認合計500萬次實際模型評分、30分鐘。到上限即保存進度並標記未完成，不挑已完成prefix作正式結論。此為新實驗預算，不續跑先前已停止的舊實驗。

## 8. 預先固定的判讀規則

作為繼續投入的工程門檻，非普遍科學常數：主預算500n時，P對O平均R至少0.01（改善量為初始F的1%）、bootstrap區間下界>0、勝率>=60%、敗率<=20%；同時P對S平均R>0且區間下界>0，並通過全部硬驗收。這樣才稱為「本生成器、此預算下值得推進」。

| 觀察 | 判讀與下一步 |
|---|---|
| 同輪、同成本都改善且主門檻通過 | 推進到不同模型／任務與非均勻alpha；仍不宣稱全域最優 |
| 同輪改善，同成本無改善或較差 | 有搜尋品質價值但昂貴；後續才研究分支抽樣／按需觸發 |
| P優於O但不優於S | 改善可能來自接續規則，不能歸功於排除候選 |
| 大多持平，呼叫顯著增加 | 分支邊際價值低；先停擴大，不以少數好案例支持全面採用 |
| 本輪都選更低F，但最終較差 | 新路徑與排程造成後續差異；檢查軌跡，不能把單步單調當終局優勢 |
| 平均改善，但某設定常變差 | 限縮適用條件，另設獨立驗證；不只報總平均 |
| 內部F改善、未來外部評估惡化 | 內部目標與外部品質不一致，不能宣稱全面變好 |

若主門檻未過但平均有正向趨勢，只列探索結果，不事後改預算／門檻宣告成功。
