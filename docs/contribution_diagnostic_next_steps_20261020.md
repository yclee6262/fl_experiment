# 單步錨點增益之後：先對齊比較對象的診斷設計

執行狀態更新（2026-10-20）：兩階段已完成，結果見 [診斷比較報告](contribution_diagnostic_results_20261020.md)。以下保留原設計；執行前版本另凍結於實驗目錄，未覆寫。

日期2026-10-20。回應使用者「下一步可以如何繼續」。本次只核對既有資料與設計下一輪，未新增模型查詢、求解或診斷結果。

## 為何先診斷、不立即換公式

本輪單步錨點增益A，成本比完整LOO低，但與custom完整移除pooled品質排序未穩定對應。A與原參考同時存在三項差異：

1. A用內部全團隊搜尋目標L，原C用離線pooled品質E。
2. A只拿掉錨點方向，原C同時移除錨點、評分模型及alpha。
3. A在原路徑、原接受距離逐步比較，原C從保存起點重新走完整路徑，步長／接受／切換都可改變。

不能由單一低相關推論只要換加權就好，也不能把對某個內部代理的成功改稱最終品質有效。本輪負面結果及原來的參與者品質目標均保留。

## 第一階段：先查評分標準的差異（推薦優先）

使用已保存的20團隊baseline及80個custom完整移除解，保留相同位置、不重跑solver。

對每個移除後解X_full_without_i，以**原完整團隊模型及原alpha**重新評L_S；不能用移除輸出檔的result.loss，它用的是剩餘團隊的目標，不是同一把尺。

`C_full,L,i=L_S(X_full_without_i)-L_S(X_full)`

原pooled參考保持：

`C_full,E,i=E(X_full_without_i)-E(X_full)`。

固定報告A對C_full,L、A對C_full,E，以及C_full,L對C_full,E的團隊內排序／近零／方向分布。不得因哪把尺相關較好就回填原正式結果。

baseline的L_S(X_full)已保存，20團隊中Clean每團隊3人、污染5人；重新評每人移除位置時查所有原模型，上限10×3×3+10×5×5=340個參與者模型輸入，重複位置可快取。0個新solver、0次重訓，pooled E值可直接重用已鎖定參考。這是工作量上限估算，不是已產生成本。

判讀：若內部與pooled的效果排序本身不一致，評分差異是值得關注的環節；但這不證明它是全部原因。若A只對內部有訊號，也只能稱內部指標的診斷訊號，不能宣稱參與者品質貢獻有效。即使內部相關低，第二階段仍可檢查角色差異。

## 第二階段：建立同角色的全程錨點參考

沿用20個保存案例、原模型、alpha、target、box、原X0及custom30。每次只拿掉I_i，保持所有評分模型／alpha及搜尋目標L_S不變，將剩餘方向權重按原規則正規化，再從原X0完整跑custom。

得到X_anchor_without_i後，建立：

`C_anchor,L,i=L_S(X_anchor_without_i)-L_S(X_full)`

`C_anchor,E,i=E(X_anchor_without_i)-E(X_full)`。

這是候選／錨點角色的程序效果，不是完整參與者貢獻。P3曾有候選排除的正式負面結果；這裡是新資料來源、custom-only、固定起點的對照診斷，不是重推P3估計器有效，也不把舊best_of候選排除標籤混用。

只需新增80個custom錨點移除求解，baseline與原完整移除解重用；沒有重訓或新seed。固定上限80 solves、200,000 participant samples、300秒solver，失敗保存，不換樣本。這些是待執行預算，不是已實測需求。

| 固定比較 | 主要檢查的差異 |
|---|---|
| A vs C_anchor,L | 同錨點角色、同內部尺下，原路徑單步累積與重新求解的差距 |
| C_anchor,L vs C_anchor,E | 同一批錨點反事實位置，評分尺改變的差距 |
| C_anchor,L vs C_full,L | 固定同一把內部尺，錨點移除與完整參與者移除的差距 |
| C_full,L vs C_full,E | 同一批完整移除位置，評分尺改變的差距 |
| A vs C_full,E | 保留最初真正想近似的品質目標，不因診斷改名通過 |

這些對照不能把所有交互作用分解成可相加因果量；例如第一列仍同時包含固定單步距離、接受／切換、新路徑與跨步累積的差異，只能定位範圍，不能單憑它斷言是加總公式造成。

## 第三階段：定位後才決定下一個方法

- 若A能反映C_anchor,L，卻無法反映C_full,E：可暫定位為錨點／內部搜尋診斷工具；若研究目標仍是參與者品質，還需研究模型角色及外部品質，不能直接採用。
- 若連A對C_anchor,L也弱：先查原路徑反事實與移除後新路徑、早晚步抵銷、跨步重複計入等。可先讀既有J明細作描述，不依LOO選最佳權重或某一輪作新正式方法。
- 若參考效果多為近零或數值不穩：保留undefined與覆蓋率，先檢查可辨識性；不把數值噪音排序當作失敗或成功。
- 只有對照指出有可檢驗機制後，才另立新估計器設計、凍結驗收並準備真正獨立資料；不再一邊換分數一邊沿用同一批答案宣稱泛化。
