# 專家選擇權與局部偏差風險：初始 α 研究紀錄

## 問題與對照

在固定乾淨二維、target 0、參與者 IDs 1／2／20、box [-1, 1] 的設定下，比較新的初始 α 候選是否能讓最終 X 的 pooled evaluator 絕對目標誤差低於現行五候選校正式多起點。pooled 與合成真實函數只事後評分，不參與候選挑選。

原方法分別以 Uniform、Stage 0 MSE 倒數、MSE 倒數 1.5 次方、殘差二階矩修正，以及目標附近 MSE 建立五組 α；每組各做 Stage 3，用 Stage 0 的 B 加權 ridge 偏差校正分數選交付 X。

## 新候選及經濟意涵

**Best-agent（專家選擇權）**：取 Stage 0 盲測 MSE 最低的參與者，建立只給該方權重 1 的 one-hot α，另外做一次 Stage 3。六候選流程把所得 X 加入原五候選，沿用完全相同的內部選解分數。這使單一驗證較佳的專家成為可選方案；若預測效益不足，仍保留原方法的交付結果。它需多一次求解，並非免費切換。

**Local-bias-risk（局部偏差風險）**：在既有 20 筆 Stage 0 標記資料上，對每個 local model 的有號殘差與輸入位置做 ridge 線性回歸（截距懲罰 0.01、座標係數懲罰 1）。令 c 為 Stage 2 proposals 的平均位置、b_i 為 c 的預測偏差、v_i 為回歸後殘差平方平均，設 α_i 比例為 `1 / (b_i² + v_i + 1e-5)`。七候選流程在六候選之外增加此 α 與一次 Stage 3；用同一選解規則。它反映預期區域的偏差與不確定性，但局部線性假設可能不成立。

兩個新增 α 只讀盲測資料、local predictions、proposals；不使用 pooled evaluator 或合成真實函數作初始化輸入。多起點最終 α 為被選中候選的初始 α，不是全部候選的平均。

## 開發與 pilot

先在已用過的 seeds 500–529 與 600–659 上，將各新 α 加到原五候選的保存模型與 proposal，再以原內部規則選 X。六候選的平均 pooled 差（新減舊）分別為 -0.001768 與 -0.001054；七候選分別為 -0.001468 與 -0.001636。這是從多個探索試法中挑出的開發數值，不可用作正式優勢區間。

5-seed pilot（seeds 0–4）有 25／25 條摘要條件、35／35 個候選有效；三種多起點選擇共 15／15 次重算通過。平均 pooled 誤差：五候選 0.014757、六候選 0.014757、七候選 0.013966；每條件平均模型請求：2031.0、2248.8、2637.6。pilot 僅證明流程與計數可用。

## 正式規則與資料

## 獨立正式結果與判定

seeds 700–759 共 300／300 條摘要條件有效；五／六／七候選各 60／60 個有效交付解。保存模型及盲測資料重載後，180／180 次多起點選擇重算通過；14／14 個事前登錄來源 SHA-256 與執行版本一致。可行性及外部分數亦通過共用驗收。

| 方法 | 平均 pooled 絕對誤差 | 平均 truth 絕對誤差 | 平均方法請求 | 平均方法內本機秒數 |
|---|---:|---:|---:|---:|
| 五候選基準 | 0.015218 | 0.013511 | 1857.55 | 0.1451 |
| 六候選 Best-agent | 0.015081 | 0.013054 | 2141.00 | 0.1624 |
| 七候選 Best-agent + Local-bias-risk | 0.016300 | 0.012862 | 2506.00 | 0.1986 |

**事前主要比較**六候選減五候選：同 seed 的 pooled 差平均 -0.000136851；固定分析 RNG、10,000 次 seed-bootstrap 的 95% 區間為 [-0.001257999, +0.001009866]。60 個配對中較好 8、相同 49、較差 3，沒有額外失敗；因區間跨零，**未通過穩定品質改善門檻**。平均多 283.45 次模型請求，未建立經濟上更划算的證據。

**次要探索**七候選減五候選：pooled 差平均 +0.001082418，95% 區間 [-0.000652676, +0.002940004]；較好 14、相同 36、較差 10。平均多 648.45 次請求，pooled 均值更高。其 truth 均值雖較低，但 truth 只作診斷，不取代事前的 pooled 判準。逐 seed 的 pooled／truth 比較方向相衝突，六候選 3／60、七候選 7／60；衝突不代表可在兩種指標間事後挑選有利結論。

**決策**：保留原五候選方法，這兩個新增候選均不納入主要方法；依登錄的門檻，不進入污染、高維等複雜情境。若繼續搜尋，需用新的方法定義、獨立 seeds 與事前規則，不依本批正式結果調整公式後仍宣稱獨立驗證。完整結果見 `alpha_weight_outputs/alpha_specialist_formal_v1_20261004/economic_decision.json`、`selection_verification.json`、`analysis.json` 與原始 CSV。
