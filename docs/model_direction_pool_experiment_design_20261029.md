# 方向差異模型池：有界驗證規劃 v1

日期 2026-10-29。使用者授權子代理實作、執行；主代理規劃及獨立判讀。此文件在新實驗前固定，所有結果為新探索結果，不回填歷史正式確認。

## 固定定義

單模型單 owner，固定錨點與模型權重，不改搜尋。保留原同輪 model-only P 及接受端點；full 原路徑繼續，minus 僅當輪。每個模型以同25共同探測點（兩維 [-1,-.5,0,.5,1] 笛卡兒積）的 Q90-Q10 作固定 s_i，低於 1e-12 為 undefined。模型、資料、loss、座標固定、確定評分才允許快取。

方向 g：割線 [loss_i(a_k)-loss_i(x_t)]/(s_i*distance)；切線以原實際 bounded step h 的探測差商替代。全模型共用原solver有效方向，distance<1e-8 排除；切線 h<=1e-12 排除。空集合／缺漏不可填零。U_i=min_j sqrt(mean_k((g_i-g_j)^2))，單模型owner版本。參考距離 r_ref=.1；Uhat=.1*U，Ub=Uhat/(1+Uhat)。I=norm(full-minus)/pre.eta，Ib=I/(1+I)。N=Ub*Ib；若原solver梯度近零而終止，仍記該輪接受起點及有效方向，不能遺失潛在制衡。

同輪其他模型 P 按固定 v 加權平均標準化端點loss差；分別累積 P、Ub、N。P 先有號加總再取正，不逐輪截正。可靠正門檻沿用 max(1e-8,rounds*1e-10)。每案 B=500 整數研究單位，子額度用固定 beta，分別最大餘數取整、owner ID tie-break，無正分保留該額度、缺必要資料整案 held。無實際金錢。

## 固定比較與主要問題

基準 beta=0 P-only；P+Ub 與 P+N 固定 beta=.1,.2,.3，主候選 beta=.2，其他只敏感度，不事後選勝者。兩項額度不互轉。問題是補回 beneficial 而非只增加發放：比較新增 beneficial owner 及 harmful/zero owner 領獎、其金額，保留率與集中度。N 不作有號品質估計，不用符號符合率宣稱有效。

## 資料、執行次序與成本上限

舊 peer 46案例全部當已讀開發，可重用封存端點但必須有來源hash並核對；新逐輪方向資料需真實原solver查詢或可核對既有查詢。新增最多32個解析任務，包含有益／錯誤少數、有效／錯誤制衡、複製模型與固定種子擾動／錯誤評分、2D；至少8個自然多輪路徑（最多8輪），須覆蓋割線與原流程切換後的切線。不得把強制切線宣稱自然切換。新參數一半開發、一半保留，具體fixture在首次solver前存檔hash；開發完成鎖checkpoint後才分析保留。保留也只是參數外推／機制驗證，不是外部有效性。

預算最多2500單輪分支、250000解析模型評分、10分鐘主流程、200MB。無訓練、無真實模型大型實驗、無pooled進計分；reference僅在分數及分配落盤後診斷。未覆蓋的情況如實列未完成，不能用單元測試冒充多輪效果。

## 必要驗收及停止

技術：原solver完整路徑／接受端點不變；逐模型快取與重算一致（浮點容差1e-10+1e-9*abs）；缺漏 held、無正保留、預算守恆、固定尺度×.1/10/100在固定路徑下分數與支付穩定；獨立公式與至少解析分支核對；記錄所有評分請求、實際計算、快取命中、反事實分支數及壁鐘。

研究主gate：保留資料 P+N(.2) 比 P-only 至少補回一個有益作用，且有害總金額不增加；比 P+Ub(.2) 有害金額不更高且補回有益數不更低。任一不滿足不得推薦部署。另檢查零作用是否被補充獎勵、複製／噪音是否取得不合理收益；所有已知觀測相同診斷相反的配對須保留並說明辨識限制。不可為通過gate調beta／尺度／挑案例。

技術失敗先停修復，輸出exclusive-create新attempt保留原失敗。品質失敗不擴大實驗，整理失敗機制與下一步。凍結歷史程式／結果，不改alpha、pruning、基本池、錨點池或Notion。
