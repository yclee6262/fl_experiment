# 法五完整貢獻流程與完整參與者 LOO：成本比較結果

日期：2026-10-30。執行規約：`method5_vs_full_loo_cost_design_20261030.md`。實作由 GPT-6.1 Sol 子代理執行，主代理獨立核對。正式量測輸出：`contribution_analysis/method5_cost_experiment_20261030_attempt_04/`。

**結論：本輪沒有建立低成本優勢。新流程用了39,418次模型評分，完整LOO為27,414次，新流程多43.8%；20個團隊全部較貴。核心計算時間加總約1.365秒對0.813秒，新流程為1.68倍。不能以成本較低推薦目前完整方案。**

這不否定錨點與模型分開計算的用途，也不比較兩者是否回答相同問題。本輪回答的是實際計算成本；沒有把局部作用重新定義成完整LOO效果。

## 1. 比較內容與公平條件

- New：一次原完整搜尋與必要輪前觀察；所有owner的逐輪錨點方向移除C^A；所有模型的逐輪評分移除C；固定完整F的端點評分；25點尺度探測；方向去重與U/I/N；錨點500與正C資格C+N模型500的影子分配，β=.2。
- LOO：一次原完整搜尋；逐人從原起點同時移除錨點及模型，依凍結原規則重新正規化剩餘權重、完整搜尋；用原完整F補評最終端點。原搜尋最多30輪，自然停止條件相同，不強迫各分支跑相同實際輪數。
- 二者使用相同保存模型、CPU單執行緒、精確輸入快取、同等快取機會。每個方案及每次重複從空快取開始；不共享另一方案或歷史回覆。原模型評分的重複請求在baseline也可命中；這與10/22舊比較baseline全額計費不同，不能混用數字。
- New尺度探測在原搜尋前執行並全額計費；LOO沒有不需要的探測或方向觀察器。新方法的錨點／模型角色可共用同臂快取，LOO不同移除分支也可共用。
- 基本池兩臂對稱執行既有T0/T1完整履約固定測試合約與事件。這測到標準帳務引擎成本，但不是各團隊動態請求、准入、身分認證的真實接入。沒有實際付款。

一評分樣本＝一個模型對一個位置的真實推論；API呼叫未批次化。邏輯請求與快取命中分開保存。所有新分數、模型尺度與參數保持既定版本，未因結果較貴而刪輪或改公式。

## 2. 資料與驗證順序

開發先用兩個既有團隊（seed 2026101600），乾淨3人、污染5人。獨立核對69個owner×輪：原搜尋結果、每個錨點分數與端點均重現，錨點分配分別455／45／0及80／170／0／15／235。主代理開發驗收通過後才執行正式20團隊。

主要比較使用既有歷史20團隊，乾淨／受控污染各10隊，seed 2026101610至2026101619；與兩個開發團隊不重疊。全部二維，故沿用25點固定探測，不另設高維規則。模型早已訓練，本輪沒有新訓練或新增獨立實務資料。這是歷史團隊的新成本量測，不是新應用泛化確認。

每團隊一次暖機、三次交錯順序量測；每次清空快取。暖機後先核對原baseline及完整LOO全部回傳欄位與歷史資料，通過才進計時重複。重複結果、分數及實際推論數完全相同。主要比較涵蓋251個原輪、1,033個owner×輪，每個owner×輪各一個錨點及模型移除分支。

主要負擔是兩類逐輪分支，而非N的幾行公式。新流程做2,066個局部分支；LOO做80次完整移除搜尋。局部分支每次仍可能有多次縮步、模型查詢及共同補評，完整LOO也可能提早自然停止，所以不能從「只重算一輪」推導省成本。

即使假設完全免除2,000次尺度探測，新流程仍至少37,418次，高於27,414次約36.5%。這只是由已量測成本得到的樂觀減項下界，不是已實作、已計時的C-only新方案；不能據此宣布其他修改後版本的效果或成本。
