# 學長後續設計：重要回合抽查、可核對的區間與精確回退

2026-11-10。狀態：下一步設計；僅第2節是本次對舊資料做的零新增模型呼叫診斷。未跑新求解、未調整歷史演算法、未建立新方法有效性。

## 1. 建議先做什麼

先完成「零代理基線＋原快取可用值的代理一致性修正」診斷，再測重要回合抽查。現在應先問代理是否幫忙，而非只替原代理提高抽樣效率。

最小可落地的主候選是：**錨點CA使用確定界與部分抽查，模型CM維持完整F精確計算**。它沿用目前兩種角色的定義；模型池不為了容易做區間而換成peer尺。若CA節省的成本足夠，整體仍可能低於完整LOO；需配對重跑確認，不能相加歷史分項就宣稱省成本。

重要性抽查與CI是學長原文六三5、六一3／6的延續。以下門檻是建議工程／探索門檻，不是老師已核准的採用標準。

## 2. 本次新診斷：原代理反而增加了抽查變異

來源：senior_remaining_20261109_attempt_01/records/*_base.json，共20隊；使用既有exact與proxy，零新增模型呼叫。

固定路徑、獨立同機率p的Bernoulli抽查，HT修正總和的變異為 `(1-p)/p * sum_t (C_t - proxy_t)^2`。零代理則是 `(1-p)/p * sum_t C_t^2`。因此可以直接比較兩種殘差平方和，而無需重抽或查詢。

| 評分尺／角色 | 原代理殘差平方和 ÷ 零代理 | 原代理較差團隊 |
|---|---:|---:|
| F／CA | 8.2795倍 | 17/20 |
| F／CM | 19.1615倍 | 14/20 |
| Fminus／CA | 7.5741倍 | 16/20 |
| Fminus／CM | 29.6553倍 | 16/20 |

這是合計條件式HT變異比，不是獎金誤差比或新模型確認。原代理可保留負面基線，但目前沒有理由只以它作所有新抽查設計的唯一基準。

重現程式：`contribution_analysis/senior_followup_proxy_diagnostic_20261110.py`。輸出及來源hash：`docs/senior_followup_proxy_diagnostic_20261110.json`。

## 3. 現有實作的正確部分與限制

- 原始signed prediction由既有API回覆保存，再取絕對loss；沒有新增尺度探測。
- 固定路徑、固定代理、獨立Bernoulli且所有不確定殘差π>0時，現有HT點估計及設計變異估計公式適當。總和無偏不保證獎金截正／正規化無偏。
- 目前常態CI的失敗是實際結果，不能只換成t分布臨界值便宣稱修好。抽查漏掉主導殘差時，估計變異甚至為0。
- `run.py`的代理端點評分一律使用`ploss`。即使代理落在原搜尋已查過的點，也未自動取已知真實輸出；若落在full端點，理論上該端點差應為0，代理仍可能算出非零。下一版必須做同點一致性控制。
- 原方向由真實既有loss重建，代理只模擬端點評分和縮步。修正時不得偷偷改方向或接受規則，否則估計對象變了。
- 原成本重跑先跑完整baseline再做角色分支，快取可能包含後續輪次的點。此成本是搜尋結束後的批次離線貢獻計算。若要宣稱每輪即時計算，必須另用時間戳可見快取，分開列成本；本輪主規約先採批次離線，不混用口徑。

## 4. 資料邊界與輸出介面

每個item定義為 `(team_id, owner_id, round_id, role)`，role為CA或CM。每個item保存：

- 原輪x、接受端點、Fcurrent、Ffull、eta、mode、方向及零方向狀態。
- 各模型在原搜尋已評點的signed prediction、模型版本、input位元key、首次可見輪次。
- 代理候選／試探序列、代理值、cache命中來源、是否與原端點完全相同。
- sampling_design_id、預先計算的π、分層與抽籤seed、selected、實際查詢事件及成本。
- exact值只在抽中、確定可由cache推得，或精確回退時提供給計算器。未抽的exact留在驗證器，不能流入特徵、抽中機率、停止判斷或付款。
- 分數尺F固定為主；Fminus只作同端點敏感度，另名另表。

採樣器只能接收`ObservableRecord`；驗證器可讀`OracleRecord`。對採樣器輸入序列化後做hash，並做「刪除所有未抽exact欄位仍輸出完全相同抽樣方案」的隔離測試。

## 5. 先做三個代理版本，不全面排列組合

| 版本 | 操作 | 新模型呼叫 |
|---|---|---:|
| Pold | 原最小範數代理，完整保留作負面基線 | 0 |
| Pzero | 每個item代理固定0；仍透過抽查HT估計原精確分數 | 0 |
| Pcache | 原代理，但每個試探點若已有合法時間範圍內的精確模型回覆，優先使用；相同端點差必為0 | 0 |

Pcache只允許精確模型版本＋input key命中，不用「很接近」當成同一點。未觀測模型的分數不能由另一模型代替。若兩端點本來就已完全評過，該item可直接精確計算，其殘差不再未知，且不消耗抽查預算。

在舊20隊上補列：每owner最大單輪殘差平方占比、代理／零代理殘差平方和、方向矩陣秩與條件數、候選外插距離、full點proxy誤差、縮步接受次序差異。精確殘差僅用於事後診斷。不得用已看到的最大殘差作部署保證界。

只在開發資料選一個代理進入下一階段；若Pcache仍不能降低殘差平方和，後續先用Pzero，保留「代理尚無增益」結論。Pzero是統計對照，不表示參與者貢獻設定為0。

## 6. 重要回合抽查的兩個可實作設計

### 6.1 主建議：可觀測風險分層、固定樣本數

搜尋端點固定後，對每位owner、每個role分別建立有限母體T個item。用原搜尋可觀測的full試探點預測誤差、代理試探點外插程度及原輪步長作風險排序；不讀移除分支exact殘差。最小版本採「原full試探點的最大signed prediction誤差」一項排序，先不學習回歸模型。

各owner×role依上述風險分成高／低兩層（平分，tie按輪次）。事前固定總抽查數m，把約2/3名額給高風險、1/3給低風險；每個非空非全查層至少2個，否則合併層或宣告該預算不適用。不得為維持低成本名目而讓某未知層π=0。

層內均勻不放回抽樣，層h大小N_h、抽m_h，π_t=m_h/N_h。估計式為：`S_hat=sum proxy + sum_h N_h * mean_sample(residual_h)`。

層內樣本變異s_h²可得時，設計變異估計為 `sum_h N_h²(1−m_h/N_h)s_h²/m_h`。此公式與獨立Bernoulli不同，不能沿用舊ΣZ(1−p)e²/p²。m_h=1無法從樣本估s_h²；改合併層、全查或保留未知，不能填0。

同預算對照用不分層SRS，總m相同。每分支保守上限按10次試探＋全模型端點補評計11n次；固定m提供同「最壞新增呼叫上限」。cache共享與縮步差異仍會使實際成本不同，必須量測，不說實際成本完全相等。

### 6.2 附對照：獨立非均勻Bernoulli

以相同觀測風險v_t與估計成本c_t設 `π_t=min(1,max(π_min, λ v_t/sqrt(c_t)))`；π_min取本次目標均勻率的1/4。λ由二分法使Σπ_tc_t等於均勻arm的預期代理成本。c_t只能由已知n、原輪或代理縮步次數給出；不能偷讀該未抽精確分支的真實成本。

仍使用itemwise HT與獨立Bernoulli設計變異。此arm比較的是相同「預期代理成本」，不是保證相同實際成本。報實際均值、分位數、超預算比例。因成本到達上限而臨時停止會改變抽中機率，不能把剩餘item當未抽且沿用原π；此時該trial標為未完成，不產生合法付款輸出。

為避免第一次實作過多，6.1為主候選，6.2只在6.1有可觀測風險辨識能力後做。

## 7. 有效區間：先利用原法已給的確定界

### 7.1 CA完整F有可部署、零新增呼叫的上下界

令B_t=F(x_t)、A_t=F(x_t^F)。原CA分支只接受F低於B_t的點，否則停在x_t，且loss非負，因此：

`0 ≤ F(x_t^{-A_i}) ≤ B_t`，所以 `−A_t ≤ C^A_it ≤ B_t−A_t`。

這是雙側界；即使B_t−A_t很小，負側仍可很大，不能把原輪改善量當成|C|上界。

抽到item用精確值，未抽item保留上述上下界，直接相加得累積識別區間 `[L_i^A,U_i^A]`。所有前提成立且包含數值誤差裕量時，這是確定包含區間，不是名目95%CI。可以依目前區間寬度選下一item並隨時停止，不需假裝自適應停抽後仍有原HT保證。區間可能很寬；寬就是資訊不足，不能只回報點估計掩蓋。

為保持研究比較清楚：HT點估計使用事前固定抽樣；自適應區間縮減arm另列，不將其精確補查殘差以原π重加一次。

### 7.2 目前CM完整F通常沒有可觀測有限上界

CM分支接受的是Fminus改善，不限制被移除模型在新端點的loss。故完整F版CM有下界 `−F(x_t^F)`，但從既有有限點的輸出一般推不出有限上界。

不能用歷史最大loss、當前樣本最大殘差、只存在本地但部署不開放的網路權重，冒充已知全域界。若未來契約確實規定可驗證的有限輸出範圍，可另推完整F界；若採clipping，必須承認分數定義被改變。

**本輪主候選：CM完整F維持精確計算。**這讓基本費的模型負值判定與模型份額不受抽樣影響，先測CA能省多少成本。

附註：CM若只作Fminus診斷，有 `−Fminus(full) ≤ C_Mpeer ≤ Fminus(current)−Fminus(full)`；CA若用Fminus診斷，也有 `−Fminus(full) ≤ C_Apeer ≤ Fcurrent/(1−alpha_i)−Fminus(full)`。這些是診斷界，不代表已決定改peer付款。

### 7.3 若需要真正機率CI

已知殘差絕對界R_t且獨立Bernoulli時，`Vmax=Σ(1−π_t)R_t²/π_t`為估計誤差變異上界，Chebyshev給出保守區間 `S_hat ± sqrt(Vmax/δ)`。可由CA已知C界與固定proxy推R_t。此推導不假設常態，但可能太寬；需要報寬度與成本，不能只報覆蓋。

沒有確定界的CM不適用。不能以幾次重抽的經驗95%分位數宣稱對任意新模型有95%保證。對固定樣本的常態／t區間可保留經驗對照，但一律報實際coverage。

多個owner／role需要同時保證時，事前分配總δ，例如Bonferroni δ/(2n)；單一95%區間不等於整團隊95%同時覆蓋。若要求可選停止，另建立適用的confidence sequence或使用上節確定區間，不能重複查看固定樣本CI直到滿意。

## 8. 分數區間如何變成分配與基本費判斷

保留既定門檻τ，先把每個分數區間變成獎金權重界。`w_i=s_i 1{s_i>τ}`：若U_i<=τ，權重上下界都是0；若L_i>τ，下界為L_i、上界U_i；若跨門檻，下界0、上界max(U_i,0)。不能把L_i截正後的份額當原方法無偏估計。

若至少某人的權重下界>0，保守份額界為：

`q_i_low = w_i_low / (w_i_low + sum_{j≠i} w_j_high)`，
`q_i_high = w_i_high / (w_i_high + sum_{j≠i} w_j_low)`。

分母0需明列「全部保留亦可能」或q_i_high=1的情況；保留額視為額外一個分配項。可枚舉n<=5的門檻組合核對公式，再用小型全域優化核對極值。區間跨0的參與者不可自動當正或負。

目前基本費規則是SA<−τA且SM<−τM才取消。CM精確時：SM>=−τM立即確定基本費不因雙負取消；SM<−τM且UA<−τA才可確定取消；SM<−τM且LA>=−τA可確定保留；其餘需補查CA或輸出未決。未決不等同「已履約所以必付」也不等同「負值所以拒付」，須由事前契約規定，研究先報未決率與補查成本。

## 9. 最小執行矩陣與成本上限

### S0：零新增模型呼叫診斷

舊20隊全部視為開發。先做Pold/Pzero殘差比較（本文件第2節已完成）；Pcache需要重新產生可見時間戳與候選紀錄，尚未實作。檢查觀測風險對最大殘差回合的召回率、前20%風險覆蓋的殘差平方比例，僅作診斷。

若可觀測風險不優於均勻選回合，不推進更多複雜抽樣特徵；先回到零代理或CA確定界。

### S1：既有模型的最小配對開發

從既有20隊預先按情境選各2隊作工程開發，其餘仍只能稱既有模型內測，不重新包裝成獨立確認。

主arms：精確CA+CM；完整LOO；CA均勻SRS＋精確CM；CA風險分層SRS＋精確CM；CA確定區間主動補查＋精確CM。代理只用S0選定的一種，另保留Pzero點估計對照。抽查名額10/20/40%；若T太短無法滿足min樣本規則，報infeasible，不能強行標稱10%。

每隊／固定率1000個抽樣遮罩作條件誤差分布，真正成本重跑至少20個遮罩。必須空快取啟動同原搜尋，所有成本含baseline，驗證分支不得反向污染其他arm。舊完整exact只供驗證器。

先以100萬實際模型呼叫、180秒為小包上限；達上限保留partial，不產生採用結論。若一次實測超時，根據已完成成本重新登錄下一包，不能默默加預算。

### S2：凍結後新模型確認

至少20個未用過的新模型團隊（n=3／5、一般／異質偏差四組各5），固定新seed與30輪，不重用舊模型只換起點當作新模型。解析模型只能證明機制與成本；真實模型外部泛化需另批來源。

凍結採樣規則、proxy、τ、停止／回退與採用門檻後才讀確認結果。工程上限200萬實際模型呼叫、300秒；累計超過上限標未完成。每方法至少20個抽樣seed，確定界active arm固定tie順序並額外測不同tie隨機seed。

## 10. 驗收、停止及交付

工程必過：baseline結果一致；CA／CM exact與原engine逐端點誤差<=1e-8；原真值落入CA確定界；同端點貢獻0；抽樣器不讀未抽exact；固定抽樣π可獨立重建；預算＋保留守恆；該精確fallback的成本全數入帳。任一失敗立即停止該arm。

探索參考門檻（非老師核准）：含baseline總呼叫至少比完整LOO少10%；至少80%團隊達同方向節省；CA池平均TV<=0.10且95分位<=0.20；基本費相對精確規則錯扣率<=1%、未決率與回退率完整列出；宣稱95%CI時須報每owner與整團隊coverage，不能只用跨隊平均掩蓋低覆蓋情境。確定區間若任何真值不在其中，視為工程／前提失敗而非容許5%失敗。

若含回退後不再便宜，直接結論「本設定下精確付款與成本目標無法兼得」；不得隱藏回退成本。若只有部分團隊可低成本辨識，報適用條件，不宣稱普遍替代。若尚需改成新的品質尺、改alpha或新資訊，離開本包範圍，先停止而非自行擴張。

交付：registration、source lock、可見資料快照、sampling plan、query ledger、score/interval/share、fallback log、paired cost、conditioned error與coverage、case counterexamples、獨立重建audit。所有新資料使用新attempt，不回填11/9結果。
