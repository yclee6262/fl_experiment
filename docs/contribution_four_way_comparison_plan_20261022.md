# 四方案效果與成本比較：執行規約

2026-10-22。授權：依照規劃去進行四種方案的比較。這是既有資料上的探索性比較，不是獨立正式確認，不回填P3或先前結果。

## 固定方案與問題

1. S1：原版等距錨點A＋逐輪模型M，保留雙分數。
2. S2：全輪、可重新縮步錨點A2＋同一M，保留雙分數。
3. S3：逐輪共同排除錨點與模型，累積J。
4. S4：原起點完整參與者LOO，custom30，得到D_L；pooled參考D_E只重用已鎖定離線值。

S1/S2的C=A+M、C2=A2+M列為預先固定的次要單分數比較。雙分數沒有預定唯一排名，不能事後挑較好的角色充當整個方案，更不能調整權重。

固定20舊開發團隊，seed2026101610–1619×clean/controlled_poison，80參與者；不加seed、不訓練、不改alpha或歷史solver。舊pilot不加入效果統計。原版A不改規則；未定義或缺失不得補零。

## 效果與選擇規則

先重建並鎖定A/A2/M/J及C/C2，再讀取既有full-removal固定完整團隊內部D_L與pooled D_E。主要問局部累積能否還原全程內部移除效果；外部品質另列。

每團隊跨人Spearman，至少3人且兩邊range>1e-4；團隊等權。正負一致的分母固定為abs(參考)>1e-4，預測近零算未命中，與部分歷史報告使用預測非零分母不同，不混用。另列正/負召回、近零比例、缺失、標準化絕對差sum(abs(score-reference))/sum(abs(reference))；後者只作不同估計對象的數值差距，不當已校準誤差或通過門檻。

bootstrap按配對seed/團隊重抽10000次，RNG20261022，99.8%探索區間；所有指標/配對差完整公開，區間不宣稱涵蓋整個新比較族的正式多重檢定。配對比較固定A2-A、C2-C、J-C2及C2-M的排名差，不增加事後比較。固定代表例為abs(C2-J)最大與abs(J-D_L)最大。

若要推薦低成本單分數替代完整內部LOO，C/C2/J在兩情境均須：至少8/10團隊可排名與可算方向、>=95%完整資料；平均rho>=0.5且區間下界>0；方向一致>=70%且區間下界>50%；部署總模型評分<=S4的70%。雙分數S1/S2仍按角色診斷評價，不給事後合成冠軍。D_L對D_E的一致性另列，S4對自身的相關不算效度證據。不存在通過者則明確結論為沒有建立替代方案，保留完整LOO為指定程序的參考。

## 獨立成本重播

四方案各自從空白成本帳啟動，先實際重跑原完整搜尋；原baseline按原始呼叫全額計費、不改原搜尋快取行為。每方案只可重用本次baseline的完全相同模型/float64輸入回覆及本方案已產生的回覆。S1/S2兩角色可共用快取，其他方案回覆不得免費流入。

本次是完整原路徑產生後的離線計分，因此允許本次完整baseline快取，而非僅當輪以前的baseline。與先前逐輪可用快取成本口徑不同，不拿新數字覆蓋舊數字。原A的數值/接受/等距規則不變；計費統一使用精確float64鍵，保守不合併僅float32相同的點。局部分支按輪、原參與者順序；S1/S2先錨點、再模型；決策端點鎖定後立即補齊共同完整面板評分。S4依原參與者順序從原始起點重跑，決策時排除模型，結束才補查共同面板；包含補查成本。

一個評分樣本＝一模型對一位置推論。分開列baseline、分支/共同評分新增、快取命中、總樣本與時間。主成本是實際部署單次，不混入驗證/暖機/重複計時的研究成本。固定每團隊一個暖機＋三次交錯輪換順序量測，報三次中位數、每團隊總時間比；所有方案使用同一凍結模型、單執行緒、本機CPU。模型載入/檔案輸出不計入部署核心時間，模型推論及方向/縮步/計分包含。保留完整baseline與分支結果核對，不能將小型本機時間外推遠端API。

預算：最多120萬次實際本機模型推論、900秒；資料/模型重載驗證最多10萬次、300秒。既有pooled讀值0新增pooled推論；truth不載入。若任一端點/分數與凍結來源不一致、來源hash變更、缺失未正確保留或超預算，停止並保存失敗，不修改公式追分。
