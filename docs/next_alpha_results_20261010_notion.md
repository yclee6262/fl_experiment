# 本輪結論

完成30個獨立seeds、三情境、五方法，共450條件。18項候選對A/B的確認比較中，有1項符合預登錄穩定優勢規則。品質改善與成本分開判讀；未建立優勢不等於證明等效。

本輪唯一符合校正判準的是既有品質留出收縮在乾淨情境對A（差值−0.00285759，同時CI −0.00652689～−0.00023589）；對B未建立優勢。兩個新增方法共12項確認比較均未建立穩定優勢。保守品質在樣本量不平衡具有較低觀察平均、最佳組合在低品質具有較低觀察平均，但不能把它們稱為已驗證優勝方法。

# 實驗目的與控制

回答最佳組合或保守風險權重是否改善最終倒推X。target固定0、二維、固定三人coalition，單次倒推，沒有α更新、pruning或付款。五方法共用同seed資料、模型、proposal、20筆資格資料與凍結評估者。

Pilot使用歷史4400–4404模型，只檢查實作，不併入正式。正式seeds4600–4629，啟動前查核313 manifests無重疊。N固定30，未宣稱保證檢定力；不得根據本輪正式pooled結果調參。

# 五種方法的具體定義

**A：均勻。**三人各1/3，資訊不足時的低成本基準。

**B：品質反比。**每人的20筆平均平方誤差MSE加0.00001後取倒數，再正規化到總和1。例MSE為0.01、0.02、0.04，權重約0.571、0.286、0.143。

**現有品質留出收縮。**共同抽樣資格資料的列1000次；每次用抽中的列算B式品質權重q，只用未抽中的列選λ，使混合預測MSE最小。權重為(1−λ)q＋λUniform；平均有效輪次。λ表示均勻比例，λ1為全均勻；OOB少於2筆則跳過。

**最佳組合留出收縮。**共同抽樣1000次；在抽中的列，以SLSQP找非負、總和1的w，使混合預測Pw對標籤y的MSE最低。再用未抽中的列決定向Uniform收縮的λ，最後平均。與前一方法差別是in-bag權重由整體混合預測最佳化產生。例兩模型固定高估1與低估1，各0.5可相互抵銷；個別MSE看不出這種互補。求解失敗該輪使用Uniform並記錄，非靜默刪除。

**保守品質。**共同重抽樣1000次，得到每人的MSE分布；取第90百分位數，加0.00001後倒數正規化。若某人平均準確但重抽樣時常很差，高分位誤差會增加而權重下降。例風險MSE0.01、0.04、0.09，權重約0.735、0.184、0.082。第90百分位是固定風險規則，不是90%信賴上界。

上述是資訊可信度與互補性的經濟直覺，不是付款、公平或完整參與者貢獻證明。組合MSE最小也不保證倒推品質最好：Stage3使用各local模型目標絕對誤差的加權和，與混合預測MSE不同。

# 下載數據與欄位解釋

隨附精簡CSV保存全部450條件，沒有只挑成功案例。完整含每輪bootstrap與solver細節的原始資料留在本地results.csv與results.jsonl。

**scenario／seed／method**：情境、獨立隨機seed與初始化方法；三者識別一次條件。本輪draw=-1代表沿用原資格盲測，blind_n=20、target=0。

**status／X／max_box_violation**：執行及交付狀態、二維交付參數、超出box的最大距離；有效解必須有限且違規量不超過1e−8。無解時X與品質留空；不能把失敗誤差填零。

**alpha**：按participant IDs1、2、20依序列出的非負權重，總和1；不是付款比例。mse是這三人的20筆資格資料MSE。

**pooled_error／truth_error**：交付X的兩種目標絕對誤差，越低越好；pooled為主要判準，truth僅診斷。

**initialization_seconds／stage3_seconds／scoring_seconds**：初始化、本次求解、事後外部評分的秒數。不得把外部評分計為Stage3；時間不要求重播一致。

**initialization_requests／stage3_requests**：各階段local API呼叫數，批次呼叫一次仍只計一次；input_samples另外計輸入點數。資格預測共用，因此cache路徑初始化API為零，不代表本地計算成本為零。

**lambda_mean**：各有效OOB輪次向均勻收縮的平均比例；只適用收縮方法。risk_mse為保守方法的bootstrap MSE第90百分位。combination_solver_fallbacks為最佳組合求解失敗後使用Uniform的輪次數，與最終交付失敗不同。

**平均／中位／Q1／Q3**：有效交付誤差的平均、50%、25%、75%分位。失敗比例包含全部執行；不能以有效品質掩蓋失敗。

**配對差／有效n／95%CI／同時CI／衝突**：同seed候選減基準的pooled差、雙方有效seed數、一般區間、多重比較校正區間、pooled/truth方向不同的seed數。CI跨零表示證據不足，並非證明兩方法相同。
