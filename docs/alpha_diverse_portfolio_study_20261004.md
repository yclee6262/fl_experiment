# 多樣化四候選初始 α：資訊分散與查詢成本研究紀錄

## 方法定義與經濟問題

原五候選方法各以 A（Uniform）、B（Stage 0 盲測品質）、MSE power 1.5、Corr precision 0.5、Target-local precision 求解一次 Stage 3，再用同一 B 權重 ridge 偏差校正分數選一個交付 X。固定刪掉 Target-local 的四候選雖省 20.08% 模型請求，但在全新 120-seed 比較中，pooled 品質差的 95% 區間上限 +0.000721，超過事前 +0.0005 研究容忍度，故沒有通過。

本輪保留四次 Stage 3 的成本目標，但**不固定省略哪個 α**。在倒推前，先只用 Stage 0 盲測資料、local models 及 Stage 2 proposals 算出五組初始 α。A、B 必留；在 MSE power、Corr precision、Target-local 三組中選兩組，使四組 α 的六個兩兩 L1 距離總和最大。相同分數以固定候選順序決定。這是資訊配置的分散投資概念：同樣四次求解，盡量覆蓋不同權重組合，以減少付費查詢重複資訊的風險。**α 距離大不保證交付 X 品質更好**，因此仍需外部 pooled 檢驗。

選好四組後，只對它們做 Stage 3；校正及選解公式與原五候選一致。最終 α 就是被選中 X 的那組。候選組合的決策絕不讀 pooled／truth 分數。單獨執行成本必須計入**全部五組 α 的初始化計算**、選組合本地時間、選中四組的 Stage 3、校正與候選評分；省略者不做 Stage 3。配對研究仍為五候選對照額外跑第五次 Stage 3，整批共用準備成本另記。

## 開發與流程 pilot

在已用過的 seeds 500–529、600–659、700–759、800–859、900–1019（合計 330）離線篩選固定及 α 多樣性組合。此方案的描述性 pooled 差（新減原五候選）平均約 +0.000081，95% 區間上限約 +0.000345；估計每條件少約 369 次請求，未計動態選法必須先算全五組 α 的少量額外成本。這些 seeds 曾用於選法，**不得當成獨立非劣證據**。

5-seed pilot（seeds 0–4）20／20 摘要條件有效，10／10 次多起點選擇重算通過。A、B、原五候選的 X／α／pooled 分數與舊 pilot 完全一致；多樣化四候選／原五候選平均 pooled 誤差 0.013377／0.014757，方法請求 1639.8／2031.0。pilot 只驗收資料流、動態候選順序與包括省略者初始化的成本。81 項回歸測試通過。

## 事前登錄與正式規則

正式執行前以 `docs/alpha_diverse_portfolio_formal_preregistration_20261004.json` 封存方法與全新 seeds 1100–1279，共 180 個配對。固定乾淨二維、target 0、參與者 IDs 1／2／20、box `[-1,1]`。主要差 `E_diverse-E_five` 用 seed 為重抽樣單位、固定 RNG 10,000 次 bootstrap。成本／品質門檻為：180 個有效配對、雙側 95% 區間上限小於 +0.0005、平均模型請求至少少 15%、無更多失敗；區間上限小於 0 才另稱嚴格品質改善。

`0.0005` 是事前研究容忍度，約為開發基準誤差的 3%，並非經應用場域驗證的業務容忍度。若有平均品質損失，仍須報告它相對節省請求的損益平衡比；沒有實際請求價格與誤差價值時，不宣稱普遍貨幣淨收益。只有基本情境通過上述成本／品質門檻，才擴到複雜情境驗證可移植性。

正式結果目錄：`alpha_weight_outputs/alpha_diverse_portfolio_formal_v1_20261004/`。

## 180-seed 正式結果與決策

seeds 1100–1279 共 720／720 條摘要條件完整；兩方法各 180／180 個有效交付解。保存模型、盲測資料與候選 X 重載後，360／360 次選解重算通過，包含動態四候選名單和成本；15／15 個事前登錄來源 SHA-256 相符。81 項回歸測試通過。

新法平均少 **370.733 次模型請求／條件**，請求減少 **19.705%**；本機方法內平均時間少約 0.02257 秒。若每次請求成本 `c`、每降低一單位 pooled 誤差的價值 `v`，只看這批平均差的損益平衡比約 `c/v > 6.19×10^-7`；沒有實際價格與誤差價值時，不能宣稱普遍淨收益。

**事前成本／品質門檻未通過**：配對區間上限 +0.000800 超出 +0.0005 研究容忍度，嚴格 pooled 品質改善也未建立。雖有查詢節省，仍不能說品質損失已被限制在事前容忍度內。原五候選維持主方案，不依這批結果放寬門檻，也不啟動複雜情境比較。
