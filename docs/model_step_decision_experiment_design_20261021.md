# 當輪模型決策貢獻：實驗設計 v1

日期：2026-10-21。狀態：**設計完成，未實作、未執行、未建立有效性**。使用者本輪授權為依目前定義設計實驗；本文件不是執行授權或正式確認結果。執行前須凍結來源、案例、程式及本文件的 hash。

## 1. 問題與研究邊界

核心問題：在原搜尋的同一個輪前狀態，模型 i 參與評分，是否讓當輪決策的結果更好？決策包含方向形成、試走、縮步、接受或不更新。

這是原完整團隊軌跡上的條件性、單輪模型角色干預。不是從頭移除參與者、不是重新訓練、不是最優解價值，也不是低成本估計器。先建立可核對的局部 LOO 基準，再研究是否能用正常搜尋統計近似。錨點方法維持目前版本，模型與錨點分數分開。

本輪不乘 q、不改 alpha 初始化或更新、不刪人、不付款、不研究 Shapley、不改歷史 solver 或結果、不修改 Notion。pooled 僅在分數與分支結果鎖定後作離線品質驗證；truth 不載入。

## 2. 唯一主定義

原完整團隊固定內部目標：

\[
\ell_j(x)=|f_j(x)-T|,\qquad L_{ref}(x)=\sum_j\alpha_j\ell_j(x).
\]

模型排除分支的決策目標：

\[
L_{-i}(x)=\sum_{j\ne i}\frac{\alpha_j}{1-\alpha_i}\ell_j(x).
\]

所有錨點 I、原錨點方向權重 a、位置 x_t、輪次索引、模式、輪前 eta、delta、邊界規則與最多十次退火嘗試皆相同。僅模型評分面板及其歸一化權重改變；a 不因移除模型而變動。原本 a=alpha 不代表模型排除後應讓 a 跟著改。

兩邊各執行**一次原 solver 外層迭代**：完整分支得 x_full，移除模型 i 分支得 x_minus_i；沒有接受更新則結果為 x_t。各自按其決策目標形成方向、縮步、接受，不強迫排除分支使用原接受距離或原方向，也不使用 L_ref 作排除分支的二次接受篩選。

\[
m_{i,t}=L_{ref}(x_{minus\ i})-L_{ref}(x_{full}).
\]

正值＝模型參與後當輪結果較符合固定完整團隊目標；負值＝該輪排除結果較符合該目標。完整分支不動、排除分支接受一個 L_ref 更差的點時，m 可為正，能記錄阻止壞步的價值。雙方不動則局部結果差為零，但仍保存其模式／eta／停止狀態差；零分不等於沒有未來資訊價值。

不將排除分支納入後續主路徑。下一輪仍來自完整團隊原路徑。每輪模型分數不要求加總等於改善；跨輪保存 S_i=sum_t m_i,t、正／負累積與覆蓋率，但僅稱「累積當輪決策差」，不稱最終品質貢獻。本輪不作短續跑或全程新 LOO。

教學驗收例：完整結果共同 loss=0.40，排除結果=0.46，m=+0.06；排除結果=0.35，m=-0.05。完整不動共同 loss=0.50，排除分支按自身目標接受但共同 loss=0.55，m=+0.05；不可把排除結果用完整 loss 拒絕後改成零。

## 3. 輪次、狀態與重用限制

納入 baseline 真正進入的全部外層迭代：已接受、十次試走皆失敗、secant 切 dynamic、dynamic 失敗停止、零方向停止。停止後不虛構額外輪次。secant 失敗只記模式切換，不在同一研究輪中額外跑 dynamic。不能僅抽原接受步；那會漏掉阻止更新的價值。

完整重播保持全部原始狀態。排除分支複製輪前幾何／控制狀態，並重算 L_minus_i(x_t)、所有 anchor_losses；best_loss 必須對應新目標。將分支 global_best 初始化為 x_t 及該分支 loss，診斷 history/states 從當輪起點另建，不把原目標的歷史 loss 搬進新目標。此分支定義是局部重新決策，不是宣稱「模型從歷史第一輪就不存在」。輸出使用當輪結束的 S_current，不把求解器最終 global_best 回傳值誤當輪末位置。

現有 state_engine 可借鏡 AST 狀態紀錄與逐輪重播，但不能原封不動套用：它的 relocate 只處理原接受步後的同目標接續，本研究需輪前分支、變更目標及所有停止情況。新增模組需顯式傳入模型權重與錨點權重。

快取只存原始模型回覆，以模型身份／hash、原始輸入及實際 API 輸入表示作核對；只有已證明相同輸入才能共用。相同點的既有全模型回覆可重組 L_minus_i；新點仍須查詢。被排除模型在分支決策階段不被呼叫；結果鎖定後為共同評分補查其回覆，分開記成本，回覆不得回流改決策。完整分支共享一次，非每位模型各重跑一次。

## 4. 研究問題與比較

RQ1（主）：固定完整團隊內部評分下，單輪模型排除能否被正確重播、產生可辨識的決策差？報同位置比例、分數範圍、正負零、接受／不接受轉移、角度／距離／試走次數變化。變化是描述，不視為貢獻越大越好。

RQ2（效度）：這些內部決策差，是否與獨立的離線品質差一致？鎖定後計算 e_i,t=E(x_minus_i)-E(x_full)，E 沿用原凍結 pooled 誤差定義與 target。不得讓 E 選點、接受、選公式、決定刪人或修正 m。

另以原始回覆作精確分解：

\[
m_{i,t}=\alpha_i[\ell_i(x_{minus\ i})-\ell_i(x_{full})]
 +(1-\alpha_i)[L_{-i}(x_{minus\ i})-L_{-i}(x_{full})].
\]

分別揭露「自身評分項」與「其他模型評分項」及兩項異號比例，診斷共同尺包含自身意見的問題。這不是獨立真值，也不把去自身項事後替換成主分數。若只內部支持而外部不支持，結論限於內部團隊偏好。

RQ3（成本）：比較完整搜尋、逐輪模型排除加共同評分、離線驗證各自模型 calls／samples／unique points／wall time／儲存。歷史同設定全程 model-only LOO 若 hash、模型、起點與預算完全匹配，可列既有成本帳；不宣稱它與局部 LOO 估計同一對象，也不在本輪新增全程移除。

舊 B、qB 與純 q 可用既有回覆／資格紀錄作固定次要對照。舊 B 僅對有接受步定義，與 m 比較須限定共同可比輪並報分母；不得把缺失補零。舊方向分數對新的局部 m 之相關，最多表示近似局部基準，不證明外部品質或撤銷舊失敗。

## 6. 固定指標與驗收／停止條件

技術硬門檻：baseline 逐輪位置、模式、eta、試走／接受／停止分支與 API 查詢順序一致；有記錄與無記錄的 baseline samples/calls 相同。分數與 loss 獨立重建誤差 <=1e-10*max(1,abs(reference))；模型回覆另報 dtype 差異，不能事後放寬容差。錨點／方向權重在模型排除前後相同。pooled／truth 污染、狀態混用、歷史 hash 變動，任一發生停止，修復後另存版本與重跑紀錄。

覆蓋：報每團隊應有／完成／失敗／不可定義輪×模型數，不排除近零或無接受團隊。資源上限造成未完工不得稱完整結果。缺失不填零；S_i 有任何必要輪缺失即不提供完整總分，另留 partial。無輪次不記為全員零貢獻；alpha_i=1 或無剩餘有效權重為未定義。alpha_i=0 應為同決策零差的技術對照。

主外部診斷固定兩項，兩情境分開：

- 排名：每輪跨模型 Spearman(m,e)，要求至少3個可比模型、m及e各自range>1e-4；先在團隊內平均有效輪，再在10個團隊間平均，避免長軌跡支配。每情境至少8/10團隊有有效排名，且報全體可評輪覆蓋比例；可評排名輪少於全部輪50%時不作廣泛排名主張。
- 符號：對abs(m)>1e-4者，e同號且abs(e)>1e-4才算一致；e近零算未支持，不算成功。團隊內比例再平均。至少8/10團隊有明確內部分數；abs(m)<=1e-4的覆蓋與其外部差另報，不能當正確零分。

進一步外部確認的探索門檻：每情境平均排名 >=0.5 且區間下界>0；符號一致率 >=0.70 且區間下界>0.50；並符合上述覆蓋。按 seed 分群 bootstrap 10000次、RNG 20261021，四項主比較用98.75%區間；兩情境若彙整比較須按共同 seed 配對重抽，禁止將輪或個人當獨立樣本。這是研究者事前規約，不是老師指定或普遍效度定理。

分支事件（兩者接受、僅完整接受、僅排除接受、皆不接受）與 secant/dynamic 分層只作描述。若某事件少於3個團隊或20個可比角色輪，不宣稱該類價值已獲驗證。全輪 S_i 對 sum_t e_i,t 僅描述，兩者都沿原路徑，不是全程移除效果。

任一主要門檻不過，停止相應的外部效度／泛化主張，交付負面結果；不翻號、改q、挑輪、改死區、加seed追結果。技術可通過而效果失敗；內部差仍可作定義清楚的局部基準，但不能稱已驗證外部貢獻。

## 7. 成本規劃與資源上限

理論成本：m個模型、T輪、K個錨點。secant錨點與目前位置回覆可共用；每個移除分支最多十個試走點，dynamic另有最多K個探測點。保守分支決策樣本上界約 T*m*(m-1)*(K+10)，不含初始化／共同評分／驗證，也未扣快取；這是計數量級，非保證耗時。一般可能比全程模型LOO更貴，不能預設省成本。

本輪建議硬上限（尚未實測）：pilot 新增模型 input_samples<=100000、模型相關 wall time<=180秒；開發上限<=500000 samples、900秒。pilot完成後，用最大每團隊每模型角色成本×80角色×4安全餘裕，與500000取較小值，凍結開發 samples預算；時間同樣估算與900秒取較小值。不看效果決定預算。若pilot估計無法完成固定樣本，就停止並報資源不足，不自行抽掉輪次。

獨立 verifier 另設<=600000新模型samples、1800秒；本輪全階段新模型samples總上限1200000、總模型相關時間2880秒。pooled原評及獨立重評合計最多7000個unique-point evaluations，單列耗時、不可混成部署成本。預算檢查在每次模型呼叫前及階段間執行；模型單次卡住需有外層超時中止並保存失敗。

成本帳分六項：baseline、排除分支決策、共同尺補查、分數運算與儲存、pooled、獨立核對。另記邏輯評分請求與真正模型呼叫、快取命中率；同一點重複請求不冒稱新模型呼叫。研究總成本和未來單次使用成本分開。

本階段沒有「必須比全程LOO便宜」的有效性門檻；此方法是基準。若較貴，直接報比值，保留日後近似的成本目標，不因成本低就宣稱品質有效。
