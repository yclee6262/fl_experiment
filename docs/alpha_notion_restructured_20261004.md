> **閱讀摘要｜更新至 2026-10-04**　目前在乾淨、二維、三人、target 0 的合成情境，原「五候選校正式多起點」在獨立 60-seed 複驗中，交付 X 的 pooled 誤差同時低於 Uniform（A）及 Stage 0 品質權重（B）；代價是模型請求約為 B 的 5.22 倍。新增六候選在全新 60-seed 正式比較中**未穩定勝過五候選**，七候選的平均 pooled 誤差更高；因此尚不擴到複雜情境。所有結論只針對已測條件，尚未證明淨貨幣收益。

## 1｜研究問題與判讀順序
本頁研究的是：**倒推開始前如何設定 α，讓交付解 X 的品質更好，且增加的計算成本有合理解釋？** α 是 Stage 3 對 local models 的資訊權重；不是參與者報價、貢獻 q、付款比例或實際交易份額。

主要指標為 `E_pool(X) = abs(f_pool(X) - target)`，越小越好。pooled evaluator 是用乾淨資料集中訓練、凍結後用來事後評分的研究模型。合成真實函數誤差 `E_true(X)` 只作交叉診斷。兩者都**不參與 α 計算、候選 X 選擇或方法調參**；若逐 seed 的方法排序衝突，會另行揭露。先讀有效交付率與限制，再看 pooled 品質，最後看請求量及耗時。α–q 接近不是本頁的成功標準。

## 2｜共用設定與記號
- **基本確認情境**：三位固定參與者 IDs 1、2、20；二維；target 0；X 每個座標限制 `[-1, 1]`，可行性容差 `1e-8`。同 seed 的各方法共用資料、local models、Stage 2 proposals 及同一凍結 pooled evaluator；只改初始 α／候選選擇流程。不更新 α、不 pruning、不結算。
- **事前資訊**：Stage 0 有 20 筆帶標記的盲測點 `(x_j, y_j)`；`f_i(x)` 是第 i 位參與者的 local model 預測；`MSE_i = mean_j((f_i(x_j)-y_j)^2)`。`norm(s)` 表示非負分數除以總和；以下 `eps = 1e-5`。若資料或數值不合法，實作會記錄 fallback 原因，不能把 fallback 當作原公式奏效。
- **配對比較**：同一 seed 比兩法的 pooled 誤差差，新法減基準；負值表示新法較好。信賴區間以 seed 為重抽樣單位，不能把同 seed 的多個候選 X 當獨立樣本。

## 3｜一次倒推的 α 公式
下表每列代表一組**事前初始權重**；單次方法只做一次 Stage 3。公式中的權重依固定 agent ID 順序儲存，均非負且和為 1。

### A｜Uniform
**公式**：`α_i = 1/n`，三人各 1/3。
**意義與限制**：平均使用各提供者資訊，是低成本基準。
### B｜Stage 0 品質權重
**公式**：`α = norm(1/(MSE_i+eps))`。
**意義與限制**：盲測預測越準，給越高資訊權重；不涉及付款。
### Quality shrink
**公式**：`α = 0.5 A + 0.5 B`。
**意義與限制**：保留分散程度，減少小盲測集造成的權重過度集中。
### Ensemble shrink
**公式**：先在盲測點求非負、和為 1 且集成 MSE 最小的 `w`；`α = 0.5 A + 0.5 w`。
**意義與限制**：看模型組合能否互補；20 筆資料可能過擬合。
### Target-peer shrink
**公式**：其他 local models 對第 i 人有效 proposal 的 `abs(預測-target)` 取中位數 `m_i`；以全部 peer 誤差中位數加 eps 為尺度 `t`；`s_i = B_i exp(-m_i/t)`，`α = 0.5 A + 0.5 norm(s)`。
**意義與限制**：同時考慮既有品質與其他模型對 proposal 的支持；共同偏差會誤導。
### Target-local precision
**公式**：`K_j = exp(-abs(y_j-target)/0.5)`；`L_i = (sum K_j (f_i(x_j)-y_j)^2 + 5 MSE_i)/(sum K_j+5)`；`α = norm(1/(L_i+eps))`。
**意義與限制**：加重目標附近的誤差，同時用 5 筆等效全域 MSE 防止局部樣本太少。
### MSE power 1.5
**公式**：`α = norm((MSE_i+eps)^(-1.5))`。
**意義與限制**：比 B 更集中於盲測最佳模型；過度集中可能有害。
### Corr precision 0.5
**公式**：令殘差矩陣 `R[j,i]=f_i(x_j)-y_j`，`M=0.5 diag(MSE_i+eps)+0.5 RᵀR/20`；在 `α_i≥0、sum α_i=1` 下最小化 `αᵀMα`。
**意義與限制**：減少重複錯誤資訊；`RᵀR` 是含有號偏差的殘差二階矩，並非中心化相關係數。
### Best-agent｜專家選擇權
**公式**：令 `i*=argmin_i MSE_i`，`α_i*=1`，其餘為 0；MSE 相同時依固定 agent 順序選第一位。
**意義與限制**：測試集中使用盲測最佳提供者的資訊是否有價值；只是新增可選解，不保證交付其結果。
### Local-bias-risk｜局部偏差風險
**公式**：對各人有號殘差 `f_i(x_j)-y_j` 用 `[1,x_j]` 做 ridge 回歸，截距／座標懲罰 0.01／1；於 proposals 平均位置 `c` 預測偏差 `b_i`，以回歸後殘差平方平均為 `v_i`；`α=norm(1/(b_i²+v_i+eps))`。
**意義與限制**：以預期區域的偏差平方加剩餘風險作資訊權重；依賴局部線性與 proposal 中心代表性的假設。

這些是**資訊加權假說**，不是已證明的成本分攤、誘因相容或分潤公平規則。Best-agent 與 Local-bias-risk 使用既有盲測資料；後者仍增加本地模型預測請求，成本會入帳。

## 4｜多起點如何從 α 交付一個 X
1. **五候選（現行對照）**：分別用 A、B、MSE power 1.5、Corr precision 0.5、Target-local precision 做 Stage 3，取得最多五個可行 X。
2. **六候選（本輪主要新法）**：在原五候選外加 Best-agent，一共最多六次 Stage 3。
3. **七候選（本輪探索）**：再加 Local-bias-risk，一共最多七次 Stage 3。
4. **三者共用、不能看 pooled 的選解規則**：以 B 權重集成 20 筆盲測預測，取有號殘差 `r_j=sum_i B_i f_i(x_j)-y_j`；把 r 對 `[1,x_j]` 做 ridge 回歸，截距／座標懲罰 0.01／1。每個有效候選 X 的內部分數為 `abs(sum_i B_i f_i(X) - ridge_bias(X) - target)`，選最小者交付。最終 α 是**被選中候選的那組 α**，不是各候選權重的平均。僅有限且符合 box 的候選可參加選擇。

每增加一個候選都會增加求解、預測與時間成本，三種流程按各自實際使用的候選與校正成本加總。pooled 與 truth 分數只在交付後記錄。對部分候選或 B 本身失敗時的完整 fallback，仍須單獨驗收。

## 5｜結果與證據等級
### 5.1 已完成的單次權重比較
- **舊五方法正式比較**：五情境 × 五方法 × 30 seeds，共 750／750 有效。乾淨情境平均 pooled 誤差：A 0.020415、B 0.017640、Quality shrink 0.018755、Ensemble shrink 0.019098、Target-peer shrink 0.018956。三個 shrink 法沒有建立對 A 的穩定優勢；這些平均值本身也不等於顯著性證明。
- **Target-local precision 獨立正式比較**：seeds 400–429 共 90／90 有效；平均 A 0.013299、B 0.013845、新法 0.015298。新法減 B 的配對差 +0.001453，95% 區間從 -0.001739 到 +0.004473；**不支持優於 B**。

### 5.2 原五候選校正式多起點
- **pilot，seeds 0–4**：平均 pooled 誤差（A／B／五候選）為 0.025947／0.030903／0.014757。15／15 摘要與 25／25 候選有效；只驗流程，不宣稱優勢。
- **首次正式，seeds 500–529**：平均 pooled 誤差（A／B／五候選）為 0.019111／0.018444／0.014730。90／90 有效、30／30 選擇可重算；對 A、B 的 97.5% 同時區間均跨零，**未達事前雙基準門檻**。
- **獨立複驗，seeds 600–659**：平均 pooled 誤差（A／B／五候選）為 0.016663／0.016652／0.013275。180／180 有效、60／60 選擇可重算；對 A、B 的 97.5% 同時區間均完全小於零，**此批通過事前門檻**。

首次正式五候選減 A：-0.004380，同時區間 -0.010167 到 +0.000494；減 B：-0.003714，區間 -0.008329 到 +0.000319。獨立複驗減 A：-0.003388，區間 -0.006443 到 -0.000491；減 B：-0.003377，區間 -0.006405 到 -0.000930。這些是同 seed 配對差的 10,000 次 bootstrap 區間；開發 seeds 不與正式 seeds 合併為單一檢定。

### 5.3 新六／七候選：開發、pilot、獨立正式
- **開發資料，不能作確認證據**：在已使用的 seeds 500–529 與 600–659 上，六候選相對五候選平均 pooled 差分別 -0.001768、-0.001054；七候選分別 -0.001468、-0.001636。Best-agent／Local-bias-risk 從多個試法中選出，以上數值有選法偏差。
- **流程 pilot，seeds 0–4**：25／25 摘要條件與 35／35 候選有效，五／六／七候選共 15／15 次選擇可重算；平均 pooled 誤差 0.014757／0.014757／0.013966。五個 seeds 無法證明品質優勢。
- **獨立正式，seeds 700–759**：事前固定六候選對五候選為**主要比較**；七候選僅為次要探索。300／300 條摘要條件有效，五／六／七候選各 60／60 個有效解，180／180 次選擇可由保存模型與盲測資料重算；14／14 個登錄來源雜湊相符。
- **主要結果，六候選減五候選**：平均 pooled 誤差 0.015081 減 0.015218，配對平均差 **-0.000137**；10,000 次 seed-bootstrap 95% 區間 **-0.001258 到 +0.001010**，跨零。60 seeds 中六候選較好 8、相同 49、較差 3；無較多失敗，但未通過事前的穩定改善門檻。
- **次要探索，七候選減五候選**：平均 pooled 誤差 0.016300，配對平均差 **+0.001082**；95% 區間 -0.000653 到 +0.002940。較好 14、相同 36、較差 10，沒有建立 pooled 品質改善。其平均 truth 誤差 0.012862，低於五候選的 0.013511，但 truth 只作診斷，不能據此改用七候選。逐 seed 的 pooled／truth 優劣方向衝突：六候選對五候選 3／60、七候選對五候選 7／60；主要判準仍為 pooled。

## 6｜成本與可主張的經濟意義
在五候選獨立 60-seed 複驗，平均 local model 請求 A 341.75、B 341.60、五候選 1782.45；平均方法內本機耗時 0.0136、0.0136、0.0728 秒。五候選約為 B 的 **5.22 倍請求**，平均多 1440.85 次請求，pooled 誤差平均少 0.003377。若每次模型請求成本為 `c`、每降低 0.001 誤差的價值為 `v`，只計這兩項的損益平衡為 `v > 426.65 c`。尚無實際 `c`、`v` 的貨幣資料，故不能說已證明淨收益。

新 pilot 的五／六／七候選平均方法模型請求為 2031.0／2248.8／2637.6；增加候選解有成本。時間是本地執行時間，不是網路服務的實際延遲；共用訓練、資格檢查、proposal、evaluator 建立另記，不能把它們重複加到各方法。

正式 seeds 700–759 的平均方法模型請求：五候選 1857.55、六候選 2141.00、七候選 2506.00；六候選平均多 **283.45 次**，七候選多 **648.45 次**。方法內本機平均耗時依序 0.1451、0.1624、0.1986 秒。六候選增加成本後未建立穩定 pooled 品質優勢；不能把少量平均改善寫成經濟上更划算。

六候選所測的是：付出額外一次求解，換取可選用盲測最佳「專家」解的權利；七候選再測依局部風險分配資訊權重。這是可解釋的**資訊取得與成本取捨**，尚非最適採購、誘因相容或公平分潤的證據。

## 7｜結果欄位與重評方式
- `summary.csv`：每列是一個 scenario × seed × method 的交付條件。`status` 記執行結果；`failure_stage`／`failure_reason` 記失敗環節；`delivery_status` 記是否取得有效交付解；`final_solution` 是交付 X，失敗時不可把空值當零。
- `candidate_rows.csv`：每 seed 的各組初始 α 單獨倒推結果。五／六／七候選摘要列各只交付一個 X，並計入該流程使用的所有候選成本；候選 pooled 分數只作事後診斷，不決定選擇。
- `agent_ids` 與 `initial_alpha`：兩個陣列按位置對應；`stage0_mse` 是各人的盲測均方誤差；`alpha_audit` 記公式中間值、fallback、各候選內部分數與實際選中的初始化。Best-agent 的 `winner_agent_id` 指盲測 MSE 最低者。
- `actual_solver`／`solver_status`：實際求解路徑與數值狀態；`final_box_feasible`／`max_box_violation`：交付 X 的 box 檢查。求解器回報成功不能代替可行性。
- `external_global_prediction`／`external_global_error`：pooled 對交付 X 的預測／主要絕對目標誤差；`final_target_error`：合成真實函數的診斷誤差。兩者都不回饋選解。
- `initialization_requests`／`stage3_requests` 與對應 `input_samples`、`seconds`：初始化／Stage 3 的請求次數、批次輸入點數與本機耗時；`external_scoring_seconds` 是事後評分時間，不可併入 Stage 3。`shared_costs.jsonl` 每 seed 記一次共同準備成本；`artifact_path` 指向可重載資料與模型。

原五候選獨立複驗的 180／180 解可重評，seed 600 隔離重播通過。pooled／truth 逐 seed 方法優劣相對 A、B 各有 13／60 衝突：這表示兩種評估來源對**哪種方法較好**看法相反，並非兩者預測值必須完全相同。複驗 target 附近測試點中位數 258.5、範圍 232–291；target-near truth MSE 中位數約 0.000101。這只描述合成資料的評估覆蓋，不保證真實應用可靠。

## 8｜版本、限制與下一步
**證據邊界**：本頁的確認結論只涵蓋指定乾淨合成情境。不能從此推論污染、高維、不同 coalition 或真實資料也會改善。此前曾探索品質次方、候選人數集中、殘差二階矩占比、target 距離與位置加權、局部偏差、內部校正變體；有些比較使用了 pooled 事後挑法或額外盲測點，均屬開發／oracle 診斷，不是本輪可交付方法。本輪六候選未過事前的基本情境門檻，**依原先規則不啟動複雜情境比較**；若要繼續找更好方法，須另訂方法與新 seeds，不能拿本批正式數值繼續挑參數後仍稱獨立驗證。

**封存注意**：五候選 60-seed 的舊 `suite_manifest.json/statistical_rule` 沿用「30 seed／95%」文字，實際 seeds 600–659、180 條件；通用 `analysis.json/formal_advantage` 不適用雙基準判定。複驗結論以事前登錄及 `decision.json` 的雙基準 97.5% 規則為準，原始封存不改寫。
