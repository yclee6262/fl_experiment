# 學長建議：截至2026-11-10仍待補齊的項目

依11/5審閱原文及11/9兩份三包結果整理。本次只核對與更新清單，沒有新實驗。

## 已測，應回覆結果而非列為從未驗證

自評三尺、完整LOO排名／符號／top-k、污染身份三池金額、CA/CM與J交互作用、方向單位化、固定身份起點敏感度、固定alpha敏感度、複製身份獲利、數值門檻／池額敏感度、5–50%均勻抽查成本／分配誤差與常態CI，都已有結果。負面結果是對疑問的回答，不代表可採用。

## 真正仍缺

1. 六一4：可部署資訊下的重複度篩選。要實作錨點＋模型輸出相似度規則，測完全複製、近似複製與相似但有用的誠實參與者；報實體總收入、誤刪與結果品質。程式核對澄清：senior_remaining_v1/analyze.py的restored是直接載入原團隊再跑，並沒有從新增身份團隊執行去重偵測。故「collapse_exact」只支持原團隊重播，不能作去重演算法通過證據；複製身份獲利結果不受此澄清影響。
2. 六三5：重要回合抽查。已做均勻Bernoulli，未做依既有資訊配置不同抽中機率的版本。固定同預算比較誤差、排名、份額及實際呼叫。尚未證實精確的殘差維持正包含機率；方向近似相同不足以把抽中機率設0。改善量小不保證負貢獻絕對值小，不能直接作雙側界。
3. 六一3、6：可信CI與統計門檻。目前常態CI未達名目覆蓋，尚未建立可據以扣基本費或設定tauA的有效區間。改抽查設計／區間方法後，需測覆蓋、寬度、錯扣、漏扣與保留款；近零數值測試不替代此驗證。
4. 六一6、六二7：採用標準與制度規則。需固定評分尺、逐輪角色作用的研究主張、三池比例、付款資格、門檻及未分配款用途。老師認可的採用標準尚未確認；本次探索門檻不是老師同意的標準。新規則以反例回歸檢查自評、污染付款、分身及不穩定問題。
5. 六一5：N僅在恢復主分配時補驗證。常數／尺度敏感度、只累計該輪正C的N，以及改目標或離線外部評估下的增量價值。現在暫不採用N即可回覆，不需為收尾重開。

新模型／新任務確認屬對外泛化主張所需的延伸，不能冒稱學長每項都直接要求；現有4隊開發＋16隊評估均曾參與歷史研究，不構成全新獨立確認。規則固定後再做，避免反覆使用同批結果調整規則。

## 建議順序

先把已測結果及採用定義提交學長討論。若續做其尚未落地的具體建議，優先重複度篩選；成本研究則將重要回合抽查與有效CI合為一包。先約定可接受的錯分與成本，再鎖規則做獨立確認。原搜尋改良與新品質估計器維持暫緩。
