# 候選點同儕支持度作為 α 初始化：實驗計畫

日期：2026-10-13。狀態：實作、小型驗收與三批正式比較已完成。此文件保留事前設計，結果見 docs/peer_support_results_20261013_notion.md；正式 V2 登錄與來源未依結果改動。沿用既有研究主線，pooled evaluator 僅作交付後主要品質評估。

## 1. 要回答的問題

讓其他模型支持的候選點提出者獲得較高 α，是否改善最終倒推 X？支持度衡量「其他 local models 對提出者候選點接近目標的認同」，不是提出者模型的真實準確度、完整參與者貢獻或付款權利。

既有 target_peer_shrink 已測過品質反比 × 同儕支持，再向均勻收縮一半；本輪不是重新命名既有方法，而是增加純支持度對照及品質收縮對照，拆解效果來源。

## 2. 共用支持訊號

N 個已通過共同資格且有合法 proposal 的參與者，每人一個候選點 X_i。建立 P[j,i]=f_j(X_i)，即模型 j 對提出者 i 候選點的預測。資料表的列是評估模型，欄是候選點提出者。自己的預測不納入支持計算，但可以保存作診斷。

對每個 i，計算其他模型的絕對目標差距：d[j,i]=abs(P[j,i]-target)，j 不等於 i。

e_i=median_j(d[j,i])；共同尺度 τ=median_{j≠i}(d[j,i])+1e-5。

s_i=exp(-e_i/τ)/sum_k exp(-e_k/τ)。誤差越小、支持越高；同一案例的所有提出者使用相同尺度。實作使用等價的穩定指數正規化以避免下溢。模型作為評估者時等權，不另以 B 加權，避免本輪同時改動多種機制。

3 人時，每人只有兩個外部評估者，中位數等於兩者平均，沒有「多數穩健」保證。所有模型也可能有共同偏差。候選點重複時如實保留；這不代表獨立資訊增加；排除自身模型後評估者組合不同，重複候選的支持度也可能不同。

## 3. 固定方法與目的

| 方法 | α 定義 | 比較用途 |
|---|---|---|
| A：均勻 | U_i=1/N | 支持訊號是否比不區分提出者好 |
| B：品質反比 | 原 20 筆 MSE 加 1e-5，倒數正規化 | 是否比既有品質方法好 |
| Q：品質向均勻收縮 | 0.5U+0.5B | 排除收縮本身改善的混雜 |
| S：支持度向均勻收縮 | 0.5U+0.5s | 單獨測支持訊號；支持越高者 α 越高 |
| QS：品質乘支持後收縮 | 0.5U+0.5 normalize(B_i×s_i) | 既有 target_peer_shrink；品質與候選支持合用 |
| E：最佳組合向均勻收縮 | 原 20 筆混合預測 MSE 最佳組合 w，0.5U+0.5w | 原資訊方法中上輪平均最佳的較強對照 |

所有收縮比例固定 0.5，沿用既有設定；本輪不搜尋比例、不挑 τ、不改 solver、不動態更新、不剪枝、不付款。QS 同時受 B 影響，支持較高不一定有更高最終 α；只有 S 明確保持這個排序。

核心機制比較：S−A 判斷支持本身是否有用；QS−Q 判斷在相同品質與收縮設定下，加入支持是否有增益。不能僅用 QS−B 的改善歸因於支持，因為收縮也改變了。

## 4. 情境與固定條件

第一輪三情境：乾淨、低品質（沿用 low_quality_25pct 設定）、樣本量 4 倍不平衡，精確污染／樣本參數沿用通過驗收的三批 runner，寫入新 manifest。固定原三名 participant IDs、二維、target 0、box [-1,1]、可行性容差 1e-8、重載評分容差 1e-7、best_of/custom30 與共同候選搜尋空間。

同 seed 所有方法共用資料切分、local checkpoints、資格資料、proposal、內部 evaluator、起點／隨機設定及凍結 pooled evaluator。低品質只影響指定 local 觀測資料，不污染 pooled 評估者。所有方法使用同一個原研究 Stage 3 目標，只改 α。

不取得新增真實標記，不把 pooled 或 truth 分數輸入支持訊號、α 或選解。truth 僅交付後診斷。第一輪不增加 N；有支持訊號後另立 5 人情境驗證，避免把 N 與方法改動混在一起。

## 5. 計算與保存順序

1. 先完成共同資格及 proposal 檢查，再產生所有方法；保存未通過案例及原因。
2. 保存完整 N×N 預測矩陣、off-diagonal 目標差距、e、τ、s、B、每方法 α、agent 順序及 proposal。矩陣只算一次，但方法獨立成本與整批共享成本分開報告。
3. 各方法只倒推一次；記錄 solver 數值停止、交付狀態、accepted X、可行性、最大違規量。
4. 交付後才算 pooled_error=abs(f_pooled(X)-target)；無交付時留空，不傳空 X 給模型；同時保存 truth 診斷。
5. 保存標記取得量（本輪新增為 0）、模型 API 次數、模型輸入樣本數、支持計算／初始化／Stage 3／外部評分耗時。off-diagonal 計算需 N(N−1) 個預測值；若批次呼叫，API 次數與輸入點數不能混用。
6. 重載模型及矩陣重算 α、X 可行性及 pooled 分數；拒絕的候選不能覆蓋 accepted state。

## 6. Pilot 與正式確認

先用 5 組全新資料重複 × 3 情境 × 6 方法，共 90 條件檢查資料流及成本。seed 必須啟動前掃描既有 manifests，確認未用，不直接沿用先前確認資料。pilot 只修實作問題；如改公式或參數，另存版本。

驗收後固定公式、來源快照、成功規則及正式新資料集。正式樣本數在 pilot 後以配對差波動、事前指定的最小有意義改善與多重比較規模估算；不任意宣稱 30 次一定足夠。分三個預先固定的獨立批次，不因中途結果追加至顯著。pilot 不併入正式確認。

## 7. 主指標、失敗與統計

主要終點：同一資料重複中，三情境 pooled 絕對誤差的等權平均。以 seed 為抽樣單位，三情境保持同組；不是三倍獨立樣本。

事前定義研究母體為三情境均通過共同資格及合法 proposal 的案例。共同前置資格失敗列仍保存，分情境報告發生率，不補抽以掩蓋失敗，也不稱為整個招募流程成功。若要主張全流程優勢，須另設適合失敗輸出的效用指標，此輪不任意填失敗誤差。

在共同合格案例上，任何方法求解失敗都保留；主要品質僅在配對雙方有效時可算，但正式品質優勢要求該比較的共同合格計畫案例全部有效，且沒有較高觀察失敗率。若不符合，輸出條件品質診斷與失敗率，禁止升格成正式穩定優勢。不把「未觀察到失敗增加」說成已證明失敗風險相等。

事前固定主要確認家族 7 組：S 與 QS 分別對 A、B、E（6 組），加 QS−Q（1 組）。使用配對平均差 Δ=E_method−E_baseline、配對 bootstrap 與 Bonferroni 同時區間；一般 95% 區間輔助呈現。重抽樣次數於登錄時依所需尾部分位解析度固定。各情境先作探索診斷，不從某一顯著情境擴張成整體勝出。

穩定優勢規則沿用：同時區間完全小於零、三批平均差全負、至少兩批一般 95% 區間全負、完整合格案例有效配對、未增加觀察失敗數，並通過重載／可行性驗收。勝過 A 是支持訊號有用的證據；要稱比目前候選更好，還須對 B、E 通過。QS 要主張支持有額外價值，另須對 Q 通過。

事前合理改善門檻未定時，報告連續差值，不宣稱有實用或經濟最適優勢；α 為最佳化權重，不是分潤。

## 8. 事後解釋與驗收

解釋圖：支持 s_i 與提出者候選點的 pooled_error 關係、α 改變與最終 pooled 差值、QS／Q 配對結果、三批比較、失敗與極端惡化案例。候選點 pooled 分數只為事後診斷，不回饋 α，也不當成參與者貢獻。

必要測試：排除自己評分、模型與提出者順序對齊、提高支持且其他值固定時 S 的 α 增加、α 非負且總和 1、所有外部預測等於目標時 s 均勻、無效預測明確失敗而非靜默減少評估者、N=1 明確不適用同儕訊號、重複／邊界 proposal、缺 seed／重複鍵、solver failure 保存、來源與模型重載、pooled 不進入初始化。

單人同儕訊號不適用；第一輪固定三人且資格／proposal／交叉預測不完整時保存共同準備失敗，不靜默替換 agent 或改 coalition。單人或回退政策若要部署，另行登錄，不混入首輪效果比較。

判讀：S 改善但 QS 不改善，可能表示原品質乘法抵銷支持；QS 比 B 好但不比 Q 好，不能證明支持的額外作用；支持與候選 pooled 品質相關但最終 X 不改善，表示訊號可能較適合候選選擇而非 α；均未建立優勢則完整保留負面結果，回到其他候選，不反覆調至顯著。
