# 求解過程梯度作用：第一輪固定設計

日期：2026-10-18。使用者授權實作第一條「求解過程貢獻分解」並比較LOO。本文件於本輪分數計算前建立；來源及文件隨準備程序凍結。這是新探索，不回填P3或先前研究，也不是老師已認可的方法。

## 定義與不能混淆的問題

本輪不從歷史標籤學規則。對正常完整團隊被選引擎的已接受路徑 x_0,...,x_T，固定 ell_i(x)=|f_i(x)-target|，原始alpha不變：

`A_i = -alpha_i * sum_t grad ell_i(x_t) dot (x_(t+1)-x_t)`。

A正值表示實際移動方向在局部有助降低該人的加權目標，負值表示相反。這是路徑上的「目標改善作用分帳」，不是證明此人造成該步移動。兩引擎的路徑只取既有best_of選中的引擎；引擎選擇本身、候選資訊與未走路徑的價值不被分解。

重要解析限制：若沿每一線段精確積分，梯度功會望遠鏡相消成 `B_i=alpha_i*(ell_i(x_0)-ell_i(x_T))`。B只是個人誤差改善的加權分帳，不因寫成梯度積分就成為移除反事實。本輪同時保存B作固定診斷，檢查局部有限差分／跨越ReLU或abs折點的影響；不依結果改選主要方法或補尺度校準。

LOO參考維持既有 `C_full,i=E_pooled(X_without_i)-E_pooled(X_full)`，包含候選、模型與alpha移除以及剩餘權重正規化。A與C不是同一估計對象；本輪檢驗A是否實用地反映C。原始差值／MAE是未校準數值落差，不能假定有無偏或因果意義。pooled不參與A、路徑或梯度。truth不作輸入。

## 實作與成本

現有AgentNode只提供預測API，並不提供梯度。使用黑箱有限差分，不讀模型參數求導：每個左端已接受狀態、每維固定h=0.001，x_plus/minus裁切到box[-1,1]，梯度為 `(ell(x_plus)-ell(x_minus))/(x_plus-x_minus)`。target=0，float32模型輸入。折點不額外平滑，不測不同h選最佳結果。

每人將所有鄰近位置一次batch查詢；一案增量API呼叫m次，輸入樣本 `2*d*m*T`，T為位移數。若無位移，A/B為0且不查詢。batch減少呼叫不代表樣本或伺服器工作免費；完整列出兩者與耗時。資料可由各local engine提供批次回覆；本地保存模型僅作相同API模擬，沒有部署梯度服務或存取參數的新假設。

本輪先直接重用已鎖定的80個完整團隊軌跡，不重播這80個solver、不新增LOO、不重訓。只讀模型／軌跡產生A/B；全部分數存檔並hash鎖定後，以另一程序讀既有LOO標籤。來源為上一輪40個seed、320 effects（Clean120、污染200），全部仍屬已接觸過的探索資料，不聲稱新獨立確認。

4個舊pilot案例另作技術與計時：每案2次warmup、15組交替control與record+gradient+endpoint，合計128次正常baseline求解。保留原history_mode及精確保存X0；不得更動歷史solver。核對正常解與原baseline最大差<=1e-7、calls與原記錄一致、增強／control的X及loss相同，trace終點等於交付解。原API batch為額外工作，不納入「原calls未變」冒充零成本。

成本指標：四案各15次中位數加總之增強／control比，目標<=1.10；同列新增calls、samples及相對baseline比例。不達標也可完成已授權的小型既有資料比較，以區分成本與有效性失敗，但不啟動新資料。上限pilot128 solves；本輪所有模型樣本500,000、實測運算300秒，每案有限差分10,000樣本，超限停止保存失敗。

## 比較與驗收

主方法A，固定診斷B與零基準。不上歷史平均校準，不擬合係數、不轉分位數。各情境分列MAE、RMSE、三態方向一致率（delta=1e-4）、負值precision／recall及計數、整體Spearman、每個coalition內Spearman分布與可計比例。seed為抽樣單位，10,000次bootstrap、RNG20261018，探索性95%區間，兩情境分開，不稱正式顯著性確認。

本輪可前進的探索門檻：兩情境各自A的MAE低於零基準、方向>=70%、負值precision及recall>=70%，以及成本<=10%目標、技術／完整性通過。各情境參考負值需至少10個、分布至少5seed。這些是研究篩選條件，不是老師指定、也不足以建立獨立有效性。B表現再好也不取代A闖關。

全部320筆皆保留；失敗不補0或換seed，無效相關以null及有效數報告。代表案例按每情境「漏掉負值、誤判負值、正確負值、最大絕對落差」分組，再取最大落差、seed及ID排序。保存逐步梯度／回覆／作用量、數值積分誤差、原始預測、標籤差值、來源hash、成本樣本、獨立重算驗收與圖表。

停止：門檻未過不調h、改正負號、居中、加深模型或追加seed；即使過關，本次也只交付探索結果，獨立資料設計需另立登錄。沒有alpha更新、pruning、付款、Shapley、Notion或新商模。
