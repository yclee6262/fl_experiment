# 模型差異資訊補充：方向斜率 U 修訂

日期：2026-10-29。狀態：設計修訂，未實作、未執行實驗、未建立分潤有效性。不改寫既有 peer 正式／探索結果。

## 1. 定義與邊界

依使用者確認，U 改為比較當輪找方向時各模型提供的斜率資訊，不使用假設存在的多個更新候選點，也不把逐模型移除的端點當成 U 的方向欄位。P 保留原本排除自身 owner 的同儕評價；I 保留當輪 model-only 移除前後接受端點的距離。N 為差異與影響的補充候選，尚不定分配比重。

以下先明確定義一個模型一位參與者的版本。多模型 owner 的資訊聚合尚待定義，不能直接按模型個數分錢。

## 2. 每輪方向特徵

起點 x_t、固定錨點 a_k，距離 d_kt=||a_k-x_t||，單位方向 u_kt=(a_k-x_t)/d_kt。使用原求解器當輪有效方向集合 K_t；過近或切線可行探測步長不足的方向排除。所有模型使用同一集合。空集合或必要評分缺漏記 undefined，不填零。s_i 為搜尋前固定共同探測點 loss 的 Q90-Q10，無效尺度不計分。

割線方向特徵：

    g_ikt = [loss_i(a_k) - loss_i(x_t)] / (s_i * d_kt)

切線方向特徵（h_kt 為原求解器實際可行探測步長）：

    g_ikt = [loss_i(x_t + h_kt*u_kt) - loss_i(x_t)] / (s_i * h_kt)

每個模型得到長度 |K_t| 的向量。沿用最近鄰差距候選：

    D_ijt = sqrt(mean_k[(g_ikt-g_jkt)^2])
    U_it = min_(j != i) D_ijt

U 表示相對其他模型最接近者仍有多少斜率差異，不表示正確、有益或獨立新增資訊的嚴格資訊量。方向重複、錨點密度、特徵座標單位會影響分數；不能宣稱抗複製或跨模式可比。

## 3. 可跨輪重用的資料

固定模型版本、前處理、loss 定義、評分資料／狀態與錨點座標，且評分確定時，可建立模型×錨點的原始 loss 表並跨輪重用。快取鍵至少包含以上評分語境與點座標。隨機評分必須另有固定隨機性協定；不可把舊抽樣當成新抽樣。

每輪起點、距離與方向會變，因此割線斜率與 U 必須重新算。起點若是上一輪已評分並接受的端點，可沿用同一語境的逐模型 loss。

切線探測點依每輪起點、方向與可行步長改變，通常需要新評分；不能以固定錨點 loss 取代。完全相同的點及語境才可快取。

現有 host_server.py 的 _solve_subspace_custom 在迴圈外計算 anchor_losses，已重用聚合目標的錨點 loss；這不等於已有 U 所需的逐模型 loss 表與記錄器。實作需檢查並保存逐模型回覆。

## 4. I、N 與尚未定案事項

I_it=||x_full,t-x_minus_i,t||/r_t，r_t 事先固定且為正；錨點保留，移除 owner 評分的分支只跑當輪。此項仍有反事實求解成本。

先前 N=[U/(1+U)]*[I/(1+I)] 僅為候選。改為斜率後 U 具有座標尺度依賴；壓縮 U 前需鎖定特徵座標規約或固定參考斜率尺度，不能直接把割線、切線與舊端點差異的數值混合。跨模式／跨輪累積與參與者多模型聚合尚未定案。

需驗證：快取與重新評分一致、原搜尋路徑不變、loss 正比例換算一致、有效方向／缺漏處理、座標與方向重複敏感性、切線與割線可比性、有益少數漏獎及錯誤／隨機模型誤獎。差異且影響大仍可能有害。pooled 僅離線驗證，truth 僅診斷，不進 U/I/N 或分配。未啟動新實驗或付款。
