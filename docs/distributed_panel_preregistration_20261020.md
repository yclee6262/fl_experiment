# 固定分散模型評分面板：開發登錄

2026-10-20。在共享回應代理四設定產生並鎖定端點後：offline_E相關為linear9 0.80/0.68、rbf5 0.70/0.62、rbf9 0.75/0.68，但16個原coalition品質代理均未在兩情境通過0.5。這表示代理路徑已有訊號，但pooled可得性仍未解決。不得將offline_E高相關混稱可部署貢獻估計。

## 新假說與額外假設

原3/5人團隊評分可能不足以近似完整資料的品質。新方法不訓練pooled、不使用pooled預測或truth；改向本次原候選池已訓練的20個local models收集端點預測，作固定、分散式評分面板。這是新增的評分可得性假設：部署需能向原候選池的未入選模型查詢；不能假裝只用參與coalition的資訊。不招募新人、不改coalition或alpha，不按歷史LOO擬合權重。這仍是品質代理，不能宣稱其必定等於pooled。

## 固定方法

沿用共享代理四個已鎖定的端點設定，不改任何求解。對每個代理端點與baseline，向local_models.pt全部20個模型查signed預測；另以剔除本次coalition的15/17個模型作非參與者面板。兩面板固定均勻，不按seed／情境調整。

各面板四種Q：abs(mean(f))、abs(median(f))、mean(abs(f))、median(abs(f))。score_i=Q(z_i)-Q(X_full)。共2面板×4Q×4端點設定=32候選，全數保留，不能因結果好挑人、調權重或反轉正負。pooled只比較既有LOO標準，不進入此分數；truth不用。

## 開發與後續確認

開發仍為同20個已用團隊，不新增其獨立性。先鎖定32候選分數，再讀既有LOO。兩情境均平均團隊內Spearman>0.5、有效團隊覆蓋>=90%的同一公式可候選確認；按兩情境最小相關最大排序，平手優先5格點、線性代理、較少面板模型，最後固定名稱排序。bootstrap10000次、RNG20261020，近零與同分口徑沿用總計畫。完整披露本輪及前兩族嘗試數。

只有通過開發的單一凍結方法才能用全新2026102200–2219二十seed×兩情境確認。不能按確認結果調整或換備選後仍稱獨立；失敗留負面結果。驗收兩情境平均相關>0.5、95%區間下界>0且覆蓋>=90%，並分開報告區間下界是否>0.5。

## 成本與停止

開發最多20,000額外local model輸入samples、0真實solver、0訓練、300秒；重用已鎖定代理端點。每個候選實際部署範圍成本要另算（正常一次、該設定共同探測、代理模擬、其面板端點查詢），不能把32候選研究總量當單一方法；也不能忽略正常求解、未入選模型及代理CPU成本。低成本樣本門檻沿用<=完整LOO方案70%，時間另配對驗證。若沒有方法通過，不啟動確認，不靠pooled／truth選分數。
