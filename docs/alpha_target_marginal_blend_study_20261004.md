# Target-local × 邊際資訊初始 α：低品質情境研究

## 目的與方法

先前單純以邊際資訊 α 替換 Target-local 候選，在不同批次及情境的 pooled 品質不穩定；補做第六候選雖可救回部分案例，但成本增加且沒有建立穩定優勢。本研究改為**把兩種信息合成一組第五候選 α**，仍只做五次 Stage 3：

`α_blend = 0.5 α_target_local + 0.5 α_marginal_50`

其中 `α_target_local` 以 Stage 0 盲測標記到正式 target 的距離加權各 local model 誤差，並加入相當於 5 筆的全域 Stage 0 MSE 先驗；`α_marginal_50 = 0.5 B + 0.5 norm(max(gain_i,0))`，`B` 為 Stage 0 MSE 反比權重，`gain_i` 是在 B 集成中排除 agent i 的 local prediction 後，盲測集成 MSE 相對完整集成的增量。若沒有正增益，邊際部分回退為 B。這衡量當前集成的預測信息，不是完整移除參與者的反事實貢獻、招募價值或付款公平性。

原五候選為 Uniform、B、MSE power 1.5、Corr precision 0.5、Target-local。新五候選只將最後一個替換為上述合成權重；其餘資料、模型、proposal、Stage 3、box 約束及 B20 全域 ridge 內部選解規則相同。pooled evaluator 是**交付後的主要品質判準**，合成真實函數只作診斷；兩者均不輸入 α 或選解。合成權重只需對 20 筆 Stage 0 標記查詢每個 local model 一次，不增加可信標記或候選求解次數。

## 開發證據與主張範圍

`explore_target_marginal_blend.py` 用保存的 local models、proposal 與 evaluator，重新求解合成候選 X，重播原五候選的內部分數作一致性檢查，再離線試算新五候選交付結果。這六批 seeds 均已用於先前研究，**全部屬於開發資料**，不能作新法的獨立優勢。

| 情境 | 舊批次：新－原 pooled 均差 | 新批次：新－原 pooled 均差 | 開發判讀 |
|---|---:|---:|---|
| 乾淨基本 | +0.000146（180 seeds） | -0.000215（120 seeds） | 方向不一致 |
| 樣本量不平衡 | +0.000001（120 seeds） | -0.000279（120 seeds） | 接近零或小幅改善 |
| 25% 低品質 | -0.000937（120 seeds） | -0.000669（120 seeds） | 兩批同方向，但都不是正式證據 |

在新批次 seeds 1900–2019，合成新法相對原五候選的方法獨立平均模型請求變化，乾淨約 +0.09%、不平衡約 -0.28%、低品質約 +1.44%；三批描述性 95% 配對區間均跨零。低品質 seeds 1700–1819 的均差也為負。由於僅低品質情境兩批同方向，本次正式問題**事前限縮為低品質參與者**，不宣稱乾淨、不平衡或真實資料上的通用優勢。

低品質 seeds 0–4 的流程 pilot 有 5／5 有效可行交付、10／10 次選解重播通過；新法／原五候選平均 pooled 誤差為 0.023291／0.023963。pilot 只檢查資料流和保存，不作品質推論。原始結果在 `alpha_weight_outputs/alpha_target_marginal_blend_*development*/` 與 `alpha_target_marginal_blend_lowquality_pilot_v1_20261004/`，沒有覆蓋既有研究輸出。

## 正式登錄與驗收

`docs/alpha_target_marginal_blend_preregistration_20261004.json` 在正式執行前固定獨立 seeds 2200–2379，共 180 個低品質配對，已核對未見於既有 suite manifests。正式環境固定三人 coalition、二維 target 0、25% local observed labels 加噪、乾淨 pooled evaluator、box `[-1,1]` 與 `1e-8` 可行性容差。同 seed 的兩方法共用資料、local models、proposal 與外部 evaluator。

主要差為 `E_blend − E_original_five`，負值代表合成法較好。以 seed 作抽樣單位，固定分析 RNG 做 10,000 次 bootstrap，報告平均差及雙側 95% 區間。正式低品質優勢要求：180／180 有效可行配對、區間上限小於零、沒有較高觀察失敗率、沒有額外可信標記，且平均方法獨立 local-model API 請求增幅不超過 5%。另報中位數、Q1／Q3、最大退步、95 百分位退步、truth 分數衝突、各階段成本與整批共用成本。任何正式結果都不回頭調整權重比例或門檻；若改方法，須另立版本與新 seeds。

正式執行目錄：`alpha_weight_outputs/alpha_target_marginal_blend_lowquality_formal_v1_20261004/`。研究結果若為負面，仍保存完整條件、來源快照與逐 seed 案例，不將開發批次合併成正式樣本。

## 正式結果：品質優勢未建立

seeds 2200–2379 的 180／180 個配對均有有效、box 可行交付解；360／360 個候選選解變體重播通過，16／16 個登錄來源快照雜湊一致。沒有觀察失敗或新增可信標記。完整數字與逐方法中位數、Q1／Q3、truth、成本在 `alpha_weight_outputs/alpha_target_marginal_blend_lowquality_decision_2200_180.json`。

| 指標 | 原五候選 | Target-local × 邊際資訊五候選 |
|---|---:|---:|
| 平均 pooled 絕對誤差 | 0.015354 | 0.015018 |
| pooled 中位數 | 0.012323 | 0.012327 |
| 平均 truth 絕對誤差（診斷） | 0.014045 | 0.013752 |
| 平均方法獨立模型請求 | 1799.23 | 1791.50 |
| 觀察失敗 | 0／180 | 0／180 |

正式主要配對差 `E_blend−E_original_five` 的平均為 **-0.000337**，10,000 次 seed bootstrap 的雙側 95% 區間為 **[-0.000897,+0.000156]**，跨零。新法較好／相同／較差為 **27／127／26**；混合 α 候選實際被選中 **33／180**。平均 API 請求約少 7.73 次（-0.43%），成本條件通過，但**品質優勢條件未通過**，所以整體正式門檻未通過。這不能表述成「低品質情境已證明新 α 更好」或貨幣淨收益。

最差案例 seed 2308 的 pooled 差為 **+0.014990**：原法選 Target-local，新法選 Uniform；相同 seed 的 truth 差亦為正。最大改善 seed 2225 為 **-0.027532**，新法選中混合 α。pooled／truth 的方法優劣方向衝突有 **18／180** 個 seed，完整案例須保留，不用 truth 事後替換主要 pooled 判準。

為釐清經濟取捨，同批單次 Uniform A 平均僅約 **363.48** 次模型請求，遠低於原五候選的 **1799.23**；但 A 的 pooled 誤差相對原五候選平均高 **0.005085**，配對 95% 區間 **[+0.002876,+0.007396]**。因此 A 是明顯較便宜但品質有可觀測損失的選項；不能把多候選額外請求簡化為純浪費。沒有實際請求價格與應用上每單位誤差價值，尚不能宣稱哪一種方法有貨幣上的淨利益。

研究決策是保留原五候選作高品質比較基準；混合候選目前只作經濟邏輯明確、成本接近但品質未獲證實的候選方法。先前「條件式第六候選」與本輪混合權重均未通過獨立品質門檻，再以同一 20 筆盲測標記和已見 pooled 結果微調比例，將增加選法偏誤。下一個有意義的研究輸入是事前定義的應用誤差容忍度、查詢／標記成本，或與現有 blind set 真正獨立的選解資訊；在取得之前，不提升新 α 為主要方法。
