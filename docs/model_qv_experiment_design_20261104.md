# 完整錨點 C^A 與模型 Q/V 實驗登錄

依本次對話設計實作。既有正式結果不回填。本文件記錄實際執行規格；逐次執行的事前案例與參數見輸出 registration.json。

錨點維持完整逐輪 C^A。模型方向分支扣除 G_i，保留所有錨點與完整評分 F，按原始步長、十次縮步及接受規則取得端點。Cdir=F(扣除方向分量後端點)-F(完整端點)。U 使用舊版25點Q90-Q10尺度、去重實際方向的標準化斜率最近鄰RMS差。Q_i=sum_t[U_it/(10+U_it)]Cdir_it。V只用原搜尋trial序列，按剩餘模型正規化權重判斷第一個改善候選，最後用完整F比較，無候選則回原點。

四臂：base、完整C^A+V（AV）、完整C^A+Q+V（QV）、完整參與者LOO。空快取獨立起跑，版本內共用精確輸入快取；最多30輪。每隊暖機1次、量測3次，順序循環交錯。評分次數為主要成本，核心時間與模型時間為補充。

20隊既有凍結神經網路案例為回歸資料。另用新種子2026110400–409，各建立一般、完全重複、不同方向係數、不同方向且偏置四組，每組10隊的二維解析模型，合計40隊。四組共用對應種子，屬配對情境，不是40個獨立抽樣種子。aligned/biased標籤只描述生成係數，不預設實際受益或受害。這是相對於原口頭規劃的具體化：未新訓練模型，因此獨立結果只支持解析合成案例。

模擬分配使用Q、V累積可靠正值（>1e-10），分別按比例分配，Q額度25%、50%、75%；零分母保留。檢查集中、保留、Q正但Cdir累積負的情況。這是模擬，不執行付款或修改基本池資格。

驗收：原始解各臂相同、重跑分數與成本一致、歷史C^A與AV呼叫數重現、V新增評分零、方向重建誤差1e-10。另以六個簡單決策／算術案例檢查有益、有害、無變化、重複資訊、尺度換算、V否決作用。機制檢查與40隊情境分開解讀。
